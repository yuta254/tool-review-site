## 総評

この記事の料金・機能は公式サイトの記載を2026年11月3日に確認したものです。当サイトで実際に使った検証はしていません。

### 現在の状況(2026年11月3日確認)

AWSの公式ブログ([英語版](https://aws.amazon.com/blogs/devops/amazon-q-developer-end-of-support-announcement/) 2026年4月30日、[日本語版](https://aws.amazon.com/jp/blogs/news/amazon-q-developer-end-of-support-announcement/) 2026年5月1日)で、Amazon Q Developerのサポート終了が発表されています。

| 日付 | 内容 |
| --- | --- |
| 2026年5月15日 | 新規受付の停止。IDEプラグインからAWS Builder IDで無料枠のアカウントを作ることと、AWSコンソールから新しいサブスクリプションを作ることができなくなった(既存のProサブスクリプションへのユーザー追加は可能) |
| 2026年5月29日 | Q Developer ProでClaude Opus 4.6が使えなくなった(Opus 4.5など既存のモデルは引き続き利用可) |
| 2027年4月30日 | IDEプラグインと有料サブスクリプションのサポート終了 |

- 既存のPro利用者は2027年4月30日までIDEプラグインを使えます。移行期間中も重要なバグ修正は提供されるとされています。
- 公式の移行先は**Kiro**(仕様駆動開発のためのエージェント型IDEとCLI)です。Q Developerのエージェント型コーディング、インラインチャット、ターミナル統合、MCPサポートも含むと説明されています。
- AWSマネジメントコンソール、AWSドキュメントサイト、AWS Console Mobile App、SlackとMicrosoft Teams向けのチャットアプリでのAmazon Q Developerは、影響を受けないとされています。
- IDEで行うJavaのアップグレードと.NETの移植(コード変換)は有料サブスクリプションが必要で、2027年4月30日以降は使えなくなります。代わりにAWS Transformが案内されています。
- 既存の無料枠の利用者がいつまで使えるかは、確認したページには明記されていませんでした。

Amazon Q Developerは、AWSが提供するAIコーディング支援ツールで、旧CodeWhispererを土台に機能を拡張したサービスです。VS CodeやJetBrains系IDEなどに拡張機能として組み込み、インラインのコード補完に加え、チャット形式で質問しながらコードを書き進められる点は他のAIコーディングツールと共通しています。AWSのサービスやSDKに関する質問・提案を想定して作られている点が特徴で、AWSを日常的に使うチーム向けの設計です。ただし上のとおりIDEプラグインはサポート終了が決まっているため、**これから新しく始める場合はKiroが公式の移行先**になります。汎用的なAIコーディング支援ツールとの比較は[GitHub Copilotレビュー](/reviews/github-copilot-review/)も参照してください。

## 主な機能(公式の説明)

- AWSのサービスやSDKの使い方、構成に関する質問への回答とコードの提案
- 公式の機能ページでは、認証情報の露出やログインジェクションなどの問題を検出して修正案を示すスキャンと、論理エラーや脆弱性などを指摘する自動コードレビューがあると説明されている
- Javaアプリケーションのアップグレード(Java内のOracle SQLをPostgreSQLへ変換する機能も含む)や、.NET Frameworkからクロスプラットフォームの.NETへの移植を行う「コード変換」機能(IDEでの利用は2027年4月30日まで)
- IDEの拡張機能のほか、CLIでもエージェント型のコーディングとコード提案に対応

## 過信は禁物な点

- IDEプラグインと有料サブスクリプションは2027年4月30日にサポートが終わるため、今からチームの標準ツールとして新しく採用するのは避け、移行先のKiroと併せて検討する
- 2026年5月15日以降は、無料枠のアカウントも新しいサブスクリプションも作れない
- 価値の大部分がAWSサービスとの連携に集中しており、AWSをあまり使わない開発者にとっては恩恵を実感しにくい。AWS以外の一般的なコーディング支援での精度は、当サイトでは他ツールと比べていない
- チーム・エンタープライズ向けの機能(管理ダッシュボード、IP補償など)はProでのみ提供される
- コード変換機能を使っても、変換後のコードを人手でレビューし、テストで動作確認する工程は省略できない
- 生成されたコードやセキュリティ指摘を鵜呑みにせず、最終判断は開発者自身が行う前提が必要

## 料金(2026年11月3日確認)

[公式の料金ページ](https://aws.amazon.com/q/developer/pricing/)の表示です。料金は米ドルで、円での価格は表示されていませんでした。

| プラン | 月額 | 主な内容 |
| --- | --- | --- |
| Free Tier | 0ドル | エージェントリクエスト(チャットとエージェント型コーディング)月50件、Javaアップグレード変換 月1,000行。**新規作成は2026年5月15日に停止** |
| Pro Tier | 1ユーザー19ドル | エージェントリクエストは上限付きで拡大、Java・.NETの変換はユーザーあたり月4,000行(アカウント単位で合算、超過は1行0.003ドル)、管理ダッシュボード、IP補償。**新規サブスクリプションの作成は停止**(既存への追加は可) |

参考として、移行先の[Kiroの料金ページ](https://kiro.dev/pricing/)では、Free(0ドル・50クレジット)、Pro(月20ドル・1,000クレジット)、Pro+(月40ドル・2,000クレジット)、Pro Max(月100ドル・5,000クレジット)、Power(月200ドル・10,000クレジット)が表示されており、有料プランの追加クレジットは1クレジット0.04ドルです。日本の請求先住所には消費税がかかると書かれています。

## 向いている人

- すでにQ Developer Proを契約していて、2027年4月30日までに移行の計画を立てる必要があるチーム
- IDEでJavaや.NETのコード変換を進めていて、期限までに終わらせたいチーム
- AWSマネジメントコンソールやSlack・Teamsのチャットで Amazon Q Developer を使っている人(サポート終了の影響を受けない範囲)
- これから始める人は、Q DeveloperのIDEプラグインではなくKiroを比較の対象にする

## 使い方のコツ

1. 既存の契約者は、進行中のコード変換を2027年4月30日より前に終わらせる(公式ブログでも推奨されている)
2. コード変換機能を使う際は、対象を小さな範囲に区切り、変換結果をテストとレビューで必ず確認する
3. IAMの権限設定は必要最小限にとどめ、チーム導入前にセキュリティ担当者と認証まわりの運用ルールを決めておく
4. Kiroへ移る場合は、クレジット制の料金になる点を踏まえて、月の利用量を見積もってからプランを選ぶ

最新の料金プランや対応機能は変更される可能性があるため、利用前に必ず公式サイトで最新情報を確認してください。

## よくある質問

**Q. 今から新しく使い始められますか。**
IDEプラグインでは使い始められません。公式ブログによると、2026年5月15日から、無料枠のアカウント作成と新しいサブスクリプションの作成が止まっています。公式の移行先はKiroです。

**Q. AWSを使っていない場合でも価値がありますか。**
下がります。このツールの特徴はAWSのサービスやSDKに関する質問・提案を想定している点にあり、AWS以外の環境では汎用のコーディング支援AIとの差が縮まります。

**Q. GitHub CopilotやCursorと併用できますか。**
技術的には併用できますが、補完が競合して煩わしくなることがあります。AWS作業のときだけ有効にするなど、使い分けの設定を決めてから運用するほうが快適です。

**Q. セキュリティスキャンはどこまで信用できますか。**
これだけで安全性を保証するものではありません。既存のレビューやスキャンを置き換えるのではなく、上乗せする位置づけで使ってください。
