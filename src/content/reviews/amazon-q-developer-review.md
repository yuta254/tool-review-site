## この記事の結論

- Amazon Q Developer の IDEプラグインと有料サブスクリプションは **2027年4月30日にサポート終了**。2026年5月15日から、無料枠のアカウントと新しいサブスクリプションは作れない(AWS公式ブログ)
- 既存の Pro は1ユーザー月19ドルのまま(2026年11月22日 公式の料金ページで確認)。2026年12月から終了までの5か月分は1ユーザー95ドル
- 公式の移行先は **Kiro**。Free 0ドル(月50クレジット)、Pro 月20ドル(1,000クレジット)、Pro+ 月40ドル、Pro Max 月100ドル、Power 月200ドル
- Kiro の料金は税別で、日本の請求先住所には日本の消費税がかかると Kiro の料金ページに明記されている
- AWSマネジメントコンソール、AWSドキュメント、Console Mobile App、Slack・Teams のチャットの Amazon Q Developer は終了の影響を受けない
- 2026年11月22日時点の Amazon Q Developer の料金ページ(日本語)には、サポート終了の告知が載っていない。終了の情報は公式ブログで確かめる必要がある

この記事の料金・機能は、[Amazon Q Developer の料金ページ](https://aws.amazon.com/q/developer/pricing/)、[AWS公式ブログの日本語版](https://aws.amazon.com/jp/blogs/news/amazon-q-developer-end-of-support-announcement/)、[Kiroの料金ページ](https://kiro.dev/pricing/)、AWSの消費税とインボイスのよくある質問を2026年11月22日に確認したものです。当サイトでは実機・実サービスを検証していません。

Amazon Q Developerは、AWSが提供するAIコーディング支援ツールで、旧CodeWhispererを土台に機能を拡張したサービスです。VS CodeやJetBrains系IDEなどに拡張機能として組み込み、インラインのコード補完、チャット、エージェント型のコーディングに対応し、AWSのサービスやSDKに関する質問・提案を想定して作られています。汎用のAIコーディング支援ツールとの比較は[GitHub Copilotの記事](/reviews/github-copilot-review/)も参照してください。

## 終了・変更の記録

AWSの公式ブログ([英語版](https://aws.amazon.com/blogs/devops/amazon-q-developer-end-of-support-announcement/) 2026年4月30日、[日本語版](https://aws.amazon.com/jp/blogs/news/amazon-q-developer-end-of-support-announcement/) 2026年5月1日)で、サポート終了が発表されています。

| 日付 | 内容 | 出典 |
| --- | --- | --- |
| 2026年4月30日 | サポート終了の発表(日本語版は5月1日) | AWS公式ブログ |
| 2026年5月15日 | 新規受付の停止。IDEプラグインから AWS Builder ID で無料枠のアカウントを作ることと、AWSコンソールから新しいサブスクリプションを作ることができなくなった(既存の Pro サブスクリプションへのユーザー追加は可能) | 同上 |
| 2026年5月29日 | Q Developer Pro で Claude Opus 4.6 が使えなくなった(Opus 4.5 など既存のモデルは引き続き利用可。Opus 4.7 を含む最新のモデルは Kiro のみ) | 同上 |
| 2027年4月30日 | IDEプラグインと有料サブスクリプションのサポート終了。IDEで行う Java のアップグレードと .NET の移植(コード変換)も使えなくなり、代わりに AWS Transform が案内されている | 同上 |

- 既存の Pro 利用者と、**Kiro のサブスクリプションを持つ利用者**は、2027年4月30日まで Q Developer の IDEプラグインを使えます。移行期間中も重要なバグ修正は提供されるとされています。
- IDEプラグインは4つのIDEのマーケットプレイスに掲載が続き、Kiro へ案内する非推奨の通知が表示されます。
- 公式の移行先の Kiro は、仕様駆動開発のためのエージェント型の開発環境(IDEとCLI)で、Q Developer のエージェント型コーディング、インラインチャット、ターミナル統合、MCPサポートも含むと説明されています。
- AWSマネジメントコンソール、AWSドキュメントサイト、AWS Console Mobile App、Slack と Microsoft Teams 向けのチャットアプリでの Amazon Q Developer は、影響を受けないとされています。

## 料金(2026年11月22日確認)

[公式の料金ページ](https://aws.amazon.com/q/developer/pricing/)(日本語)の表示です。料金は米ドルで、円での価格は表示されていません。

| プラン | 月額 | 主な内容 |
| --- | --- | --- |
| Free Tier | 0ドル | エージェントリクエスト(チャットとエージェント型コーディング)月50件、Java アップグレードの変換 月1,000行。データ収集は「オプトアウト可能」。**新規作成は2026年5月15日に停止** |
| Pro Tier | 1ユーザー19ドル | エージェントリクエストの上限の引き上げ、Java・.NET の変換は1ユーザーあたり月4,000行(支払いアカウント単位で合算、超過は1行0.003ドル)、管理ダッシュボード、IP補償。データ収集は「自動的にオプトアウト」。**新規サブスクリプションの作成は停止**(既存への追加は可) |

- Pro の料金は、サブスクリプションが「アクティベート」されたユーザーごとにかかります。コンソールやIDEでチャットにサインインしただけでは料金は発生せず、エージェント型コーディングの依頼、コード変換の計画の依頼、コード補完のいずれかを行うと発生し、解約するまで毎月更新されます(料金ページのよくある質問)。
- 最初の月は、アクティベートした時点の残り日数で日割りになります。
- 変換の例として料金ページは、10サブスクリプションで月40,000行が含まれ、50,000行を変換すると超過の10,000行に30ドルがかかる、と説明しています。

### 移行先の Kiro の料金(2026年11月22日確認)

[Kiroの料金ページ](https://kiro.dev/pricing/)の表示です(米ドル・税別)。

| プラン | 月額 | 含まれるクレジット | 追加のクレジット |
| --- | --- | --- | --- |
| Kiro Free | 0ドル | 月50 | — |
| Kiro Pro | 20ドル | 月1,000 | 1クレジット0.04ドル |
| Kiro Pro+ | 40ドル | 月2,000 | 1クレジット0.04ドル |
| Kiro Pro Max | 100ドル | 月5,000 | 1クレジット0.04ドル |
| Kiro Power | 200ドル | 月10,000 | 1クレジット0.04ドル |
| チーム(2人以上のクレジット共有) | 1席月20ドル | 1席あたり月500を共有 | 1クレジット0.04ドル |

- 初めて Free から Pro に上げると、その月の残りが無料になり、12か月以内に使える試用のクレジット500が付きます(1回目の変更のみ)。
- 含まれるクレジットは翌月に繰り越されません。追加で買ったクレジットは購入から12か月で失効します。
- 有料のサブスクリプションは毎月1日に処理されます。支払いは主なクレジットカードで、日本の請求先住所で申し込めます。

## 日本の消費税・インボイス

- **Amazon Q Developer(AWSの請求)**: AWSの[消費税のよくある質問](https://aws.amazon.com/jp/c-tax-faqs/)によると、2019年10月1日以降、日本の居住者が AWS のサービスを使うと10%の消費税を加算して請求されます。消費税額は「請求とコスト管理」の請求書ページか PDF の請求書で確認でき、PDF では「CT」と表示されます。[インボイスのよくある質問](https://aws.amazon.com/jp/local/invoice-faq/)には、アマゾンウェブサービスジャパン合同会社の登録番号 T6011001106696 が各請求書の下部に記載されるとあります。Q Developer Pro だけを取り上げた税の説明は、確認したページにはありません。
- **Kiro**: 料金ページに「価格は税別」「日本の請求先住所の場合は日本の消費税がかかる」と書かれています。税額は税の登録番号や請求先住所などで変わる、とされています。Kiro の請求書に適格請求書の登録番号が載るかは、確認したページには書かれていませんでした。
- Kiro Pro は月20ドルに10%が加わり、月22ドルが目安です。

## 1年・2年の総額の試算

前提: 公式の月額×月数。消費税10%を加えた額。追加のクレジット・変換の超過は入れない。円は仮に1ドル=150円とした場合の目安。

| 内容 | 期間 | 税込みの総額 | 円の目安 |
| --- | --- | --- | --- |
| Q Developer Pro を終了まで続ける(2026年12月〜2027年4月) | 5か月 | 1ユーザー104.5ドル | 約15,675円 |
| Kiro Pro | 1年 / 2年 | 264ドル / 528ドル | 約39,600円 / 約79,200円 |
| Kiro Pro+ | 1年 / 2年 | 528ドル / 1,056ドル | 約79,200円 / 約158,400円 |
| Kiro のチーム 5席 | 1年 / 2年 | 1,320ドル / 2,640ドル | 約198,000円 / 約396,000円 |

- Q Developer Pro(月19ドル)と Kiro Pro(月20ドル)の差は月1ドルです。ただし、数え方が違います。Q Developer はエージェントリクエストの件数、Kiro はクレジット(簡単な指示は1未満、仕様のタスクの実行は1より多い)で数えます。
- 2027年4月30日以降、Q Developer の IDEプラグインと有料サブスクリプションは使えないため、2年の比較では Kiro などへの移行が前提になります。

## 条件別の選び方

| 条件 | 行き先 | 理由(公式の記載) |
| --- | --- | --- |
| これから新しく始める | Kiro か他のツール | Q Developer の新規作成は2026年5月15日に停止 |
| Q Developer Pro を契約中で、IDEで使っている | 2027年4月30日までに Kiro などへ移行 | IDEプラグインと有料サブスクリプションはその日に終了 |
| IDEで Java・.NET の変換を進めている | 期限までに終わらせる。以後は AWS Transform | IDEでの変換は2027年4月30日以降は使えない |
| AWSコンソールや Slack・Teams のチャットで使っている | そのまま | 終了の影響を受けないとされている |
| 補完が中心でAWSに縛られない | [GitHub Copilot](/reviews/github-copilot-review/) なども比較 | Copilot は補完がクレジットを使わない(GitHub公式) |
| チームでクレジットを共有したい | Kiro のチーム(1席月20ドル) | 1席あたり500クレジットを共有し、管理者が上限を決められる |

## 公式に書いていないこと

- **料金ページでの終了の告知**: 2026年11月22日時点の日本語の料金ページには、新規受付の停止とサポート終了の記載が見当たりませんでした。Free・Pro の表がそのまま載っているため、料金ページだけを見て申し込めると読み違えないよう注意が必要です。
- **既存の無料枠の利用者がいつまで使えるか**: 公式ブログに明記されていませんでした(前回11月3日と同じ)。
- **Q Developer Pro の消費税の個別の説明**: AWS全体の消費税とインボイスの説明はありますが、Q Developer のサブスクリプションに限った記載はありません。請求書の「CT」の行で確かめられます。
- **Kiro の返金と解約の条件**: 確認した Kiro の料金ページには書かれていませんでした。
- **クレジット1つで何ができるか**: Kiro は「簡単な指示は1クレジット未満、複雑な指示は1より多い」「モデルで消費量が違う」とだけ書いています。Free の月50クレジットで、普段の作業の指示が何クレジット減るかを見ると、月に必要なプランを見積もれます。

## よくある質問

**Q. 今から新しく使い始められますか。**
IDEプラグインでは使い始められません。公式ブログによると、2026年5月15日から、無料枠のアカウント作成と新しいサブスクリプションの作成が止まっています。公式の移行先はKiroです。

**Q. 既存のProはいつまで使えますか。**
2027年4月30日までです。公式ブログによると、既存のPro利用者とKiroのサブスクリプションを持つ利用者は、その日までIDEプラグインを使えます。移行期間中も重要なバグ修正は提供されるとされています(2026年11月22日確認)。

**Q. 料金ページに申し込みの案内が残っているのはなぜですか。**
理由は公式に書かれていません。2026年11月22日時点の日本語の料金ページにはFree・Proの表がそのまま載っていますが、新規受付は公式ブログで2026年5月15日に止まったと発表されています。申し込みの可否はブログの記載を優先して判断してください。

**Q. Kiroに消費税はかかりますか。**
かかります。Kiroの料金ページに、価格は税別で、日本の請求先住所には日本の消費税がかかると書かれています(2026年11月22日確認)。

**Q. 入力したコードは学習に使われますか。**
Amazon Q Developerの料金表では、データ収集はFreeが「オプトアウト可能」、Proが「自動的にオプトアウト」とされています。Kiroのデータの扱いは、この記事では確認していません。
