## Todoist AI とは

**Todoist AI は、Todoist の AI機能の総称で、公式には「Todoist Assist」という名前でまとめられています。** 話した内容やメモ・画像からタスクを作る、あいまいなタスクを分解する、メールをタスクに変える、といった**入力と整理の手間を減らす機能**が中心で、Motion のようにカレンダーを丸ごとAIに任せる発想ではありません。無料プランでも一部を使え、全部を回数の制限なく使うにはプロ以上が必要です。

このほか、**ClaudeやChatGPTなどのAIアシスタントから、自分の Todoist のタスクを読み書きできる公式の連携**もあります(下の「[AIアシスタントとつなぐ](#claudechatgpt-などの-aiアシスタントとつなぐ)」を参照)。

この記事の機能・料金は、Todoist の[公式料金ページ](https://www.todoist.com/ja/pricing)とヘルプセンター、AI機能の紹介ページ([todoist.com/ai-tools](https://www.todoist.com/ai-tools)。以前の todoist.com/todoist-assist から転送されます)を2026年11月12日に確認したものです。当サイトは公式の公開情報を整理しており、実際に使った検証はしていません。

## Todoist Assist でできること

| 機能 | できること(公式ヘルプの説明の要旨) | 使えるプラン |
| --- | --- | --- |
| 音声入力(Ramble) | 話した内容をその場で文字にして、日付・ラベル・優先度の付いたタスクに分ける。日本語を含む約40言語に対応。「期限」(日付とは別に付ける項目)と所要時間は有料プランの機能で、初心者プランでは話しても反映されない | 初心者(とプロ レガシー)は月10回まで、プロ・ビジネスは無制限 |
| Task Capture Assist | 貼り付けた文章(25,000字まで)、画像、PDF などから、やることを抜き出してタスクの候補にする。確定するまで登録されない | 初心者は月10回まで(音声入力と合わせた回数)、プロ・ビジネスは公正な利用の範囲で無制限 |
| Task Assist | 目標に向けたタスクの提案、進め方のヒント、あいまいなタスクを行動しやすい表現に書き直す、大きなタスクをサブタスクに分ける(以前の公式ヘルプの説明。下の注意点を参照) | プロ・ビジネス |
| Email Assist | プロジェクト専用のアドレスに転送したメールを、予定日やメモを抜き出したタスクに変える。設定の「高度な設定」でオンにしてから使う | プロ・ビジネス |
| Filter Assist | 「今週期限で優先度が高いもの」のような言葉から、フィルターの検索式を作る | 初心者(無料)・プロ・ビジネス |

いくつか注意点があります。

- **無料プランの「月10回」は、音声入力(Ramble)と Task Capture Assist の合計です。** タスクが1件以上見つかったときだけ1回と数え、毎月1日(協定世界時)に戻る、とヘルプセンターに書かれています。
- **Task Assist は、料金ページではプロ・ビジネスの機能として載っていますが、使い方を説明していたヘルプセンターのページ(Task Assist 拡張機能)は2026年11月12日時点で開けなくなっています。** 上の表の Task Assist の説明は、以前の公式ヘルプの記載です。現在のヘルプセンターの「Todoist Assist について」(2026年11月11日更新)では、オン・オフを切り替えられる Todoist Assist の機能は Email Assist だけとされています。
- **Filter Assist は現在、英語とスペイン語のみ対応**とヘルプセンターに書かれています。日本語で指示してフィルターを作る使い方は想定されていません。
- Task Capture Assist の対応言語は、確認したヘルプのページには書かれていませんでした。
- 「明日の15時」「毎週月曜」のような日時を入力欄で読み取る機能(スマート クイック追加)は、AI機能とは別に、無料プランから使えます。

## Claude・ChatGPT などの AIアシスタントとつなぐ

「Todoist AI assistant」で調べる人の中には、**ChatGPT や Claude から Todoist を操作したい**人もいるはずです。Todoist には **Claude と ChatGPT 向けの公式の連携(コネクタ)** があり、会話の中でタスクを作る・直す・完了にする・予定を変える、といったことができると公式ページで案内されています。公式ページでは、この連携は**全員が使える**とされています(2026年11月12日確認)。

| 項目 | 公式ヘルプの説明の要旨 |
| --- | --- |
| つなげるもの | Claude・ChatGPT には公式の連携があり、Gemini・Codex・Cursor など MCP に対応したものも、公式の MCP サーバー(`https://ai.todoist.net/mcp`)経由でつなげる |
| つなぎ方 | Todoist にログインしてアクセスを許可する(OAuth)。パスワードを相手に渡すことはない |
| できること | タスクやプロジェクトの作成、内容の変更、完了 |
| 止め方 | Todoist の「設定 > 連携」でトークンを取り消すと、すぐにアクセスが止まる |

ヘルプセンターには次の注意も書かれています。

- 繰り返しタスクの日付の変更を頼むと、繰り返しの設定が消えることがある。特定の日付に予定を変えるように頼む
- 繰り返しタスクを完了にすると、完了ではなく次の回に進む
- 勤め先や学校のアカウントでは、管理者が外部の連携を許可している必要がある場合がある

## 自然な言葉で期限とリマインダーを入れる(AI機能とは別)

「Todoist 自然言語 リマインダー」と調べる人が知りたいのは、たいてい「普段の言葉で日時を書けば、期限と通知まで設定されるか」です。これは Todoist Assist(AI機能)ではなく、**日付の自動認識(スマート クイック追加)とリマインダーの機能**で、日本語にも対応しています。公式ヘルプセンター(2026年11月3日確認)の説明の要点です。

| やりたいこと | 入力の例(公式ヘルプより) | 使えるプラン |
| --- | --- | --- |
| 期限を付ける | 「明日16:00」「金曜19:00」「5日後」をタスク名と一緒に入力 | 無料から |
| 繰り返しの期限 | 「資源ゴミを出す 隔週水曜日」、細かいものは「8月29日から6ヶ月後まで毎月第三火曜日」まで | 無料から |
| 期限の時刻に通知 | 日付と時刻を付けると、自動リマインダーが設定どおりに付く(何分前に通知するかは設定画面で選ぶ) | 無料から |
| 通知の日時を別に決める | タスク画面の「リマインダー」で「月曜 19:00」「毎週月曜 8:00」のように入力 | 1つのタスクに複数付けられるのはプロ・ビジネス |
| 入力欄で通知まで一度に入れる | 「!」の後に時間を書く(「!30分前」「!明日 15:00」「!毎日 17:00」など) | プロ・ビジネス |

- 日付の入力は最大150文字まで。チェコ語とトルコ語の日付には未対応と書かれていますが、日本語の表現の例は日本語版のヘルプに多数載っています。
- 「毎月の報告書を作成」のように、日付の言葉がタスク名の一部として読み取られることがあります。登録前に、ハイライトされた部分が意図どおりかを見てください。
- Web版・デスクトップ版では、通知のスヌーズはできません(スマホのアプリではできる)。

## 料金(2026年11月12日確認)

Todoist の日本語の料金ページの表示です(Task Capture Assist の回数はヘルプセンターの記載)。

| プラン | 料金 | AI関連で使えるもの |
| --- | --- | --- |
| 初心者 | 無料 | Filter Assist、音声入力と Task Capture Assist(合わせて月10回まで) |
| プロ | 年払いで8,064円(月あたり672円) | Task Assist、Email Assist、Filter Assist、音声入力(無制限)、Task Capture Assist |
| ビジネス | 年払いで1ユーザー11,520円(月あたり960円)+地方税 | プロの機能をメンバー全員に+チーム機能 |

月払いを選ぶと、プロは月894円、ビジネスは1ユーザー月1,280円の表示になります(年払いは約20%オフと表示)。最新の料金と請求方法は[公式の料金ページ](https://www.todoist.com/ja/pricing)で確認してください。

## 得意なこと

- あいまいなタスク(「資料を何とかする」など)を、次の行動が分かる表現に書き直す
- 大きすぎるタスクを、手を付けやすいサブタスクに分ける
- 受け取ったメールを、期限付きのタスクとして取り込む(プロ以上)
- これまでの Todoist の操作感をほぼそのまま保っている

## 過信は禁物な点

- **自動でスケジュールを組むわけではない。** 「いつやるか」を決めるのは自分です。カレンダーを自動で埋めてほしいなら、[Motion](/reviews/motion-review/)や[Reclaim.ai](/reviews/reclaim-ai-review/)の方が目的に合います
- **タスク分解の提案は一般論になりやすい。** 専門的な業務では、自分の状況に合わない手順は消す前提で使ってください
- **AIの機能を十分に使うにはプロプランが必要。** 無料プランで使えるAI機能は限られ、そのうち Filter Assist は日本語に対応していません
- **機能の名前や範囲はよく変わる。** 以前は「AI Assistant」と呼ばれていた機能が、現在は Todoist Assist にまとめられています

## 向いている人

- Motion のような全自動スケジューリングまでは求めず、身軽なToDoリストを使い続けたい人
- すでに Todoist を使っていて、タスクの整理やメールの取り込みを少し楽にしたい人
- AIに管理を任せるより、自分で決めながら軽く助けてもらいたい人

## 使い方のコツ

1. Task Assist の提案は下書きとして扱い、自分の仕事に合わせて手で直す
2. Email Assist を使うなら、取り込み先のプロジェクトを1つに決めて、後でまとめて仕分ける
3. 日時の入力は、AIより先にスマート クイック追加で十分なことが多い。登録前に読み取られた日時を確認する癖をつける

## よくある質問

**Q. AI機能のために乗り換える価値はありますか。**
既に Todoist を使っているなら、プロプランで試す価値はあります。ただ、AIのために他のツールから移行するほどの差はありません。Todoist の良さはAI以前の部分(入力の速さ、素直な構造)にあり、AIはその上に乗る補助です。

**Q. 無料プランでもAIは使えますか。**
使えます。公式ヘルプセンターでは、無料の初心者プランでも Filter Assist は使え、音声入力(Ramble)と Task Capture Assist は合わせて月10回まで使えるとされています。Task Assist と Email Assist はプロ・ビジネス向けです(2026年11月12日確認)。ほかのAIツールの無料版・無料お試しの範囲は、[AIツールの無料版・お試しの見極め方](/reviews/ai-tools-free-tier-guide/)で一覧にしています。

**Q. ChatGPT や Claude から Todoist を使えますか。**
使えます。Todoist には Claude と ChatGPT 向けの公式の連携があり、公式ページでは全員が使えると案内されています。そのほかの MCP に対応したツールも、公式の MCP サーバー経由でつなげます。詳しくは上の「Claude・ChatGPT などの AIアシスタントとつなぐ」を参照してください。

**Q. タスクを自動でスケジュールしてくれますか。**
Todoist は「いつやるか」を自動で決める方向には踏み込んでいません。カレンダーを自動で埋めてほしいなら Motion や Reclaim.ai が合います。違いは[タスク管理AIの比較](/reviews/ai-task-management-comparison/)にまとめました。

**Q. 「明日の10時に通知」のような書き方でリマインダーを付けられますか。**
付けられます。日付と時刻を入れると自動リマインダーが付き、タスク画面のリマインダー欄に「月曜 19:00」のように書けば別の日時でも通知できます。入力欄で「!明日 10:00」のように通知まで一度に入れるショートカットは、プロとビジネスの機能です(公式ヘルプセンター、2026年11月3日確認)。

**Q. 日本語で使えますか。**
アプリ自体は日本語に対応しています。音声入力(Ramble)は、ヘルプセンターで日本語を含む約40言語に対応とされています。ただし Filter Assist は、ヘルプセンターの記載では英語とスペイン語のみの対応です。ほかの機能も、日本語での提案の質は、自分のタスクで少し試してから判断するのが確実です。
