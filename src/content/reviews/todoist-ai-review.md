## この記事の結論

- Todoist AI は、Todoist の AI 機能の総称で、公式には「**Todoist Assist**」などの名前で案内されている。中心は、話した内容・メモ・画像・メールからタスクを作る**入力の手間を減らす機能**で、カレンダーを自動で埋める機能ではない
- 無料の初心者プランでも、**音声入力(Ramble)と Task Capture Assist は合わせて月10回まで**使える。プロ・ビジネスは回数の制限なし(公正な利用の範囲)。回数は毎月1日(協定世界時)に戻る
- 料金はプロが**年払い8,064円(月あたり672円)・月払い894円**、ビジネスが1ユーザー年払い11,520円(月あたり960円)・月払い1,280円で、ビジネスには「+地方税」の表示(2026年11月23日に日本語の料金ページで確認。11月12日から変更なし)
- Filter Assist(言葉からフィルターを作る)は無料から使えるが、**英語とスペイン語のみ**。Email Assist(メールをタスクに変える)はプロ以上
- **Claude・ChatGPT などから Todoist を操作する公式の連携は、全員が使える**と公式ページに書かれている
- 年払いは**購入・更新から30日以内に解約すれば全額返金**。月払いは原則返金なし。プロには7日間の試用がある
- 以前のヘルプにあった「Task Assist」(タスクの分解など)は、2026年11月23日の料金ページと「Todoist Assist の紹介」のヘルプに名前が見当たらなかった

この記事は、Todoist の日本語の料金ページ、AI 機能の紹介ページ([todoist.com/ai-tools](https://www.todoist.com/ai-tools))、ヘルプセンターを2026年11月23日に確認してまとめたものです。当サイトでは Todoist を操作して確かめてはいません。

## Todoist AI とは

Todoist は、タスクを入力して期限・優先度・プロジェクトで整理する ToDo リストのアプリです。AI の機能は、その入力と整理を助ける形で組み込まれています。[Todoist Assist の紹介のヘルプ](https://www.todoist.com/help/todoist/todoist-and-ai/introduction-to-todoist-assist-KgPP22q5O)(2026年11月20日更新)では、どの機能を使うかを利用者が選べ、AI の提供元はデータを自社のモデルの学習に使わないと約束している、と説明されています。

| 機能 | できること(公式ヘルプの説明の要旨) | 使えるプラン |
| --- | --- | --- |
| 音声入力(Ramble) | 話した内容をその場で文字にし、日付・ラベル・優先度の付いたタスクに分ける。日本語を含む40以上の言語に対応。「期限」と所要時間は有料プランの機能で、初心者プランでは話しても反映されない | 初心者(とプロ レガシー)は月10回まで、プロ・ビジネスは無制限 |
| Task Capture Assist | 貼り付けた文章(1回25,000字まで)、画像(JPEG・PNG・WebP、10MBまで)、PDF・MD・TXT(10MBまで)からやることを抜き出す。確定するまで登録されない | 初心者は月10回まで(音声入力と合わせた回数)、プロ・ビジネスは公正な利用の範囲で無制限 |
| Email Assist | 転送したメールを、日時を抜き出し分かりやすい名前に直したタスクに変える。設定でオン・オフできる | プロ・ビジネス |
| Filter Assist | 見たいタスクを言葉で書くと、フィルターの式を作る。保存の前に結果を確かめて直せる | 初心者・プロ レガシー・プロ・ビジネス |
| Todoist Automations の AI ステップ(ベータ) | 料金ページでは、自動化の中に AI の手順を入れる機能として掲載 | プロ・ビジネス |

## Claude・ChatGPT などの AIアシスタントとつなぐ

「Todoist AI assistant」で調べる人の中には、ChatGPT や Claude から Todoist を操作したい人もいます。Todoist には公式の連携があり、[AI ツールのページ](https://www.todoist.com/ai-tools)のよくある質問では、Claude・ChatGPT・MCP サーバー・CLI・API への接続は**全員が使える**とされています(2026年11月23日確認)。

| 項目 | 公式ヘルプの説明の要旨 |
| --- | --- |
| 設定の案内があるもの | Claude、Claude Code、ChatGPT、Codex、Gemini Spark、Muse。MCP に対応したものなら、個別の連携がなくてもつなげる |
| つなぎ先 | 公式の MCP サーバー `https://ai.todoist.net/mcp` |
| つなぎ方 | OAuth でアクセスを許可する。相手に渡るのはトークンで、パスワードは渡らない |
| できること | タスクの読み取り・追加・変更・完了、プロジェクトの追加と整理 |
| 止め方 | Todoist の「設定 > 連携」でトークンを取り消すと、すぐにアクセスが止まる |

[ヘルプセンター](https://www.todoist.com/help/articles/use-chatgpt-with-todoist-WEeLx9d8h)には次の注意も書かれています。

- 繰り返しタスクの「日付の変更」を頼むと、繰り返しの設定が消えることがある。「〜に予定を変えて」と頼む
- 繰り返しタスクを完了にすると、完了ではなく次の回に進む
- 勤め先や学校のアカウントでは、管理者が外部の連携を許可している必要がある場合がある

## 自然な言葉で期限とリマインダーを入れる(AI 機能とは別)

「Todoist 自然言語 リマインダー」と調べる人が知りたいのは、普段の言葉で日時を書けば期限と通知まで設定されるか、という点です。これは Todoist Assist ではなく、**日付の自動認識(スマート クイック追加)とリマインダーの機能**で、日本語にも対応しています。公式ヘルプセンター(2026年11月3日確認)の説明の要点です。

| やりたいこと | 入力の例(公式ヘルプより) | 使えるプラン |
| --- | --- | --- |
| 期限を付ける | 「明日16:00」「金曜19:00」「5日後」をタスク名と一緒に入力 | 無料から |
| 繰り返しの期限 | 「資源ゴミを出す 隔週水曜日」、細かいものは「8月29日から6ヶ月後まで毎月第三火曜日」まで | 無料から |
| 期限の時刻に通知 | 日付と時刻を付けると、自動リマインダーが付く(何分前かは設定画面で選ぶ) | 無料から |
| 通知の日時を別に決める | タスク画面の「リマインダー」で「月曜 19:00」「毎週月曜 8:00」のように入力 | 1つのタスクに複数付けられるのはプロ・ビジネス |
| 入力欄で通知まで一度に入れる | 「!」の後に時間を書く(「!30分前」「!明日 15:00」など) | プロ・ビジネス |

- 日付の入力は最大150文字まで。チェコ語とトルコ語の日付には未対応と書かれています。
- 「毎月の報告書を作成」のように、日付の言葉がタスク名の一部として読み取られることがあります。登録前に、ハイライトされた部分を確かめてください。

## 試用・解約・返金

- **試用:** [ヘルプセンター](https://www.todoist.com/help/account-and-billing/billing/start-a-todoist-pro-trial-LAVIT1Xm3)では、プロの機能を7日間無料で試せ、解約しなければ試用の終わりに契約が自動で始まり最初の支払いが行われると書かれています。
- **返金:** [返金のヘルプ](https://www.todoist.com/help/articles/request-a-refund-P1PoqD3J)(2026年11月16日更新)では、年払いのプロは**購入・更新から30日以内に解約すれば全額返金**です。年払いのビジネスも30日以内なら、チームを解約してから問い合わせると返金の対象です。月払いは、各国の消費者保護法で必要な場合を除いて返金されません。
- **アプリで契約した場合:** App Store の分は Apple に返金を申請します。Google Play の分は、Google Play で解約してから Todoist に問い合わせます。

## 日本の消費税・インボイス

- 料金ページでは、ビジネスの金額に「+地方税」と書かれ、プロには税の表記がありません(2026年11月23日確認)。
- **日本の消費税(10%)の扱い、適格請求書(インボイス)の発行、日本の登録番号は、確認したページに書かれていませんでした。** ヘルプセンターの VAT の請求書の記事は EU・英国向けの内容です(2026年11月22〜23日の別記事の確認)。
- 法人で仕入税額控除を受けたい場合は、最初の請求書の表示を確かめるか、サポートに問い合わせてください。

ほかの海外AIツールの消費税の扱いと登録番号は、[海外AIツールの消費税・インボイス対応一覧](/reviews/ai-tools-japan-consumption-tax-invoice/)にまとめています(国税庁の公表サイトで照合)。

## 1年・2年の総額の試算

日本語の料金ページの円の金額をそのまま合計した目安です。円の表示のため、ドルからの換算(当サイトのドル建ての記事では1ドル=150円)はしていません。ビジネスの「地方税」は含みません。

| プラン・人数 | 年払い・1年 | 年払い・2年 | 月払い・1年 | 月払い・2年 |
| --- | --- | --- | --- | --- |
| プロ 1人 | 8,064円 | 16,128円 | 10,728円 | 21,456円 |
| ビジネス 1人 | 11,520円 | 23,040円 | 15,360円 | 30,720円 |
| ビジネス 5人 | 57,600円 | 115,200円 | 76,800円 | 153,600円 |

## 条件別の選び方

| 条件 | 選び方 | 理由(公式の記載) |
| --- | --- | --- |
| 声やメモからタスクを作るのが月に数回 | 初心者(無料) | Ramble と Task Capture Assist が合わせて月10回まで |
| 声や画像からのタスク作成を毎日使う | プロ | 回数の制限なし(公正な利用の範囲) |
| 受け取ったメールをタスクにしたい | プロ以上 | Email Assist とメールの取り込みはプロ・ビジネス |
| 日本語でフィルターを作らせたい | Filter Assist は使わず、フィルターの式を手で書く | Filter Assist は英語とスペイン語のみ |
| ChatGPT や Claude の会話からタスクを動かしたい | どのプランでも可 | 公式の連携は全員が使える |
| チームでプロジェクトを共有したい | ビジネス | チームのワークスペース、役割と権限の設定 |
| カレンダーを自動で埋めてほしい | 別のツールと比べる | Todoist は日時を自動で決める機能を案内していない |

カレンダーの自動の予定組みが目的なら[Motion](/reviews/motion-review/)や[Reclaim.ai](/reviews/reclaim-ai-review/)が近い用途です。違いは[タスク管理AIの比較](/reviews/ai-task-management-comparison/)にまとめています。ほかの AI ツールの無料の範囲は[AIツールの無料版・お試しの見極め方](/reviews/ai-tools-free-tier-guide/)で一覧にしています。

## よくある質問

**Q. 無料プランでもAIは使えますか。**
使えます。料金ページとヘルプセンターでは、無料の初心者プランでも Filter Assist は使え、音声入力(Ramble)と Task Capture Assist は合わせて月10回まで使えるとされています。Email Assist はプロ・ビジネス向けです(2026年11月23日確認)。

**Q. ChatGPT や Claude から Todoist を使えますか。**
使えます。Todoist の AI ツールのページでは、Claude・ChatGPT・MCP サーバーなどへの接続は全員が使えると案内されています。MCP に対応したほかのツールも、公式の MCP サーバー経由でつなげます。

**Q. 日本語で使えますか。**
アプリは日本語に対応しています。音声入力(Ramble)は、ヘルプセンターで日本語を含む40以上の言語に対応とされています。ただし Filter Assist は英語とスペイン語のみの対応で、Task Capture Assist の対応言語は書かれていませんでした。

**Q. タスクを自動でスケジュールしてくれますか。**
確認した公式のページでは、AI が作業の時間を決めてカレンダーに入れる機能は案内されていません。カレンダーを自動で埋めてほしいなら Motion や Reclaim.ai が近い用途です。違いは[タスク管理AIの比較](/reviews/ai-task-management-comparison/)にまとめました。

**Q. 「明日の10時に通知」のような書き方でリマインダーを付けられますか。**
付けられます。日付と時刻を入れると自動リマインダーが付き、タスク画面のリマインダー欄に「月曜 19:00」のように書けば別の日時でも通知できます。入力欄で「!明日 10:00」のように通知まで一度に入れるショートカットは、プロとビジネスの機能です(公式ヘルプセンター、2026年11月3日確認)。

**Q. 年払いにした後でやめたら返金されますか。**
