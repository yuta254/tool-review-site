各ツールの料金・機能は公式サイトの記載を2026年11月3日に確認したものです。当サイトで実際に使った検証はしていません。

## 4つの違いは「作れるもの」と「公開の仕方」

どれも「プロンプトから作れる」ツールですが、公式に説明されている作れるものと、公開の仕方が違います。

| | 提供元 | 作れるもの(公式の説明) | 公開 |
| --- | --- | --- | --- |
| v0 | Vercel | 実際のコードとフルスタックのアプリやエージェント。技術は Next.js・React・TypeScript・Tailwind CSS・shadcn/ui | v0 の Publish から Vercel に公開。コードの書き出しやGitHubとの同期もできる |
| Bolt.new | StackBlitz | フロントエンドからバックエンド(Node.js)までのアプリ一式。JavaScript系のさまざまなフレームワーク、Expoを使ったスマホアプリにも対応。バックエンドはJavaScript系のみで、PHPやPythonは使えない | 組み込みのホスティング(Bolt Cloud)とデータベースで、〇〇.bolt.host に公開 |
| Framer AI | Framer | ページ・セクション・文章・画像を含むWebサイトの土台。ビジュアルエディタで仕上げる。エージェントがコードコンポーネントを作れるとも案内されている | Framer のホスティングでそのまま公開 |
| Replit Agent | Replit | Webアプリ・スマホアプリ・スライド・データの表示など。コードを書き、動かす環境を準備し、結果をテストする(現在の版は Agent 4) | Replit の公開機能(Autoscale・Static・Reserved VM・Scheduled) |

## 料金と無料プランの制限(2026年11月3日確認)

金額はすべて米ドルの月額です。

| | 無料プラン | 有料の入口 | 独自ドメイン |
| --- | --- | --- | --- |
| v0 | 1日7メッセージまで。Vercelへの公開、GitHubとの同期 | Plus 1人あたり月30ドル(月30ドル分のクレジット) | v0 の画面から追加できる。ただし公開先の Vercel の無料プラン(Hobby)は個人・非商用に限られる |
| Bolt.new | 月100万トークン(1日30万まで)。「Made in Bolt」の表示 | Pro 月25ドル(年払いなら月18ドル相当) | 有料プランのみ |
| Framer AI | Framer の無料ドメイン、帯域は月1GB | Basic 月10ドル(エージェントのクレジット月1,000) | 有料プランのみ |
| Replit Agent | Starter:Free Mode を1日の上限つきで使える。公開できるアプリは1つで30日で自動的に止まる | Core 月20ドル(年払いなら月18ドル) | 画面から購入または接続できる。使えるプランの条件は、確認した公式ドキュメントに明記されていない(2026年10月23日確認) |

| | 日本語 | 入力したデータの学習への利用 |
| --- | --- | --- |
| v0 | 公式FAQでは、プロンプトは好きな言語で書け、同じ言語で返答するとされている(日本語の個別の記載はなし) | プロンプトや生成内容をモデルの改善に使うことがある。Vercelの設定でオプトアウトできるほか、Business以上は学習からの除外が既定 |
| Bolt.new | 個別記事で確認した範囲には記載なし | 個別記事で確認した範囲には記載なし |
| Framer AI | 個別記事で確認した範囲には記載なし | 個別記事で確認した範囲には記載なし |
| Replit Agent | 画面を日本語に切り替える機能や、日本語での指示についての記載は、確認したページに見つからなかった | 契約しているプランの規約に従うとされ、具体的な扱いは確認したページに記載なし |

用途で分けるなら、「見せるためのWebサイトを早く出したい」ならFramer、「データの保存やサーバー側の処理を含むアプリを作って公開したい」ならBoltかReplit、「Next.js のコードとして受け取り、自分のプロジェクトや Vercel で育てたい」ならv0、という考え方ができます。

## それぞれの位置づけ

### v0

Vercel が提供するAIで、もともとはUIの生成から始まったツールです。公式ドキュメントでは現在、「実際のコードとフルスタックのアプリやエージェントを作るAIエージェント」と説明されており、UIだけでなくバックエンドの処理も作れるとしています。プロンプトのほか、画像・ワイヤーフレーム・Figmaのデザインを手がかりにでき、コードの書き出しやGitHubとの双方向の同期にも対応しています。使われる技術が Next.js・React・TypeScript・Tailwind CSS・shadcn/ui に決まっているため、他のフレームワークを前提にした開発には向きません。商用のサイトを Vercel で公開するなら、Vercel の有料プランが必要です。詳しくは[v0レビュー](/reviews/v0-review/)を参照してください。

### Bolt.new

StackBlitz が提供するAIアプリビルダーで、ブラウザの中でNode.jsを動かす技術(WebContainers)を使い、ローカルの環境構築なしでアプリ一式を生成・編集・公開できます。Chrome・Edge などの Chromium 系ブラウザが完全対応で、Safari には制限があると公式ヘルプにあります。使う量はトークンで数えられ、大きなプロジェクトほど1メッセージあたりのトークンが多くなると説明されています。詳しくは[Bolt.newレビュー](/reviews/bolt-new-review/)を参照してください。

### Framer AI

プロンプトからサイトの土台を作り、Framer 本体のビジュアルエディタで仕上げる形です。エージェントにレイアウト・文章・CMS・SEOの修正や、コントラスト不足・誤字などの点検を頼めます。ホスティングまで含めて完結しますが、将来ほかのCMSやホスティングへ移す場合は手間がかかる可能性があります。会員機能や複雑なフォーム処理のようなアプリ寄りの機能が必要なら、対応範囲を公式ドキュメントで確かめてください。詳しくは[Framer AIレビュー](/reviews/framer-ai-review/)を参照してください。

### Replit Agent

ブラウザで使う開発環境 Replit に組み込まれたAIで、作ることと動かすこと・公開することが同じ場所で進みます。Agent には無料で使える Free Mode(利用枠あり)と、有料の Power・Max モードがあり、有料の作業は頼んだ内容の複雑さに応じてチェックポイント単位で課金されます。公開の費用も月のクレジットから差し引かれます。詳しくは[Replit Agentレビュー](/reviews/replit-agent-review/)を参照してください。

## 共通してつまずくところ

1. **生成されたコードの保守。** 動くものが出ても、後から他人が読んで直せるかは別問題です。長く使う予定なら、生成後に構造を整理する時間を見込んでください。
2. **要件が曖昧なまま作り始める。** プロンプトが曖昧だと出力も曖昧になります。画面の数と、各画面で何ができるかを先に箇条書きにしておくと、意図とのずれを確かめやすくなります。
3. **公開先の準備。** 生成はできても、独自ドメインでの運用や常時稼働には別の手当てが要ることがあります。Bolt と Framer は独自ドメインが有料プランのみ、Replit の無料プランは公開が30日で止まり、v0 の公開先 Vercel の無料プランは非商用に限られます。手順と費用は[AIで作ったサイトを公開する方法](/reviews/ai-site-publish-custom-domain/)にまとめました。
4. **費用の見え方。** トークン・クレジット・チェックポイントなど、使った量で数える形式が多く、試行錯誤が増えるほど費用が伸びます。Replit のように予算の上限を設定できるツールもあります。

## よくある質問

**Q. プログラミングを知らなくても使えますか。**
4つとも、ふつうの言葉の指示から作れると公式に説明されています。ただし、エラーが出たときの切り分けや、生成されたコードを読んで直す段階では知識が要ります。「詰まったときに調べられる」程度の下地はあったほうが進めやすくなります。

**Q. 業務システムを作っても大丈夫ですか。**
試作や社内の小さな効率化までは現実的です。Replit の公式ドキュメントでも、Agent が作ったコードの正しさ・安全性の確認は利用者の責任とされています。個人情報や決済を扱う本番システムは、生成物をそのまま使わず、設計とセキュリティを人が確認する前提で進めてください。

**Q. コーディング支援AIとは何が違いますか。**
ここで挙げた4つは「アプリやサイトそのものを生成する」方向、CursorやGitHub Copilotは「書いている人を支援する」方向です。既存コードを触るなら後者が適します。[コーディング支援AIの比較](/reviews/ai-coding-tools-comparison/)も参照してください。
