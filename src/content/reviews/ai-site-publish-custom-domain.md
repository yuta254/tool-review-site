## この記事の結論

v0・Bolt.new・Replit・Framer は、どれも**ツールの中に公開ボタンがあり、無料のサブドメイン(〇〇.vercel.app など)ならすぐ公開できます**。独自ドメイン(example.com のような自分の住所)を付けるときに、ツールごとに条件が分かれます。

| | 公開先 | 無料のURL | 独自ドメイン | 無料のまま使うときの主な制限 |
| --- | --- | --- | --- | --- |
| v0 | Vercel | 〇〇.vercel.app | v0の画面から追加できる(DNSはドメイン会社側で設定) | Vercelの無料プラン(Hobby)は**個人・非商用に限られる** |
| Bolt.new | Bolt Cloud(Netlifyも選べる) | 〇〇.bolt.host | **有料プランのみ** | 月10GB・333,333リクエストを超えると翌月まで止まる。「Made in Bolt」の表示 |
| Replit | Replit | 〇〇.replit.app | 画面から購入または接続できる | 無料のStarterは公開できるアプリが1つで、**30日で自動的に止まる** |
| Framer | Framer | 〇〇.framer.website など | **有料プランのみ** | 帯域は月1GB |

- **お店や仕事のサイト、広告を載せるサイト**なら、v0(Vercel)の無料プランは規約上使えません。Vercelの有料プランか、別の公開先が必要です。
- **独自ドメインは、どのツールでも「ドメインを買う」と「ツールに接続する」の2段階**です。ドメインはツールの中で買える場合もありますが、ドメイン会社で取得してDNSを設定する方法も共通して使えます。

この記事は各社の公式ドキュメント・料金ページを**2026年10月23日**に確認して整理したもので、当サイトで実際に公開して検証したものではありません。料金と条件は変わることがあるため、申し込む前に各社の公式ページで最新の表示を確かめてください。

## 独自ドメインを付ける流れ(共通)

どのツールでも、手順の骨格は同じです。

1. **ツール上でサイトを公開する。** まず無料のURLで、表示やフォームが動くことを確かめます(Bolt は公開済みのサイトにしかドメインを接続できない、と公式ドキュメントにあります)。
2. **ドメインを用意する。** ツールの中で買うか、ドメイン会社で取得します。
3. **ツールの設定画面にドメインを入力する。** 設定すべきDNSレコード(Aレコード、CNAMEなど)が表示されます。
4. **ドメイン会社の管理画面でDNSレコードを追加する。** 表示された値をそのまま写します。
5. **反映を待つ。** 数分から数時間かかります。Bolt は「多くは数時間、最大24時間」、Replit は「最大48時間」と説明しています。HTTPS(鍵マーク)について、Replit は独自ドメインでも自動で有効になると説明しており、Bolt は証明書の状態を設定画面で確認できる(必要なら手動で発行を依頼できる)と案内しています。

つまずきやすいのは4のDNSです。Bolt の公式ドキュメントでは、ルートドメイン(wwwなし)には ALIAS・ANAME・Flattened CNAME のいずれかを使い、**名前の似た AAAA レコードと取り違えないよう**注意書きがあります。ドメイン会社によって使えるレコードの種類が違うため、分からないときはドメイン会社のヘルプで「ALIAS」「CNAME」の設定方法を確認してください。

## v0(Vercel)の公開方法と独自ドメイン

### 公開のしかた

v0 で作ったプロジェクトは Vercel に公開(デプロイ)されます。公式ドキュメントの手順は次のとおりです。

1. チャット画面の上部にある **Publish** を押す
2. 初回は Vercel のプロジェクト名、公開範囲、ドメインを確認する
3. 公開すると、変わらない本番用のURL(〇〇.vercel.app)が付く

2回目以降は、Publish から **Publish Changes** を押すと本番が更新されます。

### 独自ドメインの付け方

- **Publish → Customize Domain**、または**プロジェクトのメニュー → Settings → Domains** から追加します。
- 自分のドメインを使う場合は、「Inspect on Vercel」から Vercel の管理画面に移り、表示される案内に沿ってドメイン会社側でDNSレコードを設定します。
- 〇〇.vercel.app の名前を選び直すだけなら無料で、HTTPSも自動で設定されると説明されています。

### 費用

| | 料金(2026年10月23日 公式サイトで確認) | 公開に関係する点 |
| --- | --- | --- |
| v0 Free | 0ドル | 1日7メッセージまで |
| v0 Plus | 1人あたり月30ドル | 月30ドル分のクレジット |
| v0 Business | 1人あたり月100ドル | 月30ドル分のクレジット、学習への利用を既定で除外 |
| Vercel Hobby | 0ドル | **個人・非商用に限る**。1プロジェクトに独自ドメイン50個まで |
| Vercel Pro | 月20ドル | 商用で使う場合はPro以上が必要 |

Vercel の公正利用のガイドラインでは、Hobby プランは「非商用の個人利用に限る」とされ、商用の例として**商品やサービスの販売の宣伝、広告の掲載(Google AdSense など)、アフィリエイトリンクが主目的のサイト、サイトの制作・運用で報酬を受け取ること**が挙げられています。寄付を募ることは商用に当たらないとも書かれています。お店の紹介ページや、仕事として納品するサイトを v0 で作るなら、公開先の費用として Vercel Pro(月20ドル)を見込んでおくのが安全です。

## Bolt.new の公開方法と独自ドメイン

### 公開のしかた

Bolt には公開用のホスティング(Bolt Cloud)が組み込まれていて、別のサービスに登録しなくても公開できます。

1. 画面右上の **Publish** を押す
2. 開いたメニューでもう一度 **Publish** を押す
3. 1分ほどで、〇〇.bolt.host のURLで公開される

公式ドキュメントでは、公開は Publish メニューのボタンから行うよう勧めています。**チャットで「公開して」と頼むとトークンを消費する**ためです。無料プランでは公開したサイトはすべて一般公開になり、限られた人だけに見せる設定は有料プランの機能です。

### 独自ドメインの付け方

- **独自ドメインは有料プランでのみ使えます。** 無料プランに戻すと、独自ドメインでの公開はできなくなります。
- Bolt の中でドメインを買うか、持っているドメインを接続します。接続は「歯車のアイコン → All project settings → Domains & Hosting → Connect a domain you own」から行います。
- DNSは、**www に CNAME(値は site-dns.bolt.host)、ルートドメインに ALIAS / ANAME / Flattened CNAME(値は同じ)**を設定するよう案内されています。

### 費用

| | 料金(2026年10月23日 公式サイトで確認) | ホスティングの上限 |
| --- | --- | --- |
| Free | 0ドル(月100万トークン、1日30万トークンまで) | 月10GB・333,333リクエスト。超えると月末までサイトが止まり、上限は増やせない |
| Pro | 年払いで月18ドル相当(年216ドル) | 月30GB・100万リクエスト。上限を超えた分は、自分で決めた額まで従量で追加できる |

無料プランのサイトには「Made in Bolt」のバッジが表示され、有料プランにすると消えます。公式の説明では、無料プランの上限はおよそ月1万〜1万5千回の訪問に相当するとされています。また、Bolt の代わりに Netlify に公開することもできますが、**Netlify ではデータベースやサーバー側の処理は動かない**ため、会員登録や注文の保存があるアプリは Bolt Cloud のままにするよう書かれています。

## Replit の公開方法と独自ドメイン

### 公開のしかた

Replit では、作ったアプリを Publishing(公開)の設定から公開し、〇〇.replit.app の無料のURLが付きます。公開の方式は、アクセスがあるときだけ動く Autoscale、静的なサイト向けの Static、常に動かす Reserved VM、決まった時刻に動かす Scheduled から選べます。

### 独自ドメインの付け方

- プロジェクトの画面で **Tools → Replit Cloud の Domains** を開き、「新しいドメインを買う」か「持っているドメインを使う」を選びます。
- 持っているドメインは、外部サービス(Entri)がドメイン会社の設定を代わりに書き込む案内つきの方法と、表示されたDNSレコード(AレコードとTXTレコード)を自分で入力する方法があります。
- 公式ドキュメントの比較表では、独自ドメインの費用は「ドメイン会社に支払う」、DNSの反映は最大48時間とされています。

### 費用

| | 料金(2026年10月23日 公式サイトで確認) | 公開に関係する点 |
| --- | --- | --- |
| Starter | 0ドル | 公開できるアプリは1つ。**30日で自動的に止まる**(再公開は可能)。「Made with Replit」のバッジ |
| Core | 月20ドル(年払いなら月18ドル) | 公開できるアプリの数に上限なし。バッジを外せる |
| Pro | 月100ドル(年払いなら月90ドル) | 最大15人で使うチーム向け |

公開にかかる費用(サーバーの稼働や通信量)は毎月のクレジットから差し引かれ、使い切った後は従量で請求されます。確認した公式ドキュメントには、独自ドメインを使えるプランの条件ははっきり書かれていませんでした。いずれにしても、無料の Starter は30日で公開が止まるため、続けて公開するサイトなら Core 以上が前提になります。

## Framer の公開方法と独自ドメイン

### 公開のしかた

Framer はホスティングまで含めたサイト制作ツールで、公開ボタンからそのまま公開できます。無料のドメインは、好きな名前を入れて framer.website・framer.photos・framer.media・framer.wiki のどれかを選ぶ形で、数秒で使えるようになると説明されています。

### 独自ドメインの付け方

- 料金ページのよくある質問では、**独自ドメインをつなぐには有料プランへのアップグレードが必要**とされています。
- 接続は「Site Settings → Hosting → Domains → Connect a domain you own」から行い、**ルートドメインなら A レコード2つと www の CNAME 1つ、サブドメインなら CNAME 1つ**をドメイン会社側に設定します。
- 年払いの有料プランには、ドメインを1つ無料で取得できる特典があります(1つのサイトの契約につき1回)。

### 費用

| | 料金(2026年10月23日 公式サイトで確認) | 帯域(月) |
| --- | --- | --- |
| Free | 0ドル | 1GB |
| Basic | 月10ドル | 50GB |
| Pro | 月30ドル | 100GB(超過分は100GBごとに40ドル) |

料金ページには「表示は月額で、請求は購入時に選んだ周期による」と書かれています。年払いにしたときの月あたりの金額は、購入画面で確認してください。

## 独自ドメインで1年公開するときの費用の目安

ツールの料金に、ドメイン代を足した金額です(2026年10月23日の公式の表示。為替やセール、税は含めていません)。

| 組み合わせ | 1年目の目安 | 向いている人 |
| --- | --- | --- |
| Framer Basic(年払い)+ 特典のドメイン | Basicの年額のみ | 見た目の整った紹介ページを早く出したい |
| Bolt Pro(年払い)+ 取得したドメイン | 216ドル + ドメイン代 | 会員登録やデータ保存のあるアプリを公開したい |
| Replit Core(年払い)+ 取得したドメイン | 216ドル + ドメイン代(公開の稼働分はクレジットから) | 作りながら動かし続けたい |
| v0 + Vercel Pro + 取得したドメイン | 240ドル + v0の料金 + ドメイン代 | 商用のサイトを Next.js で育てたい |
| 生成したファイルをレンタルサーバーへ置く | サーバー代 + ドメイン代 | ブログやWordPressも同じ場所で運用したい |

ツールの有料プランは月額のドル建てで、ドメインは年単位の円建てです。**毎年かかるのはツールの料金とドメインの更新料**なので、2年目以降の金額も先に確かめておくと、後から慌てずに済みます。

## ドメインの取得先とレンタルサーバー:お名前.comの場合

ツールの中でドメインを買わずに、国内のドメイン会社で取得してDNSを設定する方法もあります。例として、お名前.com の公式サイトの表示(2026年10月23日確認)を整理します。

**ドメイン**

- トップページでは、.com・.net・.jp などが登録1円と表示されています。ただし .com と .net の1円は**1人1個まで**で、過去に1円で取得したことがある場合は通常価格(.com の2個目以降は750円)になります。
- 更新料金は「会員ごとの保有件数に応じて変動する」とされ、料金一覧のページで確認する形です。また、料金には一時的に「サービス維持調整費」が加算されることがあると注記されています。
- 表示価格はすべて税込です。

**レンタルサーバー(お名前.com レンタルサーバー)**

| 支払い方法 | 月あたり(税込) | 支払い額(税込) |
| --- | --- | --- |
| 1か月払い | 2,398円 | 2,398円 |
| 12か月払い | 1,078円 | 12,936円 |
| 36か月払い | 891円 | 32,076円 |

- 初期費用は0円で、申し込んだ月の月額料金は無料です(前払いのため、初回は翌月・翌々月分が請求されます)。
- ディスク容量は1TB(SSD)、WordPressのかんたんインストール、無料のSSL証明書に対応しています。
- サーバーと同時に申し込むと、対象のドメイン(.com・.jp・.net など)が登録1円で、**サーバーを使っている間は更新料が0円**になる特典があります。ただし、ドメインを更新した後12か月以内にサーバーを解約すると、更新費用の実費が請求されます。

レンタルサーバーが向くのは、**ブログやWordPressのサイトも同じ場所で運用したい**場合や、ドメインとサーバーをまとめて管理したい場合です。AIツールで作ったサイトでも、ビルドして出来上がったHTML・CSS・JavaScriptだけで動く静的なサイトなら、一般的なレンタルサーバーに置くことができます。反対に、データベースやサーバー側の処理を使うアプリは、そのままでは動かないことが多いため、ツール側の公開機能を使う方が手間がかかりません。

## サーバー代を抑えたいときの選択肢

- **まずは無料のURLのまま公開する。** 見てもらう相手が限られる試作品なら、〇〇.bolt.host や 〇〇.framer.website で十分なこともあります。独自ドメインは後から付けられます。
- **静的なサイトなら、静的ホスティングの無料枠を使う。** Netlify の無料プラン(公式の料金ページでは「無料・月300クレジット」)は、独自ドメインとSSLの設定に対応しています。Cloudflare Pages の無料プランは、ビルドが月500回、1プロジェクトに独自ドメイン100個、1サイトのファイルは2万個までです。Vercel の Hobby も無料ですが、前述のとおり非商用に限られます。
- **データベースを使うアプリは、ツール側の公開機能を使う。** 公開先を分けると、データベースの接続先やログイン後の戻り先URLなどを自分で設定し直す必要が出てきます。

## 公開する前に確かめておきたいこと

1. **フォームやログインが本番のURLで動くか。** Replit の公式ガイドでも、独自ドメインに切り替える前に、まず無料のURLでログイン・予約・決済の流れが動くことを確かめるよう書かれています。
2. **公開範囲。** Bolt や v0 では、公開範囲(誰でも見られるか、招待した人だけか)を公開時に選びます。一般公開のサイトは検索エンジンにも載ります。
3. **個人情報や決済を扱う処理は、人の目で確認する。** AIが生成したコードはそのまま動いても、安全とは限りません。Bolt の有料プランには公開前のセキュリティ確認機能があります。ツールごとの得意・不得意は[AIアプリ生成4種の比較](/reviews/ai-app-builder-comparison/)にまとめています。

## よくある質問

**Q. v0 で作ったサイトに独自ドメインを付けるにはどうすればよいですか。**
v0 の Publish メニューの「Customize Domain」か、プロジェクトの Settings → Domains からドメインを追加し、Vercel の管理画面に表示されるDNSレコードをドメイン会社側に設定します。ただし、公開先の Vercel の無料プラン(Hobby)は非商用に限られるため、商用のサイトなら Vercel Pro(月20ドル)が必要です。

**Q. bolt.new で作ったサイトは無料で公開できますか。**
できます。Publish ボタンから 〇〇.bolt.host のURLで公開できます。独自ドメイン、限られた人だけに見せる公開、「Made in Bolt」の表示を消すことは、有料プランの機能です。無料プランは月10GB・333,333リクエストを超えると、その月はサイトが止まります。

**Q. ドメインはツールの中で買うのと、ドメイン会社で買うのとどちらがよいですか。**
ツールの中で買うと、DNSの設定をしなくても接続まで進むのが利点です(Bolt や Replit の公式ドキュメントで案内されています)。ドメイン会社で取得すると、公開先のツールを変えてもドメインをそのまま使い続けやすくなります。後でツールを乗り換える可能性があるなら、ドメインは独立して持っておく方が身軽です。

**Q. Framer のサイトを独自ドメインで公開できますか。**
有料プラン(Basic 月10ドル〜)にすると、持っているドメインを接続できます。年払いの有料プランには、ドメインを1つ無料で取得できる特典があります。各ツールの位置づけは[Framer AIレビュー](/reviews/framer-ai-review/)、[Bolt.newレビュー](/reviews/bolt-new-review/)、[v0レビュー](/reviews/v0-review/)、[Replit Agentレビュー](/reviews/replit-agent-review/)も参照してください。
