## 総評

[Motion](https://www.usemotion.com/)は、入力したタスクや会議の締め切り・所要時間・優先度をもとに、AIが自動でカレンダー上に時間枠を割り当ててくれるスケジューリングツールです。予定が変わったりタスクが追加されたりすると、そのつどスケジュールを自動で組み直してくれるのが最大の特徴です。手作業でカレンダーとToDoリストを行き来しながら調整する手間を減らしたい人にとっては、発想自体は非常に理にかなっています。

なお、Motion は現在、タスクの自動スケジューリングだけでなく、AIチャット・プロジェクト管理・ドキュメント(Wiki・メモ)・文章作成までを含む「AIの仕事用ツール一式」として案内されています(2026年11月12日に公式の料金ページで確認)。この記事では、検索でよく調べられているタスク管理と自動スケジューリングの部分を中心に整理します。当サイトは公式の公開情報を整理しており、実際に使った検証はしていません。

## Motionのタスク管理(ToDo)でできること

Motion のタスク管理は、**ToDo を書きためるだけでなく、1件ごとに「所要時間」「締切」「優先度」を入れ、それをもとに AI がカレンダーの空き時間へ作業時間を割り当てる**仕組みです。予定が増えたり作業が延びたりすると、残りのタスクの配置が組み直されます。**所要時間を入れていないタスクはカレンダーに配置されない**ので、ToDo を書くときは所要時間まで入れるのが前提です(2026年11月12日に公式ヘルプで確認)。

### タスクに入れる項目

公式ヘルプの「Task」のページで、タスクを作る画面の項目として挙がっているものです。

| 項目 | 公式ヘルプの説明の要旨 |
| --- | --- |
| タイトル | タスクの名前 |
| 優先度 | ASAP・高・中・低 など |
| 所要時間 | 作業にかかる見込みの時間 |
| 繰り返し | 1回だけか、毎日・毎週・毎月などの繰り返しか |
| 分割(チャンク) | 長いタスクを小分けにし、複数の時間帯に分けて配置する |
| 開始日 | いちばん早く着手できる日 |
| 締切 | タスクの期限 |
| 締切の固さ | 動かせない締切か、多少ずれてもよい締切かを切り替える |

### 自動スケジュールの決まり方

公式ヘルプの「How Auto-Scheduling Works」のページでは、次のように説明されています(2026年11月12日確認)。

- 所要時間・開始日・締切・優先度などを見て空き時間を探し、**締切が近いものと優先度が高いものから先に**配置する
- **所要時間がないタスクは配置できない**。締切も優先度もないタスクも配置されない
- 新しい会議が入ったり予定がぶつかったりすると、タスクは自動で配置し直される。つないだカレンダーの予定は常にタスクより優先される
- 締切に間に合わなそうなときは、前倒しにするか警告を出す。条件を満たせないタスクは「Could not fit」と表示され、所要時間・締切・優先度を直すまで配置されない
- 締切を過ぎたタスクは、次の空き時間に入れ直され、期限切れの印が付く

ToDo アプリのように「やることを並べておく」使い方より、「いつやるかまで決めてほしい」使い方に向いた作りです。いつやるかを自分で決めたいなら、[Todoist AI](/reviews/todoist-ai-review/)のような ToDo 中心のアプリの方が合います。

## 自動スケジューリングツールとしての Motion と Reclaim.ai の違い

タスクを空き時間に自動で入れる「自動スケジューリングツール」としてよく並べられるのが、Motion と [Reclaim.ai](/reviews/reclaim-ai-review/) です。いちばん大きな違いは、**Motion はタスク管理とカレンダーを1つのアプリにまとめる形、Reclaim.ai は今使っている Google カレンダーや Outlook に後付けする形**だという点です。

| | Motion | Reclaim.ai |
| --- | --- | --- |
| 形 | タスク・プロジェクト・カレンダーを Motion の中で管理 | 既存の Google カレンダー・Outlook に後付け |
| タスクの置き方 | タスクごとに作業時間をカレンダーへ配置 | 2026年5月以降の登録者(Reclaim 2.0)は、確保した集中時間の中で取り組むタスクを示す形。旧版(1.0)はタスクごとに時間を確保する |
| 無料プラン | なし(無料トライアルあり) | あり(Lite・予定を組む範囲は1週間先まで) |
| 有料の最安 | 1人あたり月19ドル(Pro AI・チーム向けの年払い。1人で使う個人向けは年払いで月29ドル) | 1人あたり月10ドル(Starter・年払い) |

Motion の料金は2026年11月12日、Reclaim.ai の料金は2026年11月3日、Reclaim.ai のタスクの置き方は2026年11月6日に、それぞれの公式ページで確認したものです。Reclaim.ai の仕組みは[Reclaim.aiの記事](/reviews/reclaim-ai-review/)、ほかのツールも含めた比較は[タスク管理AIの比較](/reviews/ai-task-management-comparison/)にまとめています。

## 得意なこと

- タスクの締め切りと所要時間から、空いている時間に自動でブロックを割り当ててくれる
- 会議が追加・変更された際に、他のタスクの配置を自動的に再調整してくれる
- 優先度の高いタスクを締め切りに間に合うよう前倒しで配置しようとする
- ToDoリストとカレンダーを一つの画面で一元管理できる

## 過信は禁物な点

- 配置のもとになる所要時間は自分で見積もって入れる。見積もりが実際より短いと、カレンダー上の計画も詰まりすぎる
- 予定が入るたびにタスクの配置が自動で組み直される仕組みのため、いつ何をやるかが日によって動く
- 割り込みや急な予定変更が多い働き方では、組み直しの回数もそのぶん増える
- 料金は年払いで1人あたり月19ドルから(1人で使う個人向けは年払いで月29ドル、月払いなら月49ドル)で、シンプルなタスク管理アプリと比べると高めの部類に入る(下の料金表を参照)
- AI機能はプランごとの「AIクレジット」の範囲で使う仕組みのため、AI機能を多く使う人は上限を確かめておきたい

## 日本語で使えるか

Motion の公式ヘルプのよくある質問では、**アプリの表示言語は今のところ英語のみ**と案内されています(2026年11月12日確認)。メニューや設定画面は英語で操作することになります。

タスク名やメモを日本語で書いたときに、AIの機能がどこまで正しく扱うかについては、公式の説明は見当たりませんでした。日本語で使う予定なら、無料トライアルの間に自分の普段のタスクを登録して確かめるのが確実です。英語の画面に抵抗がある場合は、日本語で使えるタスク管理アプリと比べてから決めると安心です([タスク管理AIの比較](/reviews/ai-task-management-comparison/))。

## 向いている人

- 日々のタスクと会議が多く、優先順位付けとスケジュール調整に時間を取られている人
- 時間単位で稼働を管理するフリーランスやコンサルタントなど、時間の可視化が重要な働き方をしている人
- 手動でのタスク管理を続けるモチベーションが続かず、ある程度AIに任せたいと感じている人

## 使い方のコツ

1. 最初の数週間はタスクの所要時間見積もりを実態に近づける調整期間と割り切り、AIの提案を都度修正して精度を上げていく
2. 優先度と締め切りの設定を丁寧に行うほど自動配置の精度が上がるため、雑に登録しない
3. 完全にAI任せにせず、1日の始めにスケジュールを一度目視で確認する習慣をつける

最新の料金プランや機能については、必ず公式サイト（usemotion.com）で確認してください。

## よくある質問

**Q. カレンダーを自動で埋められると困りませんか。**
公式ヘルプでは、つないだカレンダーにある予定は常にタスクより優先され、タスクの方がその周りに配置し直されると説明されています。動かしたくない作業は、タスクではなくカレンダーの予定として先に押さえておくと、組み直しの対象から外せます。

**Q. ToDoリストとしてだけ使えますか。**
タスクを登録して一覧で管理することはできますが、Motion の中心は「所要時間と締切から作業時間をカレンダーに入れる」ことです。公式ヘルプでは、所要時間のないタスクはカレンダーに配置されないとされています。ToDoリストとしてだけ使うなら、年払いでも1人あたり月19ドルから(個人向けは月29ドルから)の料金に見合うかを先に考えてください。

**Q. 無料で使えますか。**
2026年11月12日時点の公式料金ページには、無料で使い続けられるプランはなく、有料プラン(年払いで1人あたり月19ドルから)の無料トライアルが案内されています。無料プランのあるタスク管理AIを探しているなら、[Todoist AI](/reviews/todoist-ai-review/)や[Reclaim.ai](/reviews/reclaim-ai-review/)が候補になります。

**Q. 日本語に対応していますか。**
公式ヘルプでは、アプリの表示言語は英語のみとされています(2026年11月12日確認)。

**Q. 料金は高くありませんか。**
タスク管理ツールとしては高い部類です。「予定を組み直す時間」が実際に毎日発生している人にとっては見合いますが、タスク数がそもそも少ない人には過剰です。

**Q. Reclaim.aiとどちらを選ぶべきですか。**
Motionはタスク管理とスケジューリングを一体で提供し、Reclaim.aiは既存のGoogleカレンダーに後付けする形です。今の運用を変えたくないならReclaim、まとめて置き換えたいならMotionが合います。詳しくは[タスク管理AIの比較](/reviews/ai-task-management-comparison/)を参照してください。
