## この記事の結論

- Warp(ワープ)は、**AIエージェントと一緒に作業することを前提に作られたターミナル**。公式サイトは「the agentic development environment(エージェント型の開発環境)」と呼んでいる。2026年4月にアプリ本体のソースコードを公開した
- **macOS・Windows・Linux に対応**。Windows は Windows 10 バージョン1903以降で、使えるシェルは PowerShell 7(標準)・PowerShell 5・WSL2・Git Bash。**コマンドプロンプト(cmd.exe)には対応していない**
- 料金は米ドルで、Free(0ドル)・Build(月20ドル)・Max(月200ドル)・Business(1人月50ドル)・Enterprise(個別見積もり)。料金ページには18ドル・180ドル・45ドルの金額も並ぶ(2026年11月23日確認。金額は11月12日から変更なし)
- AIの利用分は**ドル建て**で、Build は毎月20ドル分、Max は200ドル分、Business は1人20ドル分。**Free には含まれず**、使った分を買うか自分のAPIキーを持ち込む
- **支払いはクレジットカードのみ**。利用規約では、支払いは取り消し・返金ができず、価格は税抜と定められている
- アカウント登録は任意。AI機能は設定からまとめて切れる。Warp が用意するAIでは提供元とゼロデータ保持(ZDR)の契約があり、個人でも「Help improve Warp」を切ると ZDR にできる

この記事は、Warp の公式サイト(料金ページ・利用規約・ブログ)と公式ドキュメント(docs.warp.dev)を2026年11月23日に確認してまとめたものです。当サイトでは Warp を操作して確かめてはいません。

## Warpとは

Warp は、コマンドを打つターミナルのアプリに、AIのエージェントを組み込んだものです。普通の文章で頼むと、エージェントがコマンドを実行し、出力を読んで次の手を決めます。公式サイトとドキュメントで紹介されている主な機能です(2026年11月12日確認、今回は再確認せず)。

| 機能 | できること(公式の説明の要旨) |
| --- | --- |
| ブロック(Blocks) | コマンドとその出力を1つのまとまりにする。まとまりごとにコピー・検索・絞り込み・共有ができる |
| エージェント(Warp Agent) | 指示を受けてコマンドを実行し、出力を読んで次の手を決める。対話型のプログラムの操作やファイルの編集もできる |
| 実行前の承認 | コマンドの実行・ファイルの編集・MCPサーバーの呼び出しの前に承認を求める。自動で進める範囲は「Agent Profiles」と権限の設定で決める |
| クラウドのエージェント | 手元だけでなくクラウド(Oz)でもエージェントを動かせる。Free は限定的 |
| Warp Drive | よく使うコマンド(Workflows)、手順書(Notebooks)、AIへの定型の指示(Prompts)を保存し、チームで共有できる。Free は限定的 |
| 選べるAIモデル | 有料プランでは OpenAI・Anthropic・Google・xAI のモデルと公開モデルを選べる |

このほか、ほかのターミナルで動く「Warp Agent CLI」と、クラウドで開発作業を自動化する別製品「Warp Factories」があります。2026年11月23日の料金ページは「Warp Factories pricing」という題で、ターミナルのプランと Factories のプランが同じページに載っています。この記事はターミナルの Warp を扱います。

## 料金

公式の[料金ページ](https://www.warp.dev/pricing)の、ターミナルとエージェントのプランです(米ドル。2026年11月23日確認)。日本円の表示はありませんでした。

| プラン | 比較表の月額 | 並んで表示される金額 | 含まれるAIの利用分 | 主な違い |
| --- | --- | --- | --- | --- |
| Free | 0ドル | 0ドル | なし(使った分を購入、または自分のAPIキー) | ターミナルの基本機能、Warp Agent CLI、クラウドの会話は30件まで、Warp Drive・クラウドのエージェントは限定的 |
| Build | 20ドル | 18ドル | 毎月20ドル分 | すべてのモデルを使える Warp Agent、Warp Drive 無制限、追加分の自動補充とチームの支出上限、メールでのサポート |
| Max | 200ドル | 180ドル | 毎月200ドル分 | Build の内容に加えて利用分が10倍 |
| Business | 1人50ドル | 1人45ドル | 1人あたり毎月20ドル分 | 最大25人、SAMLのシングルサインオン、チームの利用状況、管理者によるデータの設定 |
| Enterprise | 個別見積もり | 個別見積もり | 個別 | 人数無制限、自社クラウドのAIの利用、自社環境でのクラウドのエージェントなど |

- 料金ページには2組の金額が並んでいますが、どちらが月払いか年払いかの表示は、今回確認したページの本文からは読み取れませんでした。11月12日の確認では、18ドル・180ドル・45ドルが年払いの月あたりの金額として表示されていました。
- 利用分は**ドルで数えられ**、1回の作業でどれだけ使うかは、モデル・作業の大きさ・参照する内容の量・手元かクラウドかで変わると書かれています。残りは Settings > Billing & usage で見られます。
- 利用規約の4.3では、使い残した利用分は契約期間の終わりに消え、超過分として買ったものは持ち越せるとされています。

### 自分のAPIキーを使う(BYOK)

料金ページによると、Free でも**自分の OpenAI・Anthropic・Google のAPIキー**で Warp Agent を動かせます。キーは端末に保存されると書かれています。OpenRouter・LiteLLM などの OpenAI 互換の接続先も使えます。BYOK の対象は個人と従業員10人以下の組織で、それより大きい組織は Business 以上が想定されています。

## AIに送られるデータとプライバシー

ターミナルの内容をAIに渡すツールなので、仕事で使う前に確かめておきたい点です。料金ページのよくある質問と、ドキュメントの[プライバシーのページ](https://docs.warp.dev/support-and-community/privacy-and-security/privacy/)の記載です(2026年11月23日確認)。

| 項目 | 公式の記載の要旨 |
| --- | --- |
| ゼロデータ保持(ZDR) | 契約したAIの提供元とZDRの取り決めがあり、提供元はデータを学習に使わず、指示と出力は応答の生成後に消すことになっている |
| ZDRが効く範囲 | Warp が提供元のアカウントを用意する場合だけ。どのプランでも、対応するモデルに効く。自分のAPIキーや接続先を使った場合は対象外 |
| 個人でZDRにする方法 | Settings > Privacy で「Help Improve Warp」を切る |
| 「Help Improve Warp」を切ると | 利用データと内容の収集が止まる(組織が強制した設定がある場合はそれに従う) |
| Business・Enterprise | 管理者が管理画面でチームの内容の収集を変えられる |
| 秘密情報の伏せ字 | 設定できる Secret Redaction は**初期状態ではオフ** |
| 第三者の監査 | SOC 2 Type II の報告書を取得(料金ページ) |

11月12日の確認では、プライバシーのページに「Free でAI機能を使うにはテレメトリを有効にしておく必要がある」という記載があり、料金ページと書き方がそろっていませんでした。11月23日のプライバシーのページにはこの記載が見当たらず、ZDRはどのプランでも Warp が提供元のアカウントを用意する場合に効く、という書き方になっていました。

### AIを切ることはできる?

できます。公式ドキュメントでは、AI機能は **Settings > Agents > Warp Agent** でまとめて無効にでき、設定の一覧では「すべてのAI機能を有効にするか」の項目(初期値はオン)として載っています。提案を自動で出す「Active AI」も、個別に切れます。ドキュメントのページによって設定の場所の書き方が少し違うため、画面のメニュー名で確かめてください。

## 対応OSと動作条件

公式ドキュメントの「[インストールと設定](https://docs.warp.dev/getting-started/quickstart/installation-and-setup/)」と「[対応シェル](https://docs.warp.dev/getting-started/supported-shells/)」の記載です(2026年11月23日確認)。

| OS | 条件 | 入れ方の例 |
| --- | --- | --- |
| macOS | Intel または Apple シリコン、macOS 10.14以降、Metal に対応したハードウェア | アプリを入れる、または `brew install --cask warp` |
| Windows | Windows 10 バージョン1903(ビルド18362)以降、Windows Server 2022(ビルド20348)以降。x86_64 と ARM64 | インストーラー、または `winget install Warp.Warp` |
| Linux | glibc 2.31以降、OpenGL ES 3.0以上か Vulkan に対応。例として Ubuntu 20.04・Debian 11・Fedora 32・Arch Linux。x86_64 と ARM64 | .deb・.rpm・.pkg.tar.zst のパッケージ、または AppImage |

| OS | 使えるシェル |
| --- | --- |
| macOS・Linux | bash、fish、zsh、PowerShell(pwsh) |
| Windows | PowerShell 7(標準)、PowerShell 5、WSL2、Git Bash |
| 非対応 | Windows のコマンドプロンプト(cmd.exe) |

- ネットにつながっている必要があるのは**初回の起動だけ**で、その後はオフラインでも動くとされています。ただし AI と共同作業の機能は使えません。
- **アカウントの登録は任意**で、飛ばしてよいと書かれています。
- Windows で bash を使いたい場合は、WSL2 か Git Bash を経由します。

## 日本の消費税・インボイス

- 利用規約の4.4では、**表示の価格は税・手数料・関税を含まず、利用者が負担する**(源泉税を含む)と定められています(2025年10月7日更新、2026年11月23日確認)。
- 料金ページには、税についての記載が見当たりませんでした。
- **日本の消費税(10%)が請求に上乗せされるか、適格請求書(インボイス)を発行するか、日本の登録番号は、確認したページに書かれていませんでした。** 法人で使う場合は、最初の請求書の表示を確かめてください。

ほかの海外AIツールの消費税の扱いと登録番号は、[海外AIツールの消費税・インボイス対応一覧](/reviews/ai-tools-japan-consumption-tax-invoice/)にまとめています(国税庁の公表サイトで照合)。

## 1年・2年の総額の試算

比較表の月額(20ドル・200ドル・50ドル)で合計した目安です。税と追加の利用分は含みません。円は1ドル=150円で換算しています。料金ページに並ぶ低いほうの金額(18ドル・180ドル・45ドル)で計算した1年の額も参考に並べます。

| プラン | 1年 | 2年 | 1年の円の目安 | 低いほうの金額で1年 |
| --- | --- | --- | --- | --- |
| Build | 240ドル | 480ドル | 約36,000円 | 216ドル |
| Max | 2,400ドル | 4,800ドル | 約360,000円 | 2,160ドル |
| Business(1人) | 600ドル | 1,200ドル | 約90,000円 | 540ドル |
| Business(5人) | 3,000ドル | 6,000ドル | 約450,000円 | 2,700ドル |

利用規約では支払いは返金されないため、年単位で払う場合は、続けるかどうかを決めてから選ぶ形になります。Free で自分のAPIキーを使う場合、Warp への支払いは0ドルで、AIの費用は各社のAPIの請求になります。

## よくある質問

**Q. Windows で使えますか。**
使えます。公式ドキュメントでは、Windows 10 バージョン1903(ビルド18362)以降、Windows Server 2022以降が条件で、x86_64 と ARM64 に対応しています。シェルは PowerShell 7(標準)・PowerShell 5・WSL2・Git Bash で、コマンドプロンプト(cmd.exe)には対応していません(2026年11月23日確認)。

**Q. 無料で使えますか。**
Free は0ドルで、ターミナルの基本機能を使えます。ただし Warp が用意するAIの利用分は含まれておらず、使った分を買うか、自分の OpenAI・Anthropic・Google のAPIキーを持ち込む形です。

**Q. ログインしないと使えませんか。**
公式ドキュメントでは、アカウントの登録は任意で、飛ばしてよいと書かれています。料金ページでは、プランの利用分を Warp Agent CLI で使うときは同じ Warp アカウントでサインインすると説明されています。

**Q. ターミナルの内容はAIの学習に使われますか。**
Warp が用意するAIでは、提供元とゼロデータ保持の取り決めがあり、学習に使わず応答の生成後に消すと説明されています。自分のAPIキーを使った場合は、自分の契約の条件になります。個人でも Settings > Privacy の「Help Improve Warp」を切ると ZDR にできます。

**Q. 料金は日本円で払えますか。返金はありますか。**
料金ページは米ドルの表示で、支払い方法はクレジットカードのみ(Stripe)と書かれています。利用規約では、支払いは取り消し・返金ができないとされ、表示の価格は税を含みません。

**Q. オープンソースになったのですか。**
公式ブログで、アプリ本体のコードが GitHub(warpdotdev/warp)に公開されたと発表されています。画面部品のライブラリが MIT ライセンス、それ以外が AGPL v3 です。リポジトリの説明では、サーバー・Warp Drive の裏側・Oz は公開の対象外です。
