## この記事の結論

Warp(ワープ)は、**AIエージェントと一緒に作業することを前提に作り直されたターミナル**です。公式サイトは自らを「the agentic development environment(エージェント型の開発環境)」と呼び、ターミナルの紹介ページでは「エージェントの時代に向けて作り直したターミナル」と説明しています。2026年4月28日には、アプリ本体のソースコードを公開(オープンソース化)しました。

- **macOS・Windows・Linux のすべてに対応**しています。Windows は Windows 10 バージョン1903以降が条件で、使えるシェルは PowerShell 7(標準)・PowerShell 5・WSL2・Git Bash です。**コマンドプロンプト(cmd.exe)には対応していません。**
- **料金は米ドル**で、Free(0ドル)・Build(月20ドル、年払いで月18ドル)・Max(月200ドル、年払いで月180ドル)・Business(1人月50ドル、年払いで月45ドル)・Enterprise(個別見積もり)。AIの利用分は「回数」ではなく**ドル建て**で、Build は毎月20ドル分が含まれます(2026年11月12日の料金ページ)。
- **Freeプランには、Warpが用意するAIの利用分は含まれていません。** 使った分だけ買う(有料プランより20%高い)か、自分のAPIキーなどを持ち込む形です。
- **アカウント登録は任意**で、AI機能は設定から**まとめて切る**ことができます。AIを使うときのデータの扱い(ゼロデータ保持など)は後で詳しく書きます。

この記事は、Warpの公式サイト(warp.dev)の料金ページ・紹介ページ・発表と、公式ドキュメント(docs.warp.dev)の記載を2026年11月12日に確認して整理したものです。当サイトで実際に使った検証はしていません。公式情報を整理した記事です。

## Warpでできること

公式サイトとドキュメントで紹介されている主な機能です。

| 機能 | できること(公式の説明の要旨) |
| --- | --- |
| ブロック(Blocks) | コマンドとその出力を1つのまとまりにする。まとまりごとにコピー・検索・絞り込み・ブックマーク・共有ができる |
| エージェント(Warp Agent) | 指示を受けてコマンドを実行し、出力を読んで次の手を決める。データベースの対話画面など対話型のプログラムも操作でき、ファイルの編集もできる |
| 実行前の承認 | エージェントはコマンドの実行・ファイルの編集・MCPサーバーの呼び出しの前に承認を求める。どこまで自動で進めてよいかは「Agent Profiles」と権限の設定で決める |
| コードの確認 | エージェントが加えた変更を画面上で確認し、コメントを付けて直しを頼める |
| クラウドのエージェント | 手元だけでなくクラウド(Oz)でもエージェントを動かせる。Freeは限定的 |
| Warp Drive | よく使うコマンド(Workflows)、手順書(Notebooks)、AIへの定型の指示(Prompts)、環境変数を保存し、チームで共有できる |
| 選べるAIモデル | 有料プランでは OpenAI・Anthropic・Google・xAI のモデルと、公開モデル(オープンウェイト)を選べる。自動で選ばせることもできる |

このほか、ターミナルの外で使える「**Warp Agent CLI**」(ほかのターミナルで動くコーディング用エージェント)と、別製品の「**Warp Factories**」(クラウドで開発作業を自動化する仕組み)もあります。この記事はターミナルのWarpを中心に扱います。

## 対応OSと動作条件(2026年11月12日確認)

公式ドキュメントの「インストールと設定」のページの記載です。

| OS | 条件 | 入れ方の例 |
| --- | --- | --- |
| macOS | Intel または Apple シリコン、macOS 10.14以降、Metal に対応したハードウェア | アプリを入れる、または `brew install --cask warp` |
| Windows | Windows 10 バージョン1903(ビルド18362)以降、Windows Server 2022以降。x86_64 と ARM64 | インストーラー、または `winget install Warp.Warp` |
| Linux | glibc 2.31以降、OpenGL ES 3.0以上か Vulkan に対応。例として Ubuntu 20.04・Debian 11・Fedora 32・Arch Linux。x86_64 と ARM64 | .deb・.rpm・.pkg.tar.zst のパッケージ、または AppImage |

- **初回の起動後は、ネットにつながっていなくても動く**とされています。ただし AI と共同作業の機能はネット接続が必要です。
- **アカウントの登録は任意**です。ドキュメントには、登録の手順は飛ばしてもよいと書かれています。

### 使えるシェル

| OS | 使えるシェル(公式ドキュメント) |
| --- | --- |
| macOS・Linux | bash、fish、zsh、PowerShell(pwsh) |
| Windows | PowerShell 7(標準)、PowerShell 5、WSL2、Git Bash |
| 非対応 | Windows のコマンドプロンプト(cmd.exe) |

Windows で bash を使いたい場合は、WSL2 か Git Bash を経由する形になります。

## 料金とプラン(2026年11月12日確認)

公式の料金ページの、ターミナルとエージェントのプランです。料金は**米ドル**で、確認したページに日本円の表示はありませんでした。

| プラン | 月払い | 年払い(月あたり) | 含まれるAIの利用分 | 主な違い |
| --- | --- | --- | --- | --- |
| Free | 0ドル | 0ドル | なし(使った分だけ購入、または自分のAPIキー等を持ち込む) | ターミナルの基本機能、Warp Agent CLI、Warp Drive・クラウドのエージェントは限定的 |
| Build | 20ドル | 18ドル | 毎月20ドル分(APIの料金で計算) | すべてのモデルを使えるWarp Agent、Warp Driveが無制限、メールでのサポート |
| Max | 200ドル | 180ドル | 毎月200ドル分(Buildの10倍) | Buildの内容に加えて利用分が多い |
| Business | 1人50ドル | 1人45ドル | 1人あたり毎月20ドル分 | 最大25人、SAMLのシングルサインオン、チームの利用状況、管理者によるデータの設定 |
| Enterprise | 個別見積もり | 個別見積もり | 個別 | 人数無制限、自社クラウドでのAI実行、自社環境でのクラウドのエージェントなど |

料金ページのよくある質問に書かれている、AIの利用分の仕組みです。

- **利用分はドルで表示される。** 1回の作業にかかる額は、モデル・作業の大きさ・参照する内容の量・手元かクラウドかで変わる。
- **含まれる利用分は30日ごとに戻る**(契約日・更新日から数える)。残りは Settings > Billing & usage で見られる。
- **追加の利用分は、Free・Build・Max・Business のどれでも買える。** Freeの価格は有料プランより20%高い。買った分は翌月に持ち越され、12か月有効。
- **支払いはクレジットカードのみ**(Stripe経由)。学生・非営利団体・オープンソースのチーム向けの割引は、現時点ではないと書かれている。

最新の料金は[公式の料金ページ](https://www.warp.dev/pricing)で確認してください。

### 自分のAPIキーを使う(BYOK)

料金ページによると、Freeプランでも**自分のAIの契約を持ち込めます**。OpenAI・Anthropic・Google のAPIキー、xAI の SuperGrok の契約、OpenAI 互換の接続先(OpenRouter・LiteLLM など)が挙がっています。APIキーは端末に保存されると説明されています。この使い方は、個人と従業員10人以下の組織が対象で、それより大きい組織は Business 以上が必要とされています。

## AIに送られるデータとプライバシー

ターミナルの内容をAIに渡すツールなので、仕事で使う前に確かめておきたい点です。公式の料金ページのよくある質問と、ドキュメントの「プライバシー」のページの記載を整理します。

| 項目 | 公式の記載の要旨 |
| --- | --- |
| AIの処理の仕組み | エージェントはコマンドを実行し、その出力を読んで次の手を決める。AIを使う場面では、指示とあわせて作業の内容がAIのモデル側で処理される |
| ゼロデータ保持(ZDR) | Anthropic・OpenAI・Google・xAI・Fireworks AI と契約を結んでおり、対象のモデルでは、提供元がWarp経由のデータを学習に使うことを防ぎ、指示と出力は一定期間内に消すことになっている |
| ZDRが効く範囲 | **Warpが用意するAIの利用分だけ。** 自分のAPIキーなどを使った場合は、自分の契約の条件で提供元に直接送られる |
| 個人でZDRにする方法 | Settings > Privacy で「Help improve Warp」を切る(料金ページのよくある質問) |
| Business・Enterprise | ZDRの契約の対象で、AIのやり取りやターミナルのデータは収集されない(プライバシーのページ)。管理者がメンバー全員にZDRを強制できる |
| 「Help improve Warp」が入っている場合 | AIのやり取りや、AI機能のための入力内容を収集することがある、と書かれている |
| 秘密情報の伏せ字 | 設定できる「Secret Redaction」(AIに送る前に一致する内容を伏せる)は、**初期状態では切れている** |
| 第三者の監査 | SOC 2 Type II の報告書を取得している |

注意したい点があります。プライバシーのページには「**Freeプランでは、AI機能を使うにはテレメトリ(利用データの送信)を有効にしておく必要がある**」とも書かれていて、料金ページのよくある質問(誰でも「Help improve Warp」を切ればZDRにできる)と書き方がそろっていません。Freeプランで、Warpが用意するAIを使いながら送信を切りたい場合は、使う前に設定画面と最新のドキュメントで確かめてください。

### AIを切ることはできる?

できます。公式ドキュメントには、AI機能は **Settings > Agents > Warp Agent** でまとめて無効にできると書かれています。また、提案を自動で出す「Active AI」や、普通の文章をAIへの指示として受け取る「入力の自動判定」も、それぞれ個別に切れます(メニューの名前は版によって違うことがあります)。

## 得意なこと

公式の説明から読み取れる、Warp が向いている作業です。

- 長い出力の中から、目的のコマンドの結果だけを探す・共有する(ブロック)
- うろ覚えのコマンドを、普通の文章で頼んで組み立ててもらう(エージェント)
- 承認しながら、複数の手順をエージェントに進めてもらう
- よく使うコマンドや手順書を保存し、チームで共有する(Warp Drive)
- Windows・Mac・Linux で同じターミナルを使う

## 過信は禁物な点

- **エージェントが出したコマンドは、実行前に必ず読む。** 削除・上書き・権限の変更を含むものは特に注意が要ります。公式も、実行前に承認を求める仕組みと、自動で進める範囲を決める設定を用意しています。
- **Freeプランだけでは、Warpが用意するAIは使い放題ではない。** 含まれる利用分はなく、使うなら購入か自分のAPIキーです。
- **AIの利用分はドル建てで、1回あたりの額は作業ごとに変わる。** 大きな作業やクラウドでの実行は多く使います。
- **秘密情報の伏せ字は初期状態では切れている。** パスワードやキーが画面に出る作業でAIを使うなら、設定を見直してください。
- **Windows はコマンドプロンプト(cmd.exe)非対応。** cmd 前提のバッチ作業が多い人は注意が必要です。

## 向いている人

- コマンドを毎回調べ直すのが負担で、普通の文章で頼みたい人
- エージェントに作業を任せつつ、1つずつ承認して進めたい人
- Windows・Mac・Linux をまたいで同じターミナルを使いたい人
- チームでコマンドや手順書を共有したい人(Warp Drive)

エディタの中でAIに書いてもらう道具が欲しいなら、[Cursor](/reviews/cursor-review/)や[GitHub Copilot](/reviews/github-copilot-review/)の方が目的に合います。種類ごとの違いは[AIコーディングツールの比較](/reviews/ai-coding-tools-comparison/)にまとめました。

## 使い方のコツ

1. AIを使う前に、Settings > Privacy の設定と、Secret Redaction の設定を確認する
2. エージェントの権限は、最初は「毎回承認する」側に寄せ、影響の小さい作業から任せる
3. 提案されたコマンドは、特にファイルの削除や設定の変更を含むものを、実行前に目で確かめる
4. AIが要らない作業では、設定からAI機能を切ってふつうのターミナルとして使う

## よくある質問

**Q. Windows で使えますか。**
使えます。公式ドキュメントでは、Windows 10 バージョン1903(ビルド18362)以降、Windows Server 2022以降が条件で、x86_64 と ARM64 に対応しています。シェルは PowerShell 7(標準)・PowerShell 5・WSL2・Git Bash で、コマンドプロンプト(cmd.exe)には対応していません。

**Q. 無料で使えますか。**
Freeプランは0ドルで、ターミナルの基本機能を使えます。ただし Warp が用意するAIの利用分は含まれておらず、使った分を買う(有料プランより20%高い)か、自分の OpenAI・Anthropic・Google の APIキーなどを持ち込む形です(料金ページ、2026年11月12日確認)。

**Q. ログインしないと使えませんか。**
公式ドキュメントでは、アカウントの登録は任意で、飛ばしてもよいと書かれています。料金ページのよくある質問では、プランの利用分を Warp Agent CLI で使うときは同じ Warp アカウントでサインインする、と説明されています。

**Q. ターミナルの内容はクラウドに送られますか。**
AIを使う場面では、指示と作業の内容がAIのモデル側で処理されます。Warp が用意するAIでは、提供元とゼロデータ保持の契約があり、学習に使わず一定期間で消す取り決めと説明されています。AI機能そのものは設定でまとめて切れます。細かい条件は「AIに送られるデータとプライバシー」の表を見てください。

**Q. zsh や bash、fish はそのまま使えますか。**
macOS と Linux では、bash・fish・zsh・PowerShell(pwsh)が対応シェルとして挙がっています。いま使っている設定ファイルやプラグインとの相性は環境によるため、公式ドキュメントの対応シェルのページで最新の情報を確認してください。

**Q. 料金は日本円で払えますか。**
確認した料金ページは米ドルの表示で、支払い方法はクレジットカードのみ(Stripe経由)と書かれています。日本円の金額は見当たりませんでした。

**Q. オープンソースになったのですか。**
2026年4月28日の公式発表で、アプリ本体のコードが公開されました。GitHub(warpdotdev/warp)の説明では、画面部品のライブラリが MIT ライセンス、それ以外が AGPL v3 です。AIの利用分や一部の機能は、引き続き Warp のサービス側で提供されています。
