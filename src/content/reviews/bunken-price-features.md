## この記事の結論

- 文賢のプランは**パーソナル(1名のみ)**と**ビジネスチーム(1名〜無制限)**の2つ。2026年5月19日に始まった新しい料金体系です。
- **パーソナルは月1,980円、1年更新なら月あたり1,650円。ビジネスチームは1ユーザー月3,300円、1年更新なら月あたり2,750円**(すべて税込)。1年更新は1か月更新より2か月分安くなると案内されています。
- **新プランの料金表と特定商取引法に基づく表示に、初期費用の項目はありません。**
- **どちらのプランにも14日間の無料トライアル**があり、期間中に解約すれば費用はかからないとされています。解約しなければ自動で本契約に移ります。
- できることは、**ルール校正(13項目)・ルール推敲(22項目)・AIアシスト・マスキング・辞書・ファイルのチェック**など。1回にチェックできるのは50,000文字までです。
- 動作環境は**PCのGoogle Chrome最新版**。スマートフォンやタブレットでは快適に使えないと公式ヘルプに書かれています。
- **解約しても次回更新日まで使え、日割りの返金はありません。** 利用規約では、支払い後の購入者都合の返金は受けないとされています。

この記事の料金と条件は、文賢の[公式サイト](https://rider-store.jp/bun-ken/)と[ヘルプセンター](https://help.bun-ken.net/)、[特定商取引法に基づく表示](https://help.bun-ken.net/law/)、[利用規約[新プラン]](https://help.bun-ken.net/terms_np/)を**2026年11月6日**に確認したものです。当サイトでは実機・実サービスを検証していません。公式の公開情報を整理した記事です。

### 初期費用について

新プランの料金表、ヘルプ、特定商取引法に基づく表示を見た範囲では、初期費用の項目はありませんでした。特商法の表示で「商品代金以外の必要な料金」に挙がっているのは、銀行振込の場合の振込手数料だけです。

なお、2026年5月18日以前に契約した「旧プラン」は料金体系が違い、公式の比較ページでは旧プランの月額は1ユーザー2,178円〜と書かれています([旧プラン・新プランの比較](https://help.bun-ken.net/old_new_comp/))。旧プランのライセンス購入は2026年8月31日19:00に終了したと公式サイトに書かれているため、これから申し込む人は新プランの料金で考えてください。

### プランを変えるとき

パーソナルからビジネスチームへの変更は即時に反映され、次回更新日までの差額が請求されます。逆にビジネスチームからパーソナルへの変更は予約となり、次回更新日から適用されます。ライセンスの追加と削減ができるのはビジネスチームだけです([ヘルプ「プランを変更したい」](https://help.bun-ken.net/change-plan/))。

## できること

公式サイトでは、主な機能が6つに分けて説明されています。

| 機能 | 公式の説明の要点 |
| --- | --- |
| ルール校正 | 日本語の誤りを正す機能で13項目。誤字脱字、誤った言葉、誤った敬語、重複表現、差別語・不快語、誤変換しやすい言葉など |
| ルール推敲 | 読みやすくする機能で22項目。一文が100文字以上、一文に読点が4つ以上、同じ文末表現の連続、冗長な表現、二重否定、表記揺れなど |
| AIアシスト | 誤字脱字・不自然な表現・表記揺れのチェック、読みやすく/フォーマルにリライト、類語の提案(最大15案)、タイトルの提案(30案)、要約など。独自のプロンプトをボタンとして登録できる |
| マスキング | 語句を伏せ字にした状態でAIアシストに送れる。キーワードの一括マスキングも可。個人情報の自動検出はビジネスチームのみ |
| 辞書とチーム共有 | 独自の表記ルールを登録。1つの辞書にルール校正・ルール推敲それぞれ5,000件まで。ビジネスチームでは辞書を共同編集できる |
| ファイルアップロード | Word(.docx)、Excel(.xlsx)、PowerPoint(.pptx)、PDF、TXTに対応。1ファイル50MBまで。旧形式(.doc等)は対象外 |

このほか、チェックリスト、3,500以上の文章表現の提案、文字数と漢字の使用率のカウント、音声読み上げ(0.5〜2.5倍速)、PDFでの保存・印刷があります。1回にチェックできる文字数は50,000文字までで、超える場合は分けて入れるよう案内されています([ヘルプ「お申し込み前の疑問を解決」](https://help.bun-ken.net/before_applying/))。

「推敲」「校閲」「アドバイス」と呼ばれる機能は、いまの公式サイトでは「ルール推敲」「ルール校正」「AIアシスト」の名前で説明されています。公式サイトには、校閲機能はあくまで支援で、文章中の誤りをすべてもれなく指摘するものではないとの注意書きがあります。

### AIアシストに送る文章の扱い

AIアシストはOpenAI社のAPIを使う機能で、初期設定はオフです。オーナーが許可しないと、ユーザーは使えません。公式の説明では、入力した文章はAIの学習に使われず、文賢のサーバーにも保存されません。ただし、AIアシストに送った文章は不正利用の監視のためOpenAI社のサーバーに30日間保管されると書かれています。[AIアシスト機能に関する追加利用規約](https://help.bun-ken.net/terms-ai-assist/)には、米国の裁判所命令により一部のデータがより長く保持される場合があることと、機密情報を送らないことも書かれています。

## 契約期間・支払い・解約

| 契約期間 | 1か月更新か1年更新(自動更新) |
| 支払い方法 | クレジットカード(1か月・1年)、銀行振込(1年のみ)。どちらもStripeを使う |
| 解約できる人 | オーナーのみ |
| 解約の手順 | 文賢にログイン→「プラン・お支払い」画面の下部「文賢を解約する」→「サブスクリプションを停止する」 |
| 解約後 | 次回更新日まで使える。日割りの返金はない |
| 休会 | 解約が適用された後の1年間は休会扱いで、いつでも再開できる。1年を過ぎるとデータは削除される |

参照:[ヘルプ「解約はどのようにすればいいですか?[新プラン]」](https://help.bun-ken.net/cancel_np/)、特定商取引法に基づく表示。解約の予約は、期限内なら「解約を取りやめる」から取り消せるとされています。利用規約[新プラン]では、支払い後の購入者都合による返金は「いかなる理由があってもお受けできません」とされているため、1年更新は続けるかどうかを決めてから選ぶと損が出にくくなります。

## 無料トライアル

[ヘルプ「無料トライアルはありますか?」](https://help.bun-ken.net/free_trial_np/)によると、仕組みは次のとおりです。

1. 期間は、アカウント登録とプラン選択が終わってから**14日間**。選んだプランのすべての機能を使える。
2. 終了の**3日前と1日前**にリマインドのメールが届く。
3. 期間中に解約の予約を入れれば、費用はかからない。
4. 解約しなければ、終了時点の契約内容で**自動的に本契約へ移る**。クレジットカード払いなら、終了と同時に初回の決済が行われる。
5. 過去に同じメールアドレスでトライアルを使った場合などは付与されない。

トライアル中に登録した辞書などのデータは、本契約にそのまま引き継げるとされています。

## よくある質問

### 文賢の料金はいくらですか。

パーソナルは1か月更新で月1,980円、1年更新で月あたり1,650円です。ビジネスチームは1ユーザーあたり1か月更新で月3,300円、1年更新で月あたり2,750円です。どれも税込で、2026年11月6日に公式で確認した金額です。

### 初期費用はかかりますか。

新プランの料金表と特定商取引法に基づく表示には、初期費用の項目はありません。商品代金のほかに必要な料金として挙がっているのは、銀行振込の場合の振込手数料です。

### 無料で使う方法はありますか。

無料プランはありませんが、新規の契約には14日間の無料トライアルが付きます。期間中に「文賢を解約する」から解約の予約を入れれば、費用はかからないとされています。解約しないと自動で本契約に移り、クレジットカード払いならその時点で初回の決済が行われます。

### 途中で解約したら返金されますか。

返金はありません。解約しても次回更新日までは使えますが、日割りの返金は行わないと公式ヘルプに書かれています。利用規約でも、支払い後の購入者都合の返金は受けないとされています。

### 1つの契約を何人かで使えますか。

使えません。1つのユーザーライセンスを複数人で使うことはできず、使う人数分のライセンスが必要とされています。複数人で使うならビジネスチームで人数分を契約し、辞書を共有する形になります。
