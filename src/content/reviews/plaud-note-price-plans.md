## この記事の結論

PLAUD(プラウド)の費用は、**本体の買い切り価格**と、**AI文字起こしのプラン料金**の2つで決まります。本体を買うと無料の「Starter」プラン(毎月300分の文字起こし)が使えるため、月額料金を払わなくても使い始められます。有料プランが要るかどうかは、**1か月に何分録音するか**でほぼ決まります。

| 1か月の録音時間の目安 | 合うプラン | 年額(税込) |
| --- | --- | --- |
| 300分以内(1時間の会議なら月5本程度) | Starter | 無料 |
| 300〜1,200分 | Pro | 16,800円 |
| 1,200分を超える | Unlimited | 40,000円 |

この記事の価格・仕様は、PLAUDの日本公式ストア(jp.plaud.ai)の表示を**2026年10月21日**に確認し、**2026年11月3日**に再確認したものです(本体・プラン・文字起こしパッケージの価格に変更はありませんでした)。セールや改定で変わることがあるため、購入前に公式ストアで最新の表示を確かめてください。当サイトは実機を使った検証はしていません。公式の公開情報を整理した記事です。

## 本体4機種の価格と仕様

公式ストアで販売されている本体は4機種です(価格は税込・通常価格)。

| | Plaud Note Pro | Plaud Note | Plaud NotePin S | Plaud NotePin |
| --- | --- | --- | --- | --- |
| 価格 | 30,800円 | 27,500円 | 28,600円 | 27,500円 |
| 形 | カード型 | カード型 | ピン型(身につける) | ピン型(身につける) |
| 大きさ | 85.6×54.1×2.99mm | 85.6×54.1×2.99mm | 51×21×11mm | 51×21×11mm |
| 重さ | 30g | 30g | 17.4g(マグネットピンなし) | 16.6g |
| マイク | MEMS×4、VPU×1 | MEMS×2、VPU×1 | MEMS×2 | MEMS×2 |
| 最適な録音範囲 | 5mまで | 3mまで | 3mまで | 3mまで |
| 保存容量 | 64GB | 64GB | 64GB | 64GB |

公式ページに書かれている主な違いは次のとおりです。

- **Plaud Note Pro**:マイクが4基で、最大5m先の声まで拾えるとされています。対面の会話と通話を自動で判別して記録する「スマートデュアルモード」を備え、連続録音は最大30時間(音声強化モード)、長時間駆動モードでは最大50時間とされています。MagSafe対応ケースが付属します。
- **Plaud Note**:Proと同じ大きさのカード型で、マイクは2基、最適な録音範囲は3mです。MagSafe対応ケースに入れてスマートフォンの背面に付けると、通話を録音できると説明されています。
- **Plaud NotePin S**:身につけて使うピン型です。マグネットピン、クリップ、ネックストラップ、リストバンド、充電ドックが同梱されています。ボタンの長押しで録音を始め、短押しで重要な場面に印(ハイライト)を付けられます。
- **Plaud NotePin**:ピン型の先行モデルです。公式ページでは、連続録音20時間・待機40日とされています。

2026年11月3日時点の公式ストアでは、Note Pro の商品ページで「**Plaud Note Pro Flow Edition**」(29,700円)も選べます。公式のFAQによると、4基のマイクの収音性能が Note Pro より上がっている一方、本体ストレージはアプリへの自動転送を前提とした一時保存用の512MB(標準の録音品質で約30時間分)です。自動転送は現時点で iPhone のみ対応(Android は今後対応予定)とされ、その他の機能・仕様は Note Pro と共通です。

なお、NotePin S とピン型の付属品には磁石が使われているため、公式ページでは心臓ペースメーカーを使っている人に対し、胸の近くに着けないよう注意が書かれています。

### どの機種を選ぶか

- **会議室で離れた席の声まで録りたい** → マイクが多く録音範囲が5mの Note Pro
- **主にスマートフォンの通話を録りたい** → MagSafeでスマートフォンに付けられるカード型(Note Pro / Note)
- **外出先や立ち話で、身につけたまま録りたい** → ピン型(NotePin S / NotePin)
- **費用を抑えたい** → 27,500円の Note または NotePin

どの機種でも文字起こしと要約は同じクラウドのサービス(Plaud Intelligence)で行われ、プランの内容は機種によって変わりません。

本体価格とプラン料金を足した金額です(税込・2026年10月21日の通常価格で計算し、11月3日に価格の変更がないことを確認。セット割引やセールは含めていません)。

| 組み合わせ | 1年目 | 2年目以降(毎年) |
| --- | --- | --- |
| Note または NotePin + Starter | 27,500円 | 0円 |
| Note Pro + Starter | 30,800円 | 0円 |

Starter で足りるか分からない場合は、まず Starter で1〜2か月使い、毎月の録音時間を見てからプランを決めるのが無駄の少ない順番です。月に数回だけ300分を超える程度なら、Pro を年額で買うより、600分パッケージ(2,000円)を足す方が安く済むことがあります。

## どこで買う?公式ストア・Amazon・楽天の違い(返品・保証・法人購入)

### 公式ストアで買う場合

- **30日間の返品保証。** 公式の「Plaud安心購入サービス」では、公式ストアで買った場合、30日以内なら理由を問わず返品を受け付けるとしています。返品・返金ポリシーの条件は、製品一式(本体と同梱の付属品)を元の状態でそろえて返すことです。同梱の付属品だけを返すことはできず、人為的な破損や付属品の欠品、箱の著しい破損があると、返金額の一部が差し引かれる場合があります。
- **手続き。** 返品の前にアプリでデバイスの接続解除と紐付け解除を行い、注文番号とシリアル番号を添えて support-jp@plaud.ai に連絡します。返品された商品の検品後、5〜10営業日以内に元の支払い方法へ返金されるとされています。
- **年間プランと文字起こしパッケージ。** 購入から30日以内で、未使用・未アクティベートなら通常は全額返金の対象です。一度でも利用を始めた場合は返金できません。
- **製品保証。** 販売領収書の発行日から12か月の修理保証があり、申請にはシリアル番号と購入証明が必要です。落下・水濡れなど外からの力による損傷、無断の分解、紛失、Note Pro のディスプレイの物理的な破損などは対象外とされています。
- **支払い方法。** クレジットカード・デビットカード、PayPal、Shop Pay、銀行振込、コンビニ決済、Paidy が使えます。
- **公式ストア限定の特典。** 「Plaudポイント」は公式ストアでだけ使えるポイントで、購入額(税抜)の1%分が付き、会員登録で100円相当がもらえます(100ポイント=1円相当)。本体と年間プランのセット商品も公式ストアで販売されています。

### Amazon・楽天など、公式ストア以外で買う場合

- **返品はPLAUDではなく購入先の規定になる。** PLAUDの返品・返金ポリシーには、上記の条件は公式サイトで買った人だけに適用され、公式サイト以外の販売店(ECサイト・実店舗)で買った場合は購入先の販売店のポリシーに従うこと、代理店・販売店を経由した取引の返品・返金にはPLAUDは対応していないことが書かれています。30日間の返品保証を含む「Plaud安心購入サービス」も、公式ストアで買った場合だけが対象です。
- **楽天の「Plaud 楽天市場店」の場合。** 会社概要の表示では、お客様都合の返品は商品到着後8日以内の連絡で新品未開封のものに限られ、返送料はお客様負担です。初期不良や注文と違う商品が届いた場合は、到着後2週間以内の連絡で全額返金(送料は店舗負担)とされています。
- **Amazonの場合。** 返品の条件はAmazonの商品ページと返品規定で確認してください。当サイトではAmazon側の条件は確認していません。
- **製品保証。** 公式の保証ポリシーは「販売領収書の発行日から12か月」「申請にはシリアル番号と購入証明が必要」としており、購入先を公式ストアに限るという記載は、確認したページには見当たりませんでした。一方で、公式ヘルプセンターのFAQは「公式ストアで購入したデバイスの保証期間」として12か月と書いているだけで、Amazon・楽天で買った場合の扱いをはっきり書いたページは見つかりませんでした。公式ストア以外で買う場合は、注文履歴や領収書を保管し、保証の窓口を購入先とPLAUDのサポートに確認しておくと確実です。
- **非正規品と中古品に注意。** 公式サイトは、公式より安い価格で認定店舗以外で売られている製品は非正規品によく見られる特徴だとし、非正規品はアカウントを利用停止される場合があると注意しています。また、本体はアカウントとの紐付けが必要で、前の持ち主が紐付けを解除しないと別のアカウントでは使えず、中古市場で買った製品はサポートの対象外とされています。

### 法人で買う場合

- **まとめ買い。** 公式の「チーム向けに、デバイスを購入」ページから、同じ製品を複数台、または違う製品をまとめて1回の注文で買えます。まとめ買いの割引は、法人営業への問い合わせ(法人様のお問い合わせフォーム)が案内されています。
- **Plaud Team。** チーム全体の請求・ユーザー・デバイスをまとめて管理できる組織向けのプランです。公式ページには「現時点では、請求書払い(後払い)には対応しておりません」と書かれています。無料トライアルはなく、SSO は Google・Apple のアカウントによるログインに対応し、SAML・Okta・Microsoft Entra ID などのエンタープライズSSOには対応していないとされています。
- **本体の請求書払いと適格請求書。** 公式ストアの支払い方法には銀行振込やコンビニ決済がありますが、本体を請求書払い(掛け払い)で買えるかどうか、公式ストアの領収書が適格請求書(インボイス制度)の要件を満たすかどうかは、確認したページには書かれていませんでした。経理上必要な場合は、購入前に法人営業へ確認してください。なお、アプリ内課金(App Store・Google Play)で買ったプランの請求書はPLAUDでは発行しておらず、各ストアで確認する形です。

### 条件別の選び方

- **合わなかったときに返品できる安心を重視する** → 公式ストア。開封後でも30日以内ならお客様都合で返品できます(送料は自己負担、付属品と箱がそろっていることが条件)。
- **普段使っているAmazon・楽天のポイントや支払い方法を使いたい** → 公式サイトが正規店舗として挙げている店舗で買う。返品の条件は店舗ごとに違い、楽天の「Plaud 楽天市場店」ではお客様都合の返品は新品未開封のものに限られます。
- **会社で複数台をそろえたい** → 公式のまとめ買いページか法人営業へ。請求書払いや適格請求書が必要なら、購入前に対応できるかを確認します。
- **価格** → どの販売先もセールで価格が変わります。買う直前に各販売先の表示を比べ、認定店舗以外の極端に安い出品は避けてください。

ほかの会社のカード型の録音機と比べてから決めたい場合は、本体価格・無料の文字起こし時間・返品の条件を並べた[Notta MemoとPLAUD Noteの違い](/reviews/notta-memo-vs-plaud-note/)も参考にしてください。HiDock・Anker Soundcore Work・オートメモまで含めた比較は[AIボイスレコーダーの比較](/reviews/ai-voice-recorder-comparison/)にまとめました。

## よくある質問

**Q. 月額料金を払わないと使えませんか。**
払わなくても使えます。本体を買うと無料の Starter プランで毎月300分まで文字起こしできます。それを超えて使う場合に、Pro・Unlimited のプランか、文字起こしパッケージを買う形です。

**Q. Pro プランは月払いできますか。**
公式ストアでは、Pro(16,800円)と Unlimited(40,000円)は年額のアクティベーションコードとして販売されています。プラン表の「月額」は年額一括払いを月割りにした金額です。アプリ内など別の購入方法の条件は、購入前に公式の案内を確認してください。

**Q. 機種によって文字起こしの精度やプランは変わりますか。**
プランの内容(時間・言語数・要約機能)は機種で変わりません。差が出るのは録音の段階で、マイクの数と録音範囲が違います。離れた席の声まで録りたいならマイクが4基の Note Pro が向いています。

**Q. 文字起こしの時間を使い切ったらどうなりますか。**
その月の残りは、文字起こしパッケージ(600分2,000円から)を追加するか、翌月に時間が付与されるのを待つことになります。プランの時間が先に使われ、パッケージの時間はその後に使われます。

**Q. 公式ストアで買ったPLAUDは、開封した後でも返品できますか。**
できます。公式ストアで買った場合、商品の受け取りから30日以内なら理由を問わず返品でき、全額返金の対象です。ただし本体と付属品・取扱説明書・元の箱がそろっていることが条件で、製品の不具合以外の理由なら返送料は自己負担です。人為的な破損や欠品があると、返金額の一部が差し引かれる場合があります。

**Q. Amazonや楽天で買っても保証は受けられますか。**
公式の保証ポリシーは「販売領収書の発行日から12か月」で、申請にはシリアル番号と購入証明が必要としています。購入先を公式ストアに限る記載は確認したページにはありませんでしたが、Amazon・楽天で買った場合の扱いをはっきり書いたページも見つかりませんでした。返品はPLAUDではなく購入先の規定になると明記されているので、購入先の条件を確かめ、注文履歴や領収書を保管しておいてください。中古品はサポートの対象外とされています。

**Q. 法人で請求書払いにできますか。**
組織向けの Plaud Team は、公式ページで「現時点では、請求書払い(後払い)には対応しておりません」とされています。本体を請求書払いで買えるかどうかは確認したページには書かれていなかったため、まとめ買いの割引とあわせて、公式の法人営業(法人様のお問い合わせ)に確認してください。公式ストアの支払い方法には、銀行振込やコンビニ決済もあります。
