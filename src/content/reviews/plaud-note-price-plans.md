## この記事の結論

PLAUD(プラウド)の費用は、**本体の買い切り価格**と、**AI文字起こしのプラン料金**の2つで決まります。本体を買うと無料の「Starter」プラン(毎月300分の文字起こし)が使えるため、月額料金を払わなくても使い始められます。有料プランが要るかどうかは、**1か月に何分録音するか**でほぼ決まります。

| 1か月の録音時間の目安 | 合うプラン | 年額(税込) |
| --- | --- | --- |
| 300分以内(1時間の会議なら月5本程度) | Starter | 無料 |
| 300〜1,200分 | Pro | 16,800円 |
| 1,200分を超える | Unlimited | 40,000円 |

本体は、**カード型の Note Pro(30,800円)・Note(27,500円)と、ピン型の NotePin S(28,600円)・NotePin(27,500円)の4機種**です(税込)。機種選びの最初の分かれ目は**通話を録るかどうか**で、通話の録音モードがあるのはカード型の2機種だけです。文字起こしと要約のプランは機種で変わりません。

この記事の価格は、PLAUDの日本公式ストア(jp.plaud.ai)の表示を**2026年10月21日**に確認し、**2026年11月3日**と**2026年11月12日**に再確認したものです(本体・プラン・文字起こしパッケージの価格に変更はありませんでした)。機種ごとの仕様は、公式の比較ページと各機種の商品ページを**2026年11月5日**に確認しました。セールや改定で変わることがあるため、購入前に公式ストアで最新の表示を確かめてください。当サイトは実機を使った検証はしていません。録音の聞き取りやすさや文字起こしの精度は測っておらず、公式の公開情報を整理した記事です。

## 機種の違いと選び方

### まず「通話を録るか」で分ける

公式の説明では、カード型の Note Pro と Note は、MagSafe対応のマグネットケースに入れてスマートフォンの背面に付けて使うか、単体で持ち歩いて使う形です。スマートフォンに付けると通話を録音できると説明されています。カード型には MEMS マイクとは別に VPU が1基あり、Note Pro のFAQではこれを「骨伝導センサー(VPU)」と説明しています。ピン型には VPU がなく、NotePin S のFAQには、振動伝導センサーを搭載していないため通話録音に対応していないと書かれています。比較表でもピン型の録音モードは「対面録音モードのみ」です。

- **電話の内容も残したい** → カード型(Note Pro か Note)
- **対面の会話だけでよく、身につけて録りたい** → ピン型(NotePin S か NotePin)

ピン型は、マグネットピン・クリップ・ネックストラップ・リストバンドの4種類の付け方が案内されています。ただし NotePin の同梱品はマグネットピン・クリップ・充電ドック・ケーブルで、リストバンドとネックストラップが最初から入っているのは NotePin S です。

### Note Pro と Note の違い(カード型)

大きさと重さ(30g)は同じで、違いは中身です。価格差は3,300円です。

| 違うところ | Note Pro | Note |
| --- | --- | --- |
| マイクと収音範囲 | 4基・最大5m | 2基・最大3m |
| 通話と対面の切り替え | 自動 | 手動 |
| 画面 | 0.95インチのAMOLED(Note Pro のページでは600ニト) | なし |
| 録音時間 | 最大30時間(音声強化モード)、長時間駆動モードで最大50時間 | 最大30時間 |
| 無線 | BLE 5.4、2.4GHzと5GHzのWi-Fi | BLE 5.2、2.4GHzのWi-Fi |
| Apple「探す」 | あり | なし |
| 価格 | 30,800円 | 27,500円 |

**会議室で離れた席の声まで録りたい**、**通話と対面をいちいち切り替えたくない**、**録音中かどうかを画面で確かめたい**、のどれかに当てはまるなら Note Pro、どれも要らないなら Note、と分けると迷いにくくなります。

### Note Pro Flow Edition

2026年11月3日・5日・12日に確認した公式ストアでは、Note Pro の商品ページで「**Plaud Note Pro Flow Edition**」(29,700円・ブラックとシルバー)も選べます。公式のFAQでは、通常の Note Pro との違いを次の2点としています(11月5日確認)。

- **収音**:AI指向性収音技術を搭載した、S/N比68dBのMEMSマイクを4基搭載し、収音性能が Note Pro より上がっている
- **保存容量**:512MBで、データを転送するまでの一時保存用。標準の録音品質で約30時間分を保存でき、録音が終わるごとにアプリへ自動転送される

自動転送は Plaud App の設定で有効にする必要があり、現時点では iPhone のみ対応(Android は今後対応予定)と注記されています。その他の機能・仕様は Note Pro と共通とされ、充電端子は USB-C と書かれています。

本体の中に録音をためておきたい人や、Android のスマートフォンを使う人は、64GBの通常の Note Pro の方が条件に合います。iPhone を使っていて、録音を本体に残すよりアプリに自動で送りたい人向けの型です。

### NotePin S と NotePin の違い(ピン型)

大きさ(51×21×11mm)、マイク(2基)、収音範囲(3m)、連続録音(最長20時間)、待機(40日)は同じです。価格差は1,100円です。

| 違うところ | NotePin S | NotePin |
| --- | --- | --- |
| 録音ボタン | 物理ボタン(長押しで録音開始) | 感圧ボタン |
| ハイライト | 短押しで付ける | アイコンのタップで付ける |
| 電池 | 320mAh | 270mAh |
| 重さ(マグネットピンなし) | 17.4g | 16.6g |
| 同梱品 | リストバンドとネックストラップも入る | マグネットピン・クリップ・充電ドック・ケーブル |
| 価格 | 28,600円 | 27,500円 |

どちらもハイライトは付けられます。**物理ボタンで操作したい、付け方を最初から全部そろえたい**なら NotePin S、**少しでも安くしたい**なら NotePin です。NotePin は NotePin S より前に出たモデルで、公式の比較表の上では録音時間は同じです。

ピン型のマグネットピンとクリップには磁石が使われています。NotePin S のFAQでは、最大2,100ガウスの磁場を生じるとして、心臓ペースメーカーを使っている人は、ネックストラップ・マグネットピン・クリップのいずれでも胸部に着けないよう書かれています。NotePin の商品ページにも同じ趣旨の注意があります。

### まだ買えない Plaud One

公式ストアには、イヤホンと充電ケースが同梱される会話型ウェアラブルAI「[Plaud One](https://jp.plaud.ai/products/plaud-one)」(販売価格44,000円・税込)のページもあります。2026年11月5日時点では「日本での販売は現在準備中です」と表示され、11月12日時点でもボタンは「ウェイトリストに登録」で、購入はできない表示です。この記事の比較と試算には含めていません。

公式ページの仕様では(11月5日確認)、イヤホンに MEMS マイク3基と VPU 1基(各イヤホン)、ケースに MEMS マイク4基を備え、収音範囲はイヤホンが最大2m、ケースが最大5mです。連続録音はイヤホンで最大3.5時間、ケースで最大25時間、スタンバイは最大14日間です。ケースには契約不要の eSIM が入り、4G LTE で録音のアップロードやAI機能を使えると説明されています。一部の機能はベータ版や今後の更新で提供されると注記されているため、発売時の条件を見てから比べるのが確実です。

### 4機種で同じところ

- **文字起こしと要約のプラン**:どの機種でも文字起こしと要約は同じクラウドのサービス(Plaud Intelligence)で行われ、プランの内容は機種によって変わりません。本体を買うと無料の Starter プラン(毎月300分)が付きます。プランの違いは次の「文字起こしプランの違い」の節にまとめました。
- **製品保証**:シリーズ比較ページには、1年間の製品保証について「保証期間はご利用の地域における基準に準じます」と注記されています(11月5日確認)。
- **データの扱い**:保存先や暗号化は機種ではなくサービス側の仕組みです。会社で使う場合の確認点は[PLAUDを会社で使うときのセキュリティ](/reviews/plaud-note-business-security/)にまとめました。

## 買う前に確かめておきたいこと

1. **オンライン会議が中心かどうか。** 会議の大半が Zoom や Teams なら、会議ツール側の文字起こし機能で足りる場合があります。PLAUD が向くのは、対面の打ち合わせや通話など、オンライン会議の外で話す場面です。違いは[AIボイスレコーダーと会議の文字起こしAIの違い](/reviews/ai-voice-recorder-vs-meeting-transcription/)にまとめました。
2. **録音してよい場面か。** 公式ストアにも、録音の前に参加者へ伝えて同意を得るよう書かれています。社内ルールや取引先との取り決めも確認してください。考え方は[AI議事録の録音同意ガイド](/reviews/ai-meeting-recording-consent-guide/)で整理しています。
3. **返品と保証。** 公式ストアの表示では、30日間の返品保証(お客様都合でも全額返金可能)と1年間の製品保証が付いています。ただし返品の条件は買う場所によって変わるため、次の章で整理しました。

## よくある質問

**Q. 月額料金を払わないと使えませんか。**
払わなくても使えます。本体を買うと無料の Starter プランで毎月300分まで文字起こしできます。それを超えて使う場合に、Pro・Unlimited のプランか、文字起こしパッケージを買う形です。

**Q. Pro プランは月払いできますか。**
できます。公式のプラン料金ページでは、月払いは Pro が月3,000円、Unlimited が月5,000円です(2026年11月5日確認)。1年続けるなら年額(Pro 16,800円・Unlimited 40,000円)の方が安く、Pro なら月払い12か月の36,000円より19,200円少なくなります。

**Q. 機種によって文字起こしの精度やプランは変わりますか。**
プランの内容(時間・言語数・要約機能)は機種で変わりません。差が出るのは録音の段階で、マイクの数・収音範囲・通話を録れるかどうかが機種で違います。文字起こしの精度を機種ごとに比べた公式の数値は、確認したページには載っていませんでした。離れた席の声まで録りたいならマイクが4基の Note Pro が向いています。

**Q. Plaud Note Pro と Plaud Note の違いは何ですか。**
公式の比較表では、Note Pro はマイクが4基で収音範囲が最大5m、通話と対面を自動で切り替え、AMOLEDディスプレイと Apple「探す」に対応し、長時間駆動モードで最大50時間録音できます。Note はマイク2基・最大3mで、通話と対面は手動で切り替えます。大きさと重さは同じで、価格差は3,300円です(2026年11月5日確認)。

**Q. NotePin で電話の録音はできますか。**
公式の比較表では、NotePin S と NotePin の録音モードは「対面録音モードのみ」とされ、NotePin S のFAQにも通話録音に対応していないと書かれています。電話の内容も残したい場合は、通話の録音モードがあるカード型の Note Pro か Note を選びます。

**Q. NotePin S と NotePin の違いは何ですか。**
公式の情報では、NotePin S は物理ボタンで、短押しでハイライトを付けられ、電池は320mAhです。NotePin は感圧ボタンで、ハイライトはアイコンのタップで付け、電池は270mAhです。連続録音(最長20時間)・待機(40日)・マイク・大きさ・保存容量(64GB)は同じで、NotePin S にはリストバンドとネックストラップも同梱されています。価格差は1,100円です。

**Q. Note Pro Flow Edition は通常の Note Pro と何が違いますか。**
公式のFAQでは、S/N比68dBのマイク4基で収音性能が上がっている一方、本体の保存容量は一時保存用の512MB(標準の録音品質で約30時間分)で、録音ごとにアプリへ自動転送する型と説明されています。自動転送は現時点で iPhone のみ対応です。価格は29,700円で、通常の Note Pro(30,800円・64GB)より1,100円安い表示です。

**Q. 文字起こしの時間を使い切ったらどうなりますか。**
その月の残りは、文字起こしパッケージ(600分2,000円から)を追加するか、翌月に時間が付与されるのを待つことになります。プランの時間が先に使われ、パッケージの時間はその後に使われます。

**Q. 公式ストアで買ったPLAUDは、開封した後でも返品できますか。**
できます。公式ストアで買った場合、商品の受け取りから30日以内なら理由を問わず返品でき、全額返金の対象です。ただし本体と付属品・取扱説明書・元の箱がそろっていることが条件で、製品の不具合以外の理由なら返送料は自己負担です。人為的な破損や欠品があると、返金額の一部が差し引かれる場合があります。

**Q. Amazonや楽天で買っても保証は受けられますか。**
公式の保証ポリシーは「販売領収書の発行日から12か月」で、申請にはシリアル番号と購入証明が必要としています。購入先を公式ストアに限る記載は確認したページにはありませんでしたが、Amazon・楽天で買った場合の扱いをはっきり書いたページも見つかりませんでした。返品はPLAUDではなく購入先の規定になると明記されているので、購入先の条件を確かめ、注文履歴や領収書を保管しておいてください。中古品はサポートの対象外とされています。
