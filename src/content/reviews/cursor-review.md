## この記事の結論

- Cursor の個人向けプランは Free(0ドル)・Plus(月8ドル)・Premium(月30ドル)・Super(月100ドル)・Ultra(月200ドル)。チーム向けの Teams は1人月30ドルから(2026年11月22日に公式の料金ページで確認。11月3日から変更なし)
- **Plus で使えるモデルは Grok だけ**。Premium 以上でも、利用枠に含まれるのは Grok のモデルで、他社のモデルは API の定価で使った分だけ別に請求される
- 利用枠は Cursor と Grok で共通で、**毎週リセット**される
- 表示価格は**税抜**。サブスクリプションの販売元は X Subscription Corp.(米国)で、税の計算と徴収もこの会社が行うと利用規約に書かれている

- 公式ブログによると、開発元の Anysphere は **2026年8月14日に SpaceX に買収された**

この記事は、Cursor の公式サイト(料金ページ・ブログ・データの扱いのページ・ドキュメント)と、販売元の利用規約を2026年11月22日に確認してまとめたものです。当サイトでは Cursor を操作して確かめてはいません。

## Cursorとは

Cursor は、VS Code のコードベースをもとに作られたコードエディタです。チャットで相談しながらコードを直す機能と、複数のファイルにまたがる変更をまとめて行うエージェント機能が組み込まれています。対応OSは macOS・Windows・Linux です。

2026年8月以降、Cursor は製品の位置づけが大きく変わりました。料金ページのプランには、Cursor の機能と並んで xAI の Grok(Chat・Voice・Imagine・Build・API)や、X(旧Twitter)の認証マーク・広告の削減といった特典が並んでいます。エディタだけを使いたい人にとっては、料金の中に Cursor 以外のサービスが含まれる形になっています。

## 日本の消費税・インボイス

- 料金ページのよくある質問には「すべての価格は税抜きで、適用される税金は別途加算されます」と書かれています(2026年11月22日確認)。
- 販売元の[利用規約](https://x.ai/legal/bundled-subscription-terms)(2026年10月7日更新)では、X Subscription Corp. が販売者(merchant of record)となり、売上税・VAT・GST などの取引税を、アカウントの情報にもとづいて計算・徴収・納付すると書かれています。また、カード手数料・海外取引手数料・為替の変動による差額も利用者の負担と書かれています。
- **日本の消費税(10%)が上乗せされるかどうか、適格請求書(インボイス)を発行するか、日本の登録番号は、確認したページに書かれていませんでした。** 法人で仕入税額控除を受けたい場合は、契約前に販売元へ問い合わせるか、最初の請求書の表示を確かめてください。
- 他社モデルの従量分など「追加購入(Top-Ups)」は、販売者が Anysphere, Inc. になると利用規約に書かれています。月額と従量分で請求元が分かれる点は、経理の処理で注意が要ります。

## 公式の説明から分かる注意点

- **料金に Cursor 以外のサービスが含まれる**: Premium 認証マークやタイムラインの広告削減など、X の機能がプランの一覧に並んでいます。エディタだけが目的なら、その分を含めた月額で比べる必要があります。
- **他社モデルは月額とは別**: Premium 以上の利用枠は Grok のモデル向けです。Claude や GPT を中心に使うと、月額のほかに従量の請求が発生します。
- **購入先は公式サイトだけ**: 料金ページのよくある質問では、販売代理店や第三者からの購入は認めておらず、そうしたアカウントは利用停止の対象になりうると書かれています。
- **プライバシーモードの確認**: オフのままだと、コードやプロンプトが AI 機能の改善や学習に使われることがあるとデータの扱いのページに書かれています。
- **拡張機能**: Open VSX にない拡張機能もあります。公式ドキュメントでは、同じ ID でも Open VSX と Microsoft の Marketplace で発行元や中身が違う場合があるとして、信頼できる発行元から入れるよう案内しています。

確認したページに見当たらなかった事項と、各自で確かめる方法です。

- **プライバシーモードの既定値**(最初からオンかオフか): Free で登録した直後に、設定画面のプライバシーの項目を開くと確かめられます。
- **エディタの画面を日本語にできるか**: 公式サイトとドキュメントは日本語で表示されますが、エディタの表示言語については確認したページに記載がありませんでした。Free で入れて、表示言語の設定を見るのが確実です。
- **Free の具体的な回数**: 「制限あり」とだけ書かれ、回数は書かれていません。残りの利用枠は設定画面でいつでも確認できると料金ページに書かれているので、Free で登録して設定画面の表示を見てください。
- **日本の消費税・適格請求書**: 上の節のとおり、確認したページには書かれていませんでした。
- **買収後の今後の料金**: 利用規約には、価格を変更する場合は合理的な事前の通知をし、次の契約期間から適用すると書かれています。将来の具体的な改定の予定は書かれていません。

## よくある質問

**Q. VS Codeの拡張機能や設定は引き継げますか。**
公式ドキュメントによると、Cursor の設定(General > Account)にある「VS Code Import」から、拡張機能・テーマ・設定・キーバインドを一度に取り込めます。ただし拡張機能は Open VSX から入れる仕組みで、Microsoft の Marketplace にあるものがすべて揃っているわけではないとドキュメントに書かれています。普段使っている拡張機能が Open VSX にあるかを先に確かめてください(2026年11月22日確認)。

**Q. GitHub Copilotとどちらを選ぶべきですか。**
既存のエディタに補完を足したいなら Copilot、エディタごと乗り換えてエージェント機能を中心に使いたいなら Cursor が候補です。Cursor は他社モデルの利用が月額と別料金になる点も含めて比べてください。詳しくは[コーディング支援AIの比較](/reviews/ai-coding-tools-comparison/)を参照してください。

**Q. 会社のコードを扱っても大丈夫ですか。**
公式のデータの扱いのページによると、プライバシーモードを有効にするとコードのデータは Cursor やモデル提供元の学習に使われず、提供元とはデータを保存しない契約(ZDR)を結んでいるとされています。オフの場合は学習に使われることがあります。既定値は確認したページに書かれていなかったため、導入時に設定画面で確かめ、社内規程とあわせて判断してください。

**Q. 途中で解約したら返金されますか。**
販売元の利用規約では、支払いは確定で返金されず、使い残した期間の返金もないとされています(法律で求められる場合などを除く)。解約しても期間の終わりまでは使えます。次の請求を止めるには、更新の24時間前までに解約してください(2026年11月22日確認)。
