## 総評

この記事の料金・機能は公式サイトの記載を2026年11月3日に確認したものです。当サイトで実際に使った検証はしていません。

CursorはVS Codeをベースにフォークされたコードエディタで、チャットによる対話型編集と、複数ファイルにまたがる自動修正を行うエージェント機能を標準搭載しているのが最大の特徴です。単なる補完ツールというより「AIと一緒にコードベースを操作する」体験に寄せて設計されており、既存のVS Code資産(拡張機能・設定・キーバインド)を取り込む機能がある点も移行のハードルを下げています。対応OSはmacOS・Windows・Linuxです。

なお、公式ブログ(2026年8月14日)によると、Cursorを開発するAnysphereはSpaceXに買収されました。料金ページも、xAIのGrokと共通の利用枠を持つプランに変わっています(下の「料金」を参照)。

## 得意なこと

- チャットでファイルやプロジェクト全体を参照させながらの実装相談・修正
- エージェントモードによる複数ファイル横断のリファクタリングや機能追加
- 既存コードベースの構造や意図を自然言語で質問して把握する作業
- VS Codeの拡張機能・テーマ・設定・キーバインドを取り込める移行のしやすさ(拡張機能はVS Code MarketplaceではなくOpen VSXから入れる仕組み)

## 過信は禁物な点

- エージェントが自動で行った変更は、差分を必ず自分の目で確認してからマージすべき
- 大規模な既存コードベースでは、意図しない箇所まで書き換えられることがある
- セキュリティや認証まわりのコードは、AI生成のまま採用せず人間によるレビューを必須にする
- 生成結果はプロジェクト固有の設計方針を理解しているとは限らず、指示が曖昧だと的外れな修正になりやすい

## 向いている人

- VS Codeに慣れていて、移行コストを抑えつつAI機能を試したい人
- 一人称視点でコードベース全体を素早く把握・修正したい個人開発者やスタートアップ
- チャットで設計意図を説明しながらコードを育てていくスタイルが合う人

## 導入のコツ

1. 最初は小さめのリポジトリやサイドプロジェクトでエージェント機能の挙動を試す
2. 重要な変更はブランチを切り、コミット単位で差分を追える状態で使う
3. チーム導入時は「AIが変更した箇所」をレビュー観点に明記したルールを決めておく

## 料金(2026年11月3日確認)

公式の料金ページ(個人向け)の表示です。料金は米ドルの月額で、税金は含まれていません。確認したページに年払いの料金は表示されていませんでした。

| プラン | 月額 | AIの利用枠 | 主な内容 |
| --- | --- | --- | --- |
| Free | 0ドル | 制限あり | エージェントとチャットのリクエスト数に制限あり |
| Plus | 8ドル | 共有の利用枠 | Cursor、Grok(Chat・Voice・Imagine・Build)、Grok API。**使えるモデルはGrokのみ** |
| Premium | 30ドル | Plusの4倍 | 最新のGrokモデル、クラウドエージェントと自動化、AIコードレビュー。他社モデルはAPIの定価で別料金 |
| Super | 100ドル | Plusの15倍 | Premiumの内容に加え、混雑時のモデル優先アクセス |
| Ultra | 200ドル | Plusの50倍 | Superの内容に加え、すべての製品・モデルへの最優先アクセス |
| Teams | 1人30ドル〜 | チームで共有 | 一括請求、利用状況の分析、SSOなど |

料金ページのよくある質問によると、利用枠はCursorとGrokで共通で、**毎週リセット**されます。Premium以上の利用枠はGrokのモデル向けで、**他社のモデルはCursorで使えるものの、利用枠には含まれず、APIの定価で使った分だけ別に請求**されます(上限額は設定できます)。また、プランにはXの認証マークや広告の削減といった、Cursor以外のサービスの特典も並んでおり、購入はX Subscription Corp.からの直接販売に限られると書かれています。

Grok以外のモデルを主に使う予定なら、月額とは別にかかる従量の料金を[AI API料金計算ツール](/tools/ai-api-cost-calculator/)で想定利用量から試算しておくと導入判断がしやすくなります。

料金プランや機能の詳細は変更される可能性があるため、[公式の料金ページ](https://cursor.com/pricing)で最新情報を確認してください。

## よくある質問

**Q. VS Codeの拡張機能や設定は引き継げますか。**
公式ヘルプによると、設定画面の「VS Code Import」から拡張機能・テーマ・設定・キーバインドを一度に取り込めます。既定のショートカットもVS Codeと同じです。ただし拡張機能はVS Code MarketplaceではなくOpen VSXという配布元から入れる仕組みのため、すべての拡張機能があるとは限らず、同じように動かないものもあるとヘルプに書かれています。普段使っている拡張機能が見つかるかを先に確かめてください。

**Q. GitHub Copilotとどちらを選ぶべきですか。**
既存のエディタに補完を足したいならCopilot、エディタごと乗り換えて「コードベース全体を理解した提案」を受けたいならCursorです。両方を契約する必要はありません。詳しくは[コーディング支援AIの比較](/reviews/ai-coding-tools-comparison/)を参照してください。

**Q. 会社のコードを扱っても大丈夫ですか。**
公式の料金ページによると、プライバシーモードは設定画面から、またはチームの管理者が有効にでき、有効にするとコードのデータがCursorやモデルの提供元の学習に使われないとされています。オフの場合は、コードやプロンプトなどがAI機能の改善や学習に使われることがあるとデータの扱いのページに書かれています。確認したページには既定でオンかオフかの記載が見当たらなかったため、導入時に設定画面で確認してください。個人の判断で業務コードを投入する前に、社内規程の確認が要ります。
