## この記事の結論

- 人に頼む英文校正の料金は、3社とも**「英単語の数 × 1単語あたりの単価」**で決まります。単価を動かすのは、**納期・校正の深さ・原稿の量**の3つです。
- 公式の料金表で一番低い単価は、**ワードバイスの一般校正(7日納期)が4.6円**、**エディテージのスタンダード英文校正が5.5円**です。どちらも納期に余裕を持たせ、原稿がある程度長い場合の単価です。
- **急ぐと単価は2〜4倍**になります。ワードバイスの一般校正は7日なら4.6円、9時間なら18円。エディテージのスタンダードは1,500単語以下なら11営業日で6円、当日納品で18円です。
- **論理の流れまで見る上位の校正は、単価がおよそ2倍**です(エディテージのプレミアム10.5円〜、ワードバイスのプレミアム9.35円〜)。
- アイディービジネスは**1単語1.5ポイントの一律料金**で、1単語あたり**約14.7〜19.8円(税込)**。単価は高めですが、**100単語なら3時間以内**と、短い英文を早く返してもらう使い方に向いています。
- **1,000単語の例**では、ワードバイスの一般校正(7日)の4,600円から、エディテージのプレミアム(当日)の24,000円まで、約5倍の幅があります。
- **AIの校正ツールは無料版から始められ、有料版は月額の定額**です(Grammarly Pro は料金ページの表示で12ドル、DeepL Write Pro は月1,150円・年払い。11月12日確認)。社内メールや下書きはAI、契約書・論文など誤解されると困る英文は人の校正、と分けると費用を抑えやすくなります。
- 税込・税抜の表示は会社によって違います。比べるときは、各社の見積もり画面に出る**最終の支払額**で比べてください。

この記事の料金・条件は、各社の公式サイトの料金ページを**2026年11月5日に公式で確認**したものです。AIの校正ツール(Grammarly・DeepL Write)の料金と、アイディービジネスの定期券などの一部の条件は**2026年11月12日**に確認しました(文中に確認日を書いています)。当サイトでは実際のサービスを検証していません。公式の公開情報を整理した記事です。料金は改定されることがあるため、申し込む前に公式サイトで最新の表示を確かめてください。

AIの校正ツールと人の校正のどちらを使うかを先に決めたい場合は、後半の「[AIの校正ツールの料金と、人の校正との使い分け](#aiの校正ツールの料金と人の校正との使い分け)」の節から読むと整理しやすくなります。

## 料金を決める4つの要素

1. **単語数。** 英文校正は英単語の数で数えます。アイディービジネスの公式サイトでは、「This is a pen.」を4単語と数える例が示されています。日本語から英語への翻訳は、日本語の文字数で数える会社が多くなっています(アイディービジネス・ワードバイス・エディテージの翻訳の料金表は、いずれも1文字あたりの単価です)。
2. **納期。** 早く返してもらうほど単価が上がります。7日と9時間では、同じ会社・同じプランでも単価が4倍近く違います。
3. **校正の深さ。** 文法・スペル・用語といった言葉の面だけを直すのか、論旨の展開や文章全体の流れまで見るのかで、プランが分かれています。
4. **原稿の量と形式。** 長い原稿ほど単価が下がる会社があり、Word以外の形式は割増になることがあります(後の「見積もりの取り方」で整理しました)。

50単語未満の原稿も50単語分のポイントがかかり、1回に出せるのは2,000単語までです。ポイントの有効期限は購入日・利用日から180日です。担当者をネイティブにするか英語専門家にするかで料金は変わらないと公式サイトに書かれています。無料のメンバー登録で100ポイント(公式サイトでは1,200円相当)がもらえます(11月12日確認)。

### アイディービジネスの定期券(「327円から」の意味)

トップページの「327円から」は、**定期券を使った場合の1回あたりの料金**です(11月12日確認)。

| 定期券 | 価格(税込) | 使える量 | 1回あたり(税込) |
| --- | --- | --- | --- |
| 50単語 | 10,780円 | 30日間、1日1回50単語まで | 359円(税抜327円) |
| 100単語 | 16,478円 | 30日間、1日1回100単語まで | 549円(税抜499円) |

定期券は**30日間毎日1回使った場合**に1回あたりが327円(税抜)になる計算で、最初に30日分をまとめて払います。月に数回しか使わないなら、ポイントで都度払う方が安く済みます。50単語を超えた分は、ポイントと組み合わせて最大2,000単語まで出せるとされています。

## 「ネイティブチェック」と専門の校正の違い

「ネイティブチェック」は会社ごとに定義が決まった言葉ではありません。エディテージはよくある質問で、英文校正を「ネイティブの英文チェック」と言い換えています。料金を比べるときは、名前より**どこまで直すか**を見てください。公式の説明では、次のように分かれています。

| 直す範囲 | 該当するプラン(公式の説明) |
| --- | --- |
| 文法・スペル・用語など言葉の面 | エディテージ スタンダード(専門分野の校正者2名)、ワードバイス 一般校正、アイディービジネスのネイティブ担当 |
| 上記に加え、論旨の展開と文章全体の流れ | エディテージ プレミアム(シニア校正者2名)、ワードバイス プレミアム(論文の講評レポート付き) |
| 上記に加え、投稿先の要件や内容面 | エディテージ トップジャーナル英文校正(現役の査読者が入る体制・27円〜) |
| 元の日本語の意図どおりか | アイディービジネスの英語専門家担当(英文と日本語の原稿の両方を渡し、日本語で指示できる) |

アイディービジネスの英語専門家の担当は、日本語の原稿をもとに表現を提案し、大きく削ったり変えたりすることもできると説明されています(ネイティブ担当は英文の原稿だけを受け取り、指示は英語で行います)。どちらを選んでも料金は同じです。医療・薬学、法務・行政、産業・工学・IT など、専門分野の英文にも対応するとされています(11月12日確認)。

公式の単価に1,000単語を掛けた金額です(2026年11月5日の表示。エディテージ・ワードバイスは表示の単価のままで、税は含めていません)。

| エディテージ スタンダード | 11営業日 | 6,000円 |

アイディービジネスは、100ポイント単位で買うと1,000単語(1,500pt)で19,800円(税込)です。ポイントは180日で失効するため、使い切れる量だけまとめて買うのが無駄のない買い方です。

## 条件で分ける選び方

- **数百単語のメールや社外向けの文書を、その日のうちに直したい** → アイディービジネス。100単語なら3時間以内が目安で、50単語から出せます。
- **毎日短い英文を書く** → アイディービジネスの定期券。50単語の定期券は10,780円(税込)で30日間、1日1回50単語まで使え、毎日使うと1回あたり359円(税込)です。100単語の定期券は16,478円(税込)で1回あたり549円(税込)です。月に数回しか使わないなら、ポイントで都度払う方が安く済みます。
- **論文などで日程に余裕がある** → ワードバイスの一般校正(7日・4.6円)か、エディテージのスタンダード(11営業日・6円)。納期を延ばすのが一番効く節約です。
- **投稿の前に流れまで見てほしい、何度も直す予定がある** → プレミアムのプラン。エディテージ・ワードバイスとも、365日間の無料の再校正が付きます。
- **英語に自信がなく、元の日本語の意図どおりか確かめたい** → アイディービジネスの英語専門家担当。日本語の原稿を一緒に渡せます。
- **2,000単語を超える原稿や書籍** → エディテージかワードバイス。アイディービジネスは1回2,000単語までで、それ以上は個別の相談になります。

## AIの校正ツールの料金と、人の校正との使い分け

### AIの校正と人の校正の違い

| | AIの英文校正(Grammarly・DeepL Write など) | 人の英文校正(ネイティブチェック) |
| --- | --- | --- |
| 料金のかかり方 | 無料版あり。有料版は月額の定額 | 1単語あたりの従量(または回数券・定期券) |
| 返ってくるまで | その場ですぐ | 数時間〜数日(分量と納期による) |
| 直してもらえる範囲 | 文法・スペル・句読点、言い換えの提案 | 上記に加え、文脈・意図・読み手に合った表現 |
| 何度も直すとき | 何度でも試せる | 依頼のたびに費用がかかる(再校正の条件は会社ごとに違う) |

AIは「文法として正しいか」は拾えても、「その文書の目的に合っているか」までは保証しません。両方使う場合は、AIで単純な誤りを取ってから人に出すと、人の校正で意図や表現の確認に集中してもらえます。

### Grammarly の料金

英文の文法・スペルの誤りを直し、文章のトーン(語調)を表示するツールです。公式の料金ページ(2026年11月12日確認)では次のとおりです。

| プラン | 料金 | 主な内容 |
| --- | --- | --- |
| Free | 0ドル | 誤りの修正、トーンの表示、AIによる文章生成が月100回 |
| Pro | 12ドル(料金ページの表示) | 文全体の書き換え、トーンの調整、盗用とAI生成文の検出、AIによる文章生成が月2,000回 |
| Enterprise | 要問い合わせ | 組織向けの管理・セキュリティ機能 |

Pro の請求の周期(月払い・年払い)は、料金ページの表示からは読み取れませんでした。申し込み画面で確認してください。

公式ヘルプでは、英語に加えて日本語を含む24言語で修正の提案に対応し、無料版を含むすべてのプランで使えるとされています。ただし、段落ごとの書き換えに対応するのはスペイン語・フランス語・イタリア語・ドイツ語・ポルトガル語・ウクライナ語で、日本語は含まれていません。詳しくは[Grammarlyの解説](/reviews/grammarly-review/)にまとめています。

### DeepL Write の料金

翻訳サービスの DeepL が提供する文章の推敲ツールです。公式ヘルプでは、文法・スペル・句読点の修正と、別の語や表現の提案を行うと説明されています。対応言語には英語(UK・US)と日本語が含まれます。

| 使い方 | 1回に処理できる文字数 | 料金(2026年11月12日 公式サイトで確認) |
| --- | --- | --- |
| 無料(有料アカウントなし) | 1,500文字まで | 0円 |
| DeepL Pro(翻訳の有料プラン)の利用者 | 2,000文字まで | Individual は月1,150円相当(年払い) |
| DeepL Write Pro | 制限なし | アドオンとして月1,150円(年払い) |

公式ヘルプでは、**DeepL Pro(翻訳)の契約だけでは DeepL Write の有料版は含まれない**と注意書きがあります。Write Pro では、ログイン中に入力した文章が保存されないことも説明されています。DeepL の翻訳機能は[DeepLの解説](/reviews/deepl-review/)にまとめています。

### 文書の種類ごとの使い分け

| 文書 | 組み合わせの目安 | 理由 |
| --- | --- | --- |
| 社内向けのメール・チャット | AIだけ | 回数が多く、多少の言い回しの差は問題になりにくい |
| 取引先への定型的なメール | AI(毎日使うなら人の定期券も検討) | 数十単語の短い英文が中心 |
| 対外的な提案書・プレスリリース | AIで下ごしらえ → 人の校正 | 読み手に合った表現かを人に確かめてもらう |
| 契約書・規約 | 人の校正(専門分野に対応する担当者) | 1語の違いで意味が変わる。AIの提案をそのまま採用しない |
| 論文・学会の抄録 | AIで下ごしらえ → 人の校正 | 投稿先の規定(英文校正の証明書が要るか等)も先に確認する |
| 英語学習の作文 | AI、または解説つきの添削サービス | 直された理由を知ることが目的 |

### 費用の比べ方(例)

たとえば300単語の英文を月に4本、アイディービジネスで校正してもらう場合、300単語は450ポイント、4本で1,800ポイントです。1,000ポイント以上をまとめて買うと1ポイント9.79円なので、**月に約17,600円(税込)**になります(11月12日の公式の料金で計算)。同じ量をAIで直すなら、Grammarly の無料版や DeepL Write の無料版の範囲でも始められます。

この差をどう考えるかは、**その英文の誤りがどれだけの損につながるか**で決まります。社内メモならAIで十分で、契約や論文の採否にかかわる英文なら、人の確認の費用は安全のための費用と考えやすくなります。

### どちらを使う場合も確かめたいこと

1. **入力してよい文章か。** AIのサービスにも人の校正サービスにも、文章を外部に送ることになります。社外秘の資料や個人情報を含む文書は、勤め先の取り扱いの決まりと、各サービスのプライバシーに関する説明を先に確認してください。DeepL Write Pro は、ログイン中に入力した文章を保存しないと説明しています。アイディービジネスの公式サイトにも「個人情報配慮」のページがあります。
2. **直された理由を自分で確かめる。** AIの提案も人の修正も、元の意図からずれていないかは書いた本人にしか分かりません。数値・固有名詞・否定の位置は必ず見直してください。
3. **翻訳と校正を混同しない。** 日本語から英文を作るなら翻訳、英文を整えるなら校正です。翻訳の単価は後の「英文翻訳を頼む場合の単価」にまとめました。

## 見積もりの取り方

3社とも、公式サイトで原稿の単語数を入れると料金が出る見積もりの機能があり、無料で使えます。アイディービジネスは「無料自動お見積もり」、エディテージは「自動お見積り計算機」(見積もりの送り先としてメールアドレスなどを入力する形)、ワードバイスは料金ページの計算機(サービスの種類と単語数を入れる形)です。見積もりを取るときは、次の3点を確かめておくと、後から金額がずれにくくなります。

1. **どこまでを単語数に入れるか。** エディテージは、校正する箇所の指定がなければ文書全体が校正の対象になり、指定すれば対象の部分だけで計算できると案内しています(指定した部分以外のフォーマット調整は行われません)。参考文献や図表の中の文字を外せるかは、注文の前に確かめてください。
2. **原稿の形式。** エディテージは LaTeX・TeX・PDF・画像の原稿を15%増しとし、急ぎの納品はWord形式に限っています。アイディービジネスは画像を添付すると1枚50ポイントかかります。
3. **最終の支払額。** 税の扱い、ポイントの有効期限、再校正にかかる費用を含めて比べます。単価だけを並べると、税抜の表示の会社が安く見えることがあります。

## よくある質問

**Q. 英文校正の料金の相場はどれくらいですか。**
2026年11月5日に確認した3社の公式の料金表では、1単語あたり**4.6円〜24円程度**の幅があります。納期に余裕のある言葉の面の校正なら5〜6円台、翌日や当日の納品なら10〜18円、論理の流れまで見るプレミアムの当日納品なら24円です。1,000単語なら、およそ4,600円〜24,000円になります。

**Q. 英文校正を一番安く頼む方法はありますか。**
一番効くのは**納期を延ばすこと**です。ワードバイスの一般校正は7日なら1単語4.6円で、24時間の10円の半分以下です。ほかに、校正のいらない部分を対象から外す、ポイント制の会社なら使い切れる量をまとめて買う、という方法があります。無料の範囲では、アイディービジネスが無料のメンバー登録で100ポイントを配っています(100単語の校正には150ポイントかかります)。

**Q. ネイティブチェックと英文校正は違うものですか。**
決まった区別はありません。エディテージは英文校正を「ネイティブの英文チェック」と言い換えています。料金の差は名前ではなく直す範囲で決まり、文法・用語などの言葉の面だけか、論旨や文章の流れまで見るかで、単価がおよそ2倍違います。

**Q. AIの校正ツールで済ませてもよいですか。**
社内向けのメールや下書きなら、AIの校正ツールで足りる場合が多くあります。AIはその場で何度でも文法・スペル・句読点の誤りや言い換えを提案できますが、文脈や読み手に合った表現か、元の意図どおりかまでは保証しません。契約書・論文の投稿・対外的な提案書など、誤解されると困る英文は、人の校正を入れる意味が大きくなります。使い分けの目安は上の「文書の種類ごとの使い分け」にまとめました。

**Q. 無料で英文校正する方法はありますか。**
Grammarly の無料版は文法・スペルの誤りの修正に対応し、DeepL Write は有料アカウントがなくても1回1,500文字まで推敲できます(2026年11月12日確認)。人の校正では、アイディービジネスが無料登録で100ポイントを配っています(100単語の校正に使うと150ポイントかかるため、短い英文向け)。

**Q. Grammarly は日本語の文章にも使えますか。**
公式ヘルプでは、日本語を含む24言語で修正の提案に対応するとされています(2026年11月12日確認)。ただし、段落ごとの書き換えは日本語に対応していません。英文の校正が主な用途です。言い換えのツールは[QuillBotの解説](/reviews/quillbot-review/)もあわせて参照してください。
