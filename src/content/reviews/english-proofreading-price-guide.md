## この記事の結論

**人に頼む英文校正の料金相場は、1単語あたりおよそ5〜25円です。論文1本(4,000〜6,000語)なら、通常の納期で約2万〜3万円台、急ぎや論理の流れまで見る上位のプランでは4万〜6万円台が目安です**(各社の公式料金から計算。2026年11月27日確認)。

- 料金は**「英単語の数 × 1単語あたりの単価」**で決まります。単価を動かすのは**納期・校正の深さ・原稿の量**の3つです。
- 公式の料金表で低い単価は、**ワードバイスの一般校正(7日)が4.6円**、**エディテージのスタンダード英文校正が5.5円〜**です。AIで書いた原稿向けの**エディテージのポストAI英文校正は4円〜**です。
- **即日・特急にすると単価は2〜4倍**です。ワードバイスの一般校正は7日で4.6円、9時間で18円。エディテージのスタンダードは短い原稿の当日納品で18円です。
- **論理の流れまで見る上位の校正は、単価がおよそ2倍**です(エディテージのプレミアム10.5円〜、ワードバイスのプレミアム9.35円〜)。
- アイディービジネスは**1単語1.5ポイントの一律料金**で、**約14.7〜19.8円(税込)**。単価は高めですが、**100単語なら3時間以内**が目安で、短い英文を早く返してもらう使い方に向いています。
- 税込・税抜の表示は会社によって違います。最後は各社の見積もり画面の**支払額**で比べてください。

この記事の料金・条件は、各社の公式サイトの料金ページで確認したものです(確認日は表と文中に書いています)。当サイトではサービスを検証していません。公式の公開情報を整理した記事です。料金は改定されることがあるため、申し込む前に公式サイトで最新の表示を確かめてください。

## 料金を決める4つの要素

1. **単語数。** 英文校正は英単語の数で数えます。アイディービジネスの公式サイトでは、「This is a pen.」を4単語と数える例が示されています。日本語から英語への翻訳は、日本語の文字数で数える会社が多くなっています。
2. **納期。** 早く返してもらうほど単価が上がります。7日と9時間では、同じ会社・同じプランでも単価が4倍近く違います。
3. **校正の深さ。** 文法・スペル・用語といった言葉の面だけを直すのか、論旨の展開や文章全体の流れまで見るのかで、プランが分かれています。
4. **原稿の量と形式。** 長い原稿ほど単価が下がる会社があり、Word以外の形式は割増になることがあります。

## 英文校正を安くする方法

1. **納期を延ばす。** 一番効く方法です。ワードバイスの一般校正は7日なら4.6円で、24時間の10円の半分以下です。
2. **校正の対象を絞る。** 参考文献・図表・すでに校正済みの部分を外せば、その分の単語数が減ります。エディテージは、依頼フォームで校正のいらない箇所を指定できると案内しています。
3. **プランを目的に合わせる。** 論理の流れまで見る上位のプランは単価が約2倍です。言葉の面だけ直せばよい英文なら、標準のプランで足ります。
4. **AIで直した原稿なら、AI後のチェック向けのプランを検討する。** エディテージのポストAI英文校正は4円〜で、著者がAIツールで書いた・直した原稿が対象です。
5. **ポイント制なら使い切れる量をまとめて買う。** アイディービジネスは1,000pt以上で1pt 9.79円になりますが、ポイントは180日で失効します。
6. **割引の条件を見る。** ワードバイスは10,000単語以上で自動の割引があります。エディテージは11月27日時点で、トップジャーナル英文校正に20%引きの表示がありました(期間や条件は公式サイトで確認してください)。

1. 英文校正のページの「自動お見積り・ご注文」へ進みます。
2. フォームの「料金と納期をチェック」の欄に**単語数**を入れると、料金と納期の一覧が出ます。
3. 一覧から希望のプランを選ぶと、**そのまま注文を確定できる**形です。見積もりだけのときは確定まで進まないようにしてください。誤って発注のメールが届いた場合は、早めに連絡すると手配を止められるかを確認してもらえると案内されています。
4. 単語数が分からない、原稿を見て決めてほしい場合は、単語数を入れない「**原稿をアップロード&1時間でお見積り**」のフォームから原稿を送ります。
5. 参考文献など校正のいらない箇所は、フォームの「校閲の必要がない箇所の指定はありますか?」の欄で指定するか、原稿の該当箇所に色を付けて外すよう指示します。

最低単語数・最低受注額はないとされています。LaTeX・TeX・PDF・画像の原稿は15%増しで、急ぎの納品はWord形式に限られます(11月5日確認)。問い合わせはメール・電話・チャットでも受け付けています。

### ほかの会社の見積もり

- **アイディービジネス**: 「無料自動お見積り・納期確認フォーム」で、サービス(ネイティブ・英語専門家・翻訳)を選び、原稿の内容を入れます。画像を添付すると1枚50ポイントかかります。
- **ワードバイス**: 料金ページ上部の計算機に、単語数などの文書の情報を入れると見積もりが表示されます。最終の料金は単語数・納期・オプションで決まると説明されています。
- **FASTEK・エナゴ・ユレイタス**: 料金の条件を確認できなかったため、公式サイトの見積もりや問い合わせで確かめてください。

### 見積もりで確かめる3点

1. **どこまでを単語数に入れるか。** 参考文献・図表・脚注を外せるか。
2. **原稿の形式。** Word以外は割増や急ぎの対象外になることがあります。
3. **支払額。** 税の扱い、ポイントの有効期限、再校正の費用を含めて比べます。単価だけを並べると、税抜の表示の会社が安く見えることがあります。

## ネイティブチェック・英文校正・英文校閲の違い

一般に、**校正**は文字や文法の誤りを直すこと、**校閲**は内容の矛盾や論理の流れまで確かめることを指します。ただし英文の校正サービスでは、この区別は会社ごとに決まっていません。エディテージは料金のページの題を「英文校正・英文校閲サービス」とし、英文校正を「ネイティブの英文チェック」とも言い換えています。「ネイティブチェック」も同じで、定義が決まった言葉ではありません。

料金を比べるときは、名前より**どこまで直すか**を見てください。公式の説明では、次のように分かれています。

| 直す範囲 | 該当するプラン(公式の説明) | 単価の目安 |
| --- | --- | --- |
| 文法・スペル・用語など言葉の面 | エディテージ スタンダード、ワードバイス 一般校正、アイディービジネスのネイティブ担当 | 4.6〜18円 |
| 上記に加え、論旨の展開と文章全体の流れ | エディテージ プレミアム、ワードバイス プレミアム | 9.35〜24円 |
| 上記に加え、投稿先の視点での内容面 | エディテージ トップジャーナル(査読者が入る体制) | 27円〜 |
| 元の日本語の意図どおりか | アイディービジネスの英語専門家担当(英文と日本語の原稿の両方を渡す) | 約14.7〜19.8円(税込) |

アイディービジネスの英語専門家の担当は、日本語の原稿をもとに表現を提案し、大きく削ったり変えたりすることもできると説明されています。ネイティブ担当は英文の原稿だけを受け取り、指示は英語で行います。どちらを選んでも料金は同じです。

## AI校正との使い分け

### AIの校正と人の校正の違い

| | AIの英文校正(Grammarly・DeepL Write など) | 人の英文校正 |
| --- | --- | --- |
| 料金のかかり方 | 無料版あり。有料版は月額の定額 | 1単語あたりの従量(または回数券・定期券) |
| 返ってくるまで | その場ですぐ | 数時間〜数日(分量と納期による) |
| 直してもらえる範囲 | 文法・スペル・句読点、言い換えの提案 | 上記に加え、文脈・意図・読み手に合った表現 |
| 何度も直すとき | 何度でも直せる | 依頼のたびに費用がかかる(再校正の条件は会社ごとに違う) |

AIは「文法として正しいか」は拾えても、「その文書の目的に合っているか」までは保証しません。両方を使うなら、AIで単純な誤りを取ってから人に出すと、人の校正で意図や表現の確認に集中してもらえます。

エディテージのポストAI英文校正は、この順番を前提にしたプランです。AIで整えた文章に残る不自然な表現などを文単位で見るもので(プレミアムは論理展開・構成・文献情報まで)、**AI特有の誇張やハルシネーション(誤った情報)を特定して直すものではない**と明記されています。内容の正しさは書いた本人が確かめる必要があります。

Pro の請求の周期(月払い・年払い)は、料金ページの表示からは読み取れませんでした。申し込み画面で確認してください。詳しくは[Grammarlyの解説](/reviews/grammarly-review/)にまとめています。

### 文書の種類ごとの使い分け

| 文書 | 組み合わせの目安 | 理由 |
| --- | --- | --- |
| 社内向けのメール・チャット | AIだけ | 回数が多く、多少の言い回しの差は問題になりにくい |

### 費用の比べ方(例)

300単語の英文を月に4本、アイディービジネスで校正してもらう場合、300単語は450ポイント、4本で1,800ポイントです。1,000ポイント以上をまとめて買うと1ポイント9.79円なので、**月に約17,600円(税込)**になります。同じ量をAIで直すなら、Grammarly や DeepL Write の無料版の範囲でも始められます。この差をどう考えるかは、**その英文の誤りがどれだけの損につながるか**で決まります。

### どちらを使う場合も確かめたいこと

1. **入力してよい文章か。** AIにも人の校正サービスにも、文章を外部に送ることになります。社外秘の資料や個人情報を含む文書は、勤め先の決まりと各サービスのプライバシーの説明を先に確認してください。
2. **直された理由を自分で確かめる。** 数値・固有名詞・否定の位置は必ず見直してください。
3. **翻訳と校正を混同しない。** 日本語から英文を作るなら翻訳、英文を整えるなら校正です。

- **投稿の前に流れまで見てほしい、何度も直す予定がある** → プレミアムのプラン。エディテージ・ワードバイスとも、365日間の無料の再校正が付きます。エディテージのスタンダードは無料の再校正は付かず、1回分を2円/単語で追加する形です(サービス比較のページ・11月27日確認)。
- **英語に自信がなく、元の日本語の意図どおりか確かめたい** → アイディービジネスの英語専門家担当。日本語の原稿を一緒に渡せます。
- **2,000単語を超える原稿や書籍** → エディテージかワードバイス。アイディービジネスは1回2,000単語までです。

## よくある質問

**Q. 英文校正の料金の相場はどれくらいですか。**
各社の公式の料金表では、1単語あたり**およそ5〜25円**です。納期に余裕のある言葉の面の校正なら5〜7円前後、翌日や当日なら10〜18円、論理の流れまで見るプレミアムの当日納品なら22.75〜24円です。1,000単語なら、およそ4,600円〜24,000円です(2026年11月27日確認)。

**Q. 論文1本の英文校正はいくらかかりますか。**
4,000〜6,000語の論文なら、通常の納期の標準的な校正で**約2万〜3万円台**(ワードバイス一般校正の7日で18,400〜27,600円、エディテージ スタンダードで26,000〜33,000円)です。急ぎや論理の流れまで見るプランでは4万〜6万円台、査読者が入るエディテージのトップジャーナルでは10万円以上になります。

**Q. 即日・当日に頼むと、料金はどれくらい上がりますか。**
ワードバイスの一般校正は、7日の4.6円に対して13時間で15円、9時間で18円です。エディテージのスタンダードは、短い原稿で11営業日の6円に対して当日18円です。急ぎの納品は2〜4倍と考えておくと見積もりとずれにくくなります。アイディービジネスは急ぎの追加料金がなく、分量で納期の目安が決まる一律料金です。

**Q. 英文校正を一番安く頼む方法はありますか。**
一番効くのは**納期を延ばすこと**です。次に、参考文献など校正のいらない部分を対象から外すこと、言葉の面だけでよければ上位のプランを選ばないことです。AIで書いた・直した原稿なら、エディテージのポストAI英文校正(4円〜)という選択肢もあります。

**Q. エディテージの見積もりはどう取りますか。**
自動お見積り・ご注文のフォームの「料金と納期をチェック」に単語数を入れると、料金と納期の一覧が出ます。一覧からそのまま注文を確定できるため、見積もりだけなら確定まで進まないでください。単語数が分からない場合は「原稿をアップロード&1時間でお見積り」のフォームから原稿を送ります。

**Q. ネイティブチェックと英文校正・英文校閲は違うものですか。**
英文の校正サービスでは、決まった区別はありません。一般に校閲は内容や論理まで確かめることを指し、各社では「プレミアム」などの上位のプランがこれに近い範囲です。料金の差は名前ではなく直す範囲で決まり、言葉の面だけか、論旨や文章の流れまで見るかで単価がおよそ2倍違います。

**Q. ネイティブチェックの料金の相場はいくらですか。**
英文の校正としての料金なら、上の相場と同じく1単語およそ5〜25円です。エディテージはネイティブの校正者2名が担当すると説明しています。アイディービジネスはネイティブ担当と英語専門家担当のどちらを選んでも1単語1.5ポイントで同じです。

**Q. AIの校正ツールで済ませてもよいですか。**
社内向けのメールや下書きなら、AIの校正ツールで足りる場合が多くあります。ただしAIは、文脈や読み手に合った表現か、元の意図どおりかまでは保証しません。契約書・論文の投稿・対外的な提案書など、誤解されると困る英文は、人の校正を入れる意味が大きくなります。

**Q. 無料で英文校正する方法はありますか。**
Grammarly の無料版は文法・スペルの誤りの修正に対応し、DeepL Write は有料アカウントがなくても1回1,500文字まで推敲できます(2026年11月12日確認)。人の校正では、アイディービジネスが無料登録で100ポイントを配っています(100単語の校正には150ポイントかかるため、短い英文向け)。

**Q. エナゴやユレイタスの料金は載っていないのですか。**
2026年11月27日に公式サイトを確かめようとしましたが、自動の読み取りを断られたため、この記事では数字を載せていません。比べる場合は、各社の公式サイトの見積もりで、同じ単語数・同じ納期の金額を出してください。

**Q. 料金は税込ですか、税抜ですか。**
アイディービジネスは税込で表示しています。エディテージは料金表に明記がなく税抜と読め、ワードバイスの料金ページには税の記載がありません。最後は見積もり画面の支払額で比べてください。
