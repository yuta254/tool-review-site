## この記事の結論

Descript(ディスクリプト)は、**録画や音声を文字起こしし、その文章を編集すると映像・音声も同じように編集される**AI動画編集ツールです。公式サイトは「文字を消すとその場面の映像が消え、文を動かすと対応する映像も動く」と説明しています。

- **日本語の自動文字起こしは、公式の対応言語に入っていません。** ヘルプセンターには「対応はラテン文字の言語に限られ、中国語・日本語・ロシア語などはまだ対応していない」とあります。中心の機能である「文字で編集する」使い方は、**日本語で話した動画では公式には想定されていない**、と考えるのが安全です。
- 一方で、**字幕の日本語への翻訳(61言語)と、日本語の吹き替え(30言語)は対応言語に入っています。** 英語などで話した動画を日本語向けに展開する使い方なら当てはまります。
- 「um」「uh」のような**フィラー(つなぎ言葉)の検出は、英語の文字起こしのみ対応**とヘルプセンターに書かれています。
- 料金は米ドルで、**無料のFreeと、Hobbyist(年払いで月16ドル)・Creator(同24ドル)・Business(同50ドル)**など(2026年11月3日の料金ページ)。無料プランは書き出しが720pまでで、透かし(ウォーターマーク)なしの書き出しは有料プランからです。

この記事は、Descriptの公式サイト(descript.com)の料金ページ・トップページと、公式ヘルプセンター(help.descript.com)の記載を2026年11月3日に確認して整理したものです。当サイトで実際に使った検証はしていません。公式情報を整理した記事です。

## Descriptでできること

公式サイトとヘルプセンターで紹介されている主な機能です。

| 分野 | 主な機能(公式の説明の要旨) |
| --- | --- |
| 文字で編集 | 自動の文字起こし。文章を削除・コピー・並べ替えると映像も連動して編集される。タイムラインでの編集も可能 |
| 不要な部分の除去 | フィラー(つなぎ言葉)の除去、撮り直し部分の除去、言葉の間の短縮 |
| 音と映像の補正 | Studio Sound(雑音を除き声を聞きやすくする)、Eye Contact(視線をカメラに向いているように補正)、グリーンバックなしの背景除去 |
| AIの共同編集者 | Underlord:指示を出すと、字幕付け・クリップの切り出し・ズームなどの動き・翻訳・音の調整などを行う |
| 生成 | 文章からの読み上げ音声、自分の声の複製(ボイスクローン)、画像・映像の生成 |
| 収録 | 画面録画、オンラインで複数人を録る「Rooms」 |
| 書き出し・展開 | 字幕、字幕の翻訳、吹き替え、SNS向けのサイズ変更、文字起こしの書き出し |

Underlord は、ヘルプセンターで**まだベータ版**とされ、「指示を取り違えたり、できないことを引き受けたりすることがあるので、指示を具体的にし、結果を確認してほしい」という趣旨の注意が書かれています。

## Descriptで動画編集する流れ

Descript の動画編集は、**素材を入れると自動で文字起こしされ、その文章を文書のように直すと動画も同じように編集される**、という流れです。細かいタイミングの調整はタイムラインで行い、最後に MP4 などで書き出すか、リンクで公開します。**この流れは文字起こしが前提のため、日本語で話した素材では公式に想定された使い方になりません**(下の「日本語への対応」を参照)。

公式ヘルプセンターの「Get started with Descript」で案内されている流れを、順に並べます(2026年11月6日確認)。

1. **プロジェクトを始める**:録画する、手元のファイルを取り込む、AIの読み上げ音声で作る、白紙から始める、のどれかを選ぶ
2. **素材を入れる**:内蔵の録画機能や、離れた相手と録る「Rooms」で収録するか、音声・動画のファイルを取り込む
3. **自動で文字起こしされる**:取り込んだ素材はすべて自動で文字起こしされ、文章として編集できる
4. **文章を直して編集する**:文章を消す・動かす・貼り付けると、映像と音声も同じように変わる
5. **シーンとレイアウトを整える**:動画を「シーン」に区切り、画面分割・ワイプ・タイトル・エンディングなどのレイアウトを当てる。音楽や文字、素材も足せる
6. **字幕を付ける**:字幕の画面でスタイルを選び、動画の見た目に合わせて調整する
7. **タイムラインで細かく直す**:間の取り方を調整したり、音楽や差し込み映像を複数のシーンにまたがって伸ばしたりする
8. **AIで仕上げる(任意)**:Underlord、Studio Sound(声を聞きやすくする)、Eye Contact(視線の補正)、短いクリップの切り出しなど
9. **書き出す・共有する**:MP4 や GIF などで保存するか、リンクで公開する。YouTube などへ直接書き出すこともできる

### 文章を消したとき、映像はどうなるか

ヘルプセンターの「Edit like a doc」では、文章と映像の関係を次のように説明しています。

| 操作 | 映像・音声への影響(公式ヘルプの説明の要旨) |
| --- | --- |
| 文章を選んで削除 | その部分の映像・音声も消える。元の素材は残っていて、編集の境目から「Restore removed media」で戻せる |
| 文章を切り取って貼り付け | 対応する映像・音声も一緒に動く。コピーすると複製になる |
| 文字起こしから外す | 映像・音声は残し、文章だけを台本・字幕・書き出す文字起こしから隠す |
| Ignore(無視) | 文章に取り消し線を付けて残し、編集の印にする |
| 文字起こしの修正 | 誤字や聞き取りの誤り、話者名を直すための操作 |

書き出しの画質は、無料プランが720pまで(透かし入り)、Hobbyist が1080p、Creator 以上が4Kです(下の料金表を参照)。

## 料金とプラン(2026年11月3日確認)

公式の料金ページの表示です。料金は**米ドル**で、確認したページに日本円の表示はありませんでした。月払いと年払いを切り替えて表示する形で、下の表の「年払い」は年払いを選んだときの月あたりの金額です。

| プラン | 年払い(月あたり) | 月払い | 人数 |
| --- | --- | --- | --- |
| Free | 0ドル | 0ドル | 1人 |
| Hobbyist | 16ドル | 24ドル | 1人 |
| Creator | 24ドル | 35ドル | 1〜3人 |
| Business | 50ドル | 65ドル | 最大5人 |
| Enterprise | 個別見積もり | 個別見積もり | 個別 |

料金は1人あたりの月額表示です。無料プランの申し込みにクレジットカードは不要、と料金ページのよくある質問に書かれています。

### プランごとの使える量と書き出し

| 項目 | Free | Hobbyist | Creator | Business |
| --- | --- | --- | --- | --- |
| メディア時間(1人あたり・月) | 60分 | 600分(10時間) | 1,800分(30時間) | 2,400分(40時間) |
| AIクレジット(1人あたり) | 100(1回限り) | 400/月 | 800/月 | 1,500/月 |
| 書き出しの解像度(ローカル) | 720p | 1080p | 4K | 4K |
| 透かしなしの書き出し | なし | あり | あり | あり |
| 取り込めるファイルの大きさ | 1GBまで | 10GBまで | 20GBまで | 50GBまで |
| クラウド保存容量 | 5GB | 100GB | 1TB | 2TB |
| 時間・クレジットの追加購入 | なし | なし | あり | あり |

- **メディア時間**は、取り込んだ素材とDescriptで録画した素材の長さで数えられ、文字起こしをしたかどうかは関係ない、とよくある質問で説明されています。
- **AIクレジット**は、Underlord・Studio Sound・Green Screen・Eye Contact などのAI機能を使うと減ります。Underlord はヘルプセンターで、指示ごとにクレジットを使い、さらに実行した機能の分も消費する、使う量は毎回変わる、と説明されています。
- Underlord・Studio Sound・Eye Contact・フィラー除去などは、Freeでは「制限あり(Limited)」、有料プランでは「含まれる」と表示されています。
- 透かしなしの書き出しは Hobbyist 以上です。Freeで書き出した動画には透かしが入る前提で考えてください。

料金と内容はよく変わります。申し込む前に、[公式の料金ページ](https://www.descript.com/pricing)で最新の表示を確認してください。

## 日本語への対応

日本語で使う人がいちばん気になる点です。料金ページとヘルプセンターの記載を、機能ごとに分けて整理します。

| 機能 | 日本語は? | 公式の記載の要旨 |
| --- | --- | --- |
| 自動の文字起こし | **対応言語に入っていない** | 対応はラテン文字の言語に限られ、中国語・日本語・ロシア語などはまだ対応していない(ヘルプセンター)。料金ページの一覧(25言語)にも日本語はない |
| 文字で動画を編集する | 文字起こしが前提のため、日本語の音声では公式には想定されていない | 上の文字起こしの対応言語に従う |
| フィラーの検出 | **英語のみ** | 英語の文字起こしだけに対応する機能として、フィラーの検出、文字起こしの読み込み・置き換え、用語集が挙げられている |
| 字幕の翻訳 | **対応(翻訳先として)** | 61言語に翻訳でき、その中に日本語がある |
| 吹き替え(音声の翻訳) | **対応(翻訳先として)** | 30言語の中に日本語がある。ネイティブに近いAI音声(14言語、Businessのみ)にも日本語がある |
| 操作画面の言語 | 確認できず | 確認したページ(アプリの設定の説明を含む)に、画面を日本語表示にする設定の記載は見当たらなかった |

自動文字起こしの対応言語として公式に挙がっているのは、英語(米国・英国)、フランス語、ドイツ語、スペイン語(米国)、イタリア語、ポルトガル語(ブラジル)、オランダ語、ポーランド語、スウェーデン語、トルコ語などです(ギリシャ語・ヒンディー語などはベータ版)。言語の数は、ヘルプセンターでは26言語、料金ページでは25言語と書かれていて、ページによって数え方が少し違います。

まとめると、Descript が日本語の利用者に合うのは、次のような場合です。

- **英語など対応言語で話した動画やポッドキャスト**を編集する
- 英語などの動画に、**日本語の字幕や日本語の吹き替え**を付けて展開する

日本語で話した動画の文字起こしや字幕づくりが目的なら、日本語の文字起こしに対応していると公式に書かれているツールを選ぶ方が確実です。会議の録音の文字起こしなら[AI文字起こしツールの比較](/reviews/ai-transcription-tools-comparison/)、スマホやパソコンで手軽に動画を編集するアプリなら[CapCutの記事](/reviews/capcut-review/)も参考にしてください。

| 使い方 | 条件 |
| --- | --- |

## 得意なこと

公式の説明から読み取れる、Descript が向いている作業です。

- インタビュー・解説・ポッドキャストのように、**話している内容が中心の動画**を、文章を直す感覚で切り詰める(対応言語の場合)
- 録音の雑音を減らし、声を聞きやすくする(Studio Sound)
- 原稿を読みながら撮った動画の視線を補正する(Eye Contact)
- 1本の動画から、SNS向けの短いクリップや字幕付きの版を作る
- 英語などの動画に、日本語を含む多言語の字幕・吹き替えを付ける

## 過信は禁物な点

- **日本語の音声は自動文字起こしの対応言語に入っていない。** 中心の機能が使える前提で申し込まないでください。
- **フィラーの検出は英語のみ。** 英語以外の言語では、フィラーの自動除去は公式の対応範囲の外です。
- **自動の文字起こしや自動編集の結果は、確認と手直しが前提。** 文字起こしの正確さは音質や話者の数に左右されるのが一般的です。固有名詞や数字は特に見直してください。
- **Underlord はベータ版。** 公式ヘルプも、結果を確認するよう呼びかけています。
- **無料プランは透かし入り・720pまで・AIクレジットは1回限りの100。** 本番の書き出しに使うなら有料プランが前提です。
- **動作環境が新しめ。** macOS 14以降・Windows 11以降が条件です。

## 向いている人

- 英語など対応言語で話す動画・ポッドキャストを作る人
- 英語の動画を日本語の字幕や吹き替えで展開したい人
- タイムライン中心の動画編集ソフトの操作に負担を感じている人(対応言語の素材の場合)

日本語で話す動画が中心の人は、上の対応表を見たうえで、ほかのツールと比べてから決めるのが安全です。動画ツールの役割分担は[AI動画ツールの比較](/reviews/ai-video-tools-comparison/)にまとめています。

## 使い方のコツ

1. 申し込む前に、自分が使う言語が[対応言語の一覧](https://help.descript.com/script-editing/supported-transcription-languages)に入っているかを確かめる
2. 無料プラン(メディア時間60分)の範囲で、短い素材から始める
3. 自動の文字起こしや自動編集の結果は下書きとして扱い、書き出す前に人の目で確認する
4. 字幕を書き出す前に、固有名詞や数字の誤りを見直す

## よくある質問

**Q. 日本語の動画でも使えますか。**
日本語で話した音声の自動文字起こしは、公式の対応言語に入っていません(ヘルプセンター、2026年11月3日確認)。文字起こしを前提にした「文字で編集する」機能も、日本語の音声では公式には想定されていません。日本語の字幕への翻訳と日本語の吹き替えは、対応言語に入っています。

**Q. 画面は日本語で表示できますか。**
確認した公式のページ(アプリの設定の説明を含む)には、操作画面を日本語で表示する設定の記載は見当たりませんでした。英語の画面で使う前提で考えておくと安全です。

**Q. 無料プランで何ができますか。**
料金ページでは、メディア時間が月60分、AIクレジットが1回限りの100、書き出しは720pまでで透かしが入ります。Underlord や Studio Sound などのAI機能は「制限あり」で使えます。申し込みにクレジットカードは不要と書かれています。

**Q. 「えー」「あのー」のようなフィラーを自動で消せますか。**
フィラーの除去機能はありますが、ヘルプセンターでは**フィラーの検出は英語の文字起こしのみ対応**とされています。日本語の「えー」「あのー」を自動で消す使い方は、公式の対応範囲に入っていません。

**Q. 料金は日本円で払えますか。**
確認した料金ページは米ドルの表示で、日本円の金額は見当たりませんでした。為替によって円での支払額は変わります。

**Q. どんな動画に向いていますか。**
インタビュー、解説、ポッドキャストのように「話している内容」が主役の動画です(話す言語が対応言語の場合)。カット割りやエフェクトで見せる動画では、タイムライン中心の編集ソフトの方が合うことがあります。

**Q. Windows 10 で使えますか。**
ヘルプセンターのシステム要件では、Windows のデスクトップアプリは64ビット版の Windows 11 以降です。ブラウザ版は Chrome・Edge・Opera が公式のサポート対象です。
