## この記事の結論

- Descript(ディスクリプト)は、録画や音声を自動で文字起こしし、**その文章を消す・動かすと映像と音声も同じように編集される**動画編集ツール
- **日本語の自動文字起こしは、公式の対応言語に入っていない。** ヘルプセンターには「中国語・日本語・ロシア語などはまだ対応していない」とある。日本語で話した動画では、中心の「文字で編集する」使い方は公式に想定されていない(2026年11月23日確認。11月3日から変わらず)
- 一方で、**字幕の日本語への翻訳(61言語の中)と、日本語の吹き替え(30言語の中)は対応**している。英語などで話した動画を日本語向けに展開する使い方なら当てはまる
- 料金は米ドルで、Free(0ドル)・Hobbyist(年払いで月16ドル、月払い24ドル)・Creator(同24ドル・35ドル)・Business(同50ドル・65ドル)・Enterprise(個別見積もり)。金額は11月3日から変更なし
- 無料プランはメディア時間が月60分、AIクレジットは1回限りの100、書き出しは720pまでで透かし入り
- プランの返金は**請求書の日付から48時間以内**だけ。追加購入(Top-ups)は返金なし。米国外では**料金に税は含まれない**とヘルプセンターに書かれている

この記事は、Descript の公式サイト(料金ページ・利用規約)と公式ヘルプセンター(対応言語・動作環境・返金・税・Underlord などのページ)を2026年11月23日に確認してまとめたものです。当サイトでは Descript を操作して確かめてはいません。

## Descriptとは

Descript は、動画とポッドキャストを、文書を直すような操作で編集するツールです。公式ヘルプセンターの「Edit like a doc」では、文字起こしの文章を直すと、元の映像・音声が自動で合わせて更新され、タイムラインを使わなくても編集できると説明されています。公式サイトとヘルプセンターで紹介されている主な機能は次のとおりです。

| 分野 | 主な機能(公式の説明の要旨) |
| --- | --- |
| 文字で編集 | 自動の文字起こし。文章を削除・コピー・並べ替えると映像も連動して編集される。タイムラインでの編集も可能 |
| 不要な部分の除去 | フィラー(つなぎ言葉)の除去、撮り直し部分の除去、言葉の間の短縮 |
| 音と映像の補正 | Studio Sound(雑音を除き声を聞きやすくする)、Eye Contact(視線をカメラに向いているように補正)、グリーンバックなしの背景除去 |
| AIの共同編集者 | Underlord:指示を出すと、字幕付け・クリップの切り出し・翻訳・音の調整などを行う。ヘルプセンターでは「ベータ版」 |
| 生成 | 文章からの読み上げ音声、自分の声の複製、画像・映像の生成 |
| 収録 | 画面録画、オンラインで複数人を録る「Rooms」 |
| 書き出し・展開 | 字幕、字幕の翻訳、吹き替え、SNS向けのサイズ変更、文字起こしの書き出し |

## 日本語への対応

日本語で使う人がいちばん気になる点です。料金ページとヘルプセンターの記載を、機能ごとに分けて整理します(2026年11月23日確認)。

| 機能 | 日本語は? | 公式の記載の要旨 |
| --- | --- | --- |
| 自動の文字起こし | **対応言語に入っていない** | 対応はラテン文字の言語に限られ、中国語・日本語・ロシア語などはまだ対応していない(ヘルプセンター)。料金ページの一覧(25言語)にも日本語はない |
| 文字で動画を編集する | 文字起こしが前提のため、日本語の音声では公式に想定されていない | 上の文字起こしの対応言語に従う |
| フィラーの検出 | **英語のみ** | 英語の文字起こしだけに対応する機能として、フィラーの検出、文字起こしの読み込み・置き換え、用語集が挙げられている |
| 字幕の翻訳 | **対応(翻訳先として)** | 61言語に翻訳でき、その中に日本語がある |
| 吹き替え(音声の翻訳) | **対応(翻訳先として)** | 30言語の中に日本語がある。ネイティブに近いAI音声(14言語、Business のみ)にも日本語がある |
| 操作画面の言語 | 記載なし | 確認したページに、画面を日本語表示にする設定の記載は見当たらなかった |

文字起こしの対応言語として[ヘルプセンター](https://help.descript.com/script-editing/supported-transcription-languages)に挙がっているのは、英語(米国・英国)、フランス語、ドイツ語、スペイン語(米国)、イタリア語、ポルトガル語(ブラジル)、オランダ語、ポーランド語、スウェーデン語、トルコ語などです。言語の数は、ヘルプセンターの見出しでは26言語、料金ページでは25言語と書かれていて、ページによって数え方が違います。

日本語で話した動画の文字起こしや字幕づくりが目的なら、日本語の文字起こしに対応していると公式に書かれているツールを選ぶ方が確実です。会議の録音の文字起こしなら[AI文字起こしツールの比較](/reviews/ai-transcription-tools-comparison/)、スマホやパソコンで手軽に動画を編集するアプリなら[CapCutの記事](/reviews/capcut-review/)も参考にしてください。

## Descriptで動画編集する流れ

公式ヘルプセンターの「Get started with Descript」で案内されている流れです(2026年11月6日確認)。**この流れは文字起こしが前提のため、日本語で話した素材では公式に想定された使い方になりません。**

1. **プロジェクトを始める**:録画する、手元のファイルを取り込む、AIの読み上げ音声で作る、白紙から始める、のどれかを選ぶ
2. **素材を入れる**:内蔵の録画機能や「Rooms」で収録するか、音声・動画のファイルを取り込む
3. **自動で文字起こしされる**:取り込んだ素材は自動で文字起こしされ、文章として編集できる
4. **文章を直して編集する**:文章を消す・動かす・貼り付けると、映像と音声も同じように変わる
5. **シーンとレイアウトを整える**:動画を「シーン」に区切り、画面分割・タイトルなどのレイアウトを当てる
6. **字幕を付ける**:字幕の画面でスタイルを選ぶ
7. **タイムラインで細かく直す**:間の取り方や、音楽・差し込み映像の長さを調整する
8. **AIで仕上げる(任意)**:Underlord、Studio Sound、Eye Contact、短いクリップの切り出しなど
9. **書き出す・共有する**:MP4 や GIF などで保存するか、リンクで公開する

### 文章を消したとき、映像はどうなるか

ヘルプセンターの「[Edit like a doc](https://help.descript.com/getting-started/edit-like-a-doc)」の説明の要旨です(2026年11月23日確認)。

| 操作 | 映像・音声への影響 |
| --- | --- |
| 文章を選んで削除 | その部分の映像・音声も消える。編集は元の素材を壊さない方式で、編集の境目から「Restore removed media」で戻せる |
| 文章を切り取って貼り付け | 対応する映像・音声も一緒に動く。コピーすると複製になる |
| Ignore(無視) | 文章に取り消し線を付けて残し、編集の印にする(削除はしない) |

## 返金と解約

ヘルプセンターの[返金ポリシー](https://help.descript.com/billing-payments-plans/refund-policy)の要点です(2026年11月23日確認)。

- **プランの返金は、請求書の日付から48時間以内**に申し出た場合だけです。追加の編集者の席は7日以内です。
- メディア時間やAIクレジットの**追加購入(Top-ups)は返金されません。**
- 申し出はサポートへの問い合わせから行い、メールの場合はアカウントのアドレスから送ります。
- 解約・下位プランへの変更・年払いから月払いへの変更は、**今の請求期間の終わりに反映**されます。使い残した期間の日割りの返金はありません。
- 上位プランへの変更と年払いへの変更はすぐに反映され、前のプランの残りの期間は新しいプランに充当されます。

年払いは金額が大きくなるため、48時間を過ぎると返金を求められない点は、申し込む前に知っておく必要があります。

## 日本の消費税・インボイス

- ヘルプセンターの[税のページ](https://help.descript.com/hc/en-us/articles/14569944855565-Do-Descript-subscriptions-and-transcription-fees-include-taxes)では、**米国外では Descript の料金に税は一切含まれない**とされ、利用者が自国の税務当局に税を納める必要がある場合があると書かれています(2026年11月23日確認)。
- 米国外の利用者は、購入時に事業者の税番号(VAT・GST など)を入れることができ、有効な番号ならリバースチャージの対象になる場合があると書かれています。
- **日本の消費税(10%)が請求に上乗せされるか、適格請求書(インボイス)を発行するか、日本の登録番号は、確認したページに書かれていませんでした。** 日本についての個別の記載もありません。法人で使う場合は、最初の請求書の表示を確かめるか、サポートに問い合わせてください。

ほかの海外AIツールの消費税の扱いと登録番号は、[海外AIツールの消費税・インボイス対応一覧](/reviews/ai-tools-japan-consumption-tax-invoice/)にまとめています(国税庁の公表サイトで照合)。

## 公式に書いていないこと

確認したページに見当たらなかった事項と、各自で確かめる方法です。

- **操作画面を日本語にできるか:** 記載がありませんでした。英語の画面で使う前提で考えておくのが確実です。
- **日本の消費税と適格請求書:** 上の節のとおり、米国外は税抜とだけ書かれ、日本の扱いは書かれていません。
- **1回の操作で使うAIクレジットの量:** Underlord のヘルプでは、決まった価格はなく、モデル・素材の長さ・生成する内容で変わるとされています。使った量は設定の Usage の画面で見られます。
- **文字起こしの正確さ:** 対応言語での正確さの数字は書かれていません。固有名詞や数字は、書き出す前に人の目で見直す前提で考えてください。
- **日本円での支払い:** 料金ページは米ドルの表示だけでした。

## よくある質問

**Q. 日本語の動画でも使えますか。**
日本語で話した音声の自動文字起こしは、公式の対応言語に入っていません(ヘルプセンター、2026年11月23日確認)。文字起こしを前提にした「文字で編集する」機能も、日本語の音声では公式に想定されていません。日本語の字幕への翻訳と日本語の吹き替えは、対応言語に入っています。

**Q. 画面は日本語で表示できますか。**
確認した公式のページには、操作画面を日本語で表示する設定の記載は見当たりませんでした。英語の画面で使う前提で考えておくのが確実です。

**Q. 無料プランで何ができますか。**
料金ページでは、メディア時間が月60分、AIクレジットが1回限りの100、書き出しは720pまでで透かしが入ります。字幕や吹き替えの翻訳は「制限あり」です。申し込みにクレジットカードは不要と書かれています。

**Q. 「えー」「あのー」のようなフィラーを自動で消せますか。**
フィラーの除去機能はありますが、ヘルプセンターでは**フィラーの検出は英語の文字起こしのみ対応**とされています。日本語の「えー」「あのー」を自動で消す使い方は、公式の対応範囲に入っていません。

**Q. 申し込んだ後に返金してもらえますか。**
ヘルプセンターの返金ポリシーでは、プランの返金は請求書の日付から48時間以内に申し出た場合だけです。追加の席は7日以内、追加購入(Top-ups)は返金なしです。解約は今の請求期間の終わりに反映され、日割りの返金はありません(2026年11月23日確認)。

**Q. 料金は日本円で払えますか。**
確認した料金ページは米ドルの表示で、日本円の金額は見当たりませんでした。有料プランはクレジットカードに自動で請求されると書かれています。為替によって円での支払額は変わります。

**Q. Windows 10 で使えますか。**
ヘルプセンターのシステム要件では、Windows のデスクトップアプリは64ビット版の Windows 11 以降です。ブラウザ版は Chrome・Edge・Opera が公式のサポート対象です。
