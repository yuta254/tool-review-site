## この記事の結論

- Claude の個人向けプランは Free(0ドル)・Pro(月20ドル、年払いなら年200ドル)・Max(月100ドル)・Ultra(月200ドル)。組織向けの Team は2〜150席で、標準席が1席月25ドル(年払いなら月20ドル)から(2026年11月22日に公式の料金ページで確認。11月3日から金額の変更なし)
- 表示価格は**税抜**。2026年4月1日から、日本の利用者には全プランに**消費税10%が別に加算**される。Anthropic は適格請求書発行事業者として登録済み(登録番号 T7700150134388)
- 次の請求を止めるには、**次の請求日の24時間前までに解約**する。支払いは原則として返金されない(消費者向け規約・法律で定める場合・不正利用の場合を除く)
- 個人向け(Free・Pro・Max)の会話は、「モデルの改善」の設定をオンにした場合などに学習に使われる。設定はオフにできる
- Web検索とコネクタ(外部サービスとの接続)は無料プランを含む全プランで使える。Claude Code・Research・Claude in Chrome は Pro 以上
- 写真やイラストのような画像は生成しない。図やグラフは HTML・SVG で作れると公式ヘルプに書かれている

この記事は、Claude の公式の料金ページとヘルプセンター(support.claude.com・privacy.claude.com)を2026年11月22日に確認してまとめたものです。当サイトでは Claude を操作して確かめてはいません。

## Claudeとは

Claude は、米 Anthropic が提供する AI チャットです。Web・デスクトップアプリ・スマートフォンアプリから使え、開発者向けにはターミナルで動く Claude Code があります。公式ヘルプによると、有料プランのチャットで扱える会話の長さ(コンテキストウィンドウ)はモデルによって50万〜100万トークンで、一覧にないモデルは20万トークンです。

画面の表示言語は11言語から選べ、日本語が含まれています(プロフィールのアイコン→「Language」で切り替え)。会話は表示言語に関係なくどの言語でもできます。ChatGPT・Gemini との横並びの比較は[ChatGPT・Claude・Gemini徹底比較](/reviews/chatgpt-claude-gemini-comparison/)にまとめています。

## 日本の消費税・インボイス

- 料金ページには「表示価格に適用される税は含まれない」と書かれています(2026年11月22日確認)。
- 公式ヘルプの[日本の顧客向け消費税(JCT)に関するお知らせ](https://support.claude.com/ja/articles/14051822)によると、2026年4月1日以降のすべての請求書で、日本の顧客には全プランの価格に消費税10%が加算されます。請求の通貨は変わらず、消費税の額は適格請求書に日本円で表示されます。
- Anthropic は適格請求書発行事業者として登録済みで、登録番号は T7700150134388 です(国税庁の公表サイトで確かめられると案内されています)。法人の利用者は、適格請求書で仕入税額控除を受けられます。個人の利用者は控除を受けられないため、消費税は利用者の負担です。
- 請求書を画面のどこから取り出すかは、このお知らせには書かれていませんでした。適格請求書についての質問はサポートに問い合わせるよう案内されています。個別の税務の扱いは、税理士か税務署に確認してください。
- iPhone・Android のアプリから申し込んだ場合は、Apple・Google が請求元になります(返金のヘルプで、App Store の返金は Apple だけが扱うと説明されています)。この場合の請求書の形式は、それぞれのストアの表示を確かめてください。

ほかの海外AIツールの消費税の扱いと登録番号は、[海外AIツールの消費税・インボイス対応一覧](/reviews/ai-tools-japan-consumption-tax-invoice/)にまとめています(国税庁の公表サイトで照合)。

## 1年・2年の総額の試算

料金ページの金額に、日本の消費税10%を足した目安です。円は1ドル=150円で換算しており、実際の請求額は為替とカード会社の手数料で変わります。API クレジットの追加購入や、Enterprise の API 料金分は含みません。

## 公式の説明から分かる注意点

- **年払いは前払いで、原則返金なし**: Pro の年払いは年200ドルを前払いします。返金のヘルプでは、支払いは原則として返金されないとされています(EEA・英国を除く)。
- **解約しても請求期間の終わりまでは使える**: 解約は期間の終わりに効力が生じます。次の請求を止めるには、請求日の24時間前までに手続きをします。
- **アプリから申し込んだ場合は手続き先が違う**: iPhone で申し込んだ場合、返金は Apple に申し込み、返金を申し込んでも定期購入は解約されないため、別に解約が必要です。
- **個人向けの学習の設定**: 個人向けのプランでは、設定の「Privacy」にあるモデルの改善の項目で、会話を学習に使うかを選べます。シークレットチャットは、設定がオンでも学習に使われないと書かれています。
- **会話の長さの上限**: 有料プランでコード実行を有効にしていると、会話が上限に近づいたときに以前のやり取りを要約して続けられると公式ヘルプに書かれています。

## 公式に書いていないこと

確認したページに見当たらなかった事項と、各自で確かめる方法です。

- **無料プランの具体的な回数**: 料金ページは「利用量に上限あり」とだけ書いており、回数は示していません。Free で登録し、上限に達したときに表示される再開の時刻を見ると、自分の使い方での目安が分かります。
- **無料プランのコンテキストウィンドウ**: ヘルプの表は有料プランだけを対象にしています。Free で長い資料を扱えるかは、実際の資料の一部を渡し、エラーが出るかで確かめられます。
- **API クレジットの使い道**: 料金ページには Max・Ultra・Team の「Monthly API credits」が表示されていますが、何に使えるかの詳しい説明は確認した範囲にありませんでした。申し込む前に料金ページの注記とヘルプで確かめてください。
- **請求書の取り出し方**: 消費税のお知らせには書かれていません。有料プランに申し込んだ後、「Settings > Billing」の表示で請求書の項目があるかを確かめてください。

## よくある質問

**Q. ChatGPTから乗り換える価値はありますか。**
長い文書を読ませる作業と、コードの読解・修正が多い人は検討の候補になります。逆に、写真やイラストの画像生成を多用するなら、Claude は写真・イラストを生成しないと公式ヘルプに書かれているため、別のサービスとの併用が必要です。詳しくは[AIチャット3種の比較](/reviews/chatgpt-claude-gemini-comparison/)を参照してください。

**Q. どれくらいの長さの資料を読ませられますか。**
公式ヘルプによると、有料プランのチャットではモデルによって50万〜100万トークンまで扱え、一覧にないモデルは20万トークンです(2026年11月22日確認)。無料プランの上限はヘルプに書かれていません。どのくらいの資料が何トークンになるかは、無料の[AIトークン数カウンター](/tools/token-counter/)で目安をつかめます。

**Q. 業務資料を入れても大丈夫ですか。**
プランによって扱いが違います。個人向け(Free・Pro・Max)は、モデルの改善の設定をオンにした場合などに会話が学習に使われ、設定はオフにできます。法人向け(Team・Enterprise・API)は、原則として学習に使われないと公式のプライバシーヘルプに書かれています(2026年11月3日確認)。未公開の情報を扱う前に、契約中のプランの条件と社内規程の両方を確かめてください。

**Q. 消費税はかかりますか。**
かかります。公式ヘルプによると、2026年4月1日から日本の顧客には全プランの価格に消費税10%が加算され、税額は適格請求書に日本円で表示されます。登録番号は T7700150134388 です。法人は仕入税額控除を受けられ、個人は消費税を負担します(2026年11月22日確認)。

**Q. 途中で解約したら返金されますか。**
公式ヘルプでは、支払いは原則として返金されないとされています(消費者向け規約で定める場合・法律で求められる場合・不正利用の場合を除く。EEA・英国は14日以内の返金あり)。解約しても請求期間の終わりまでは使えます。次の請求を止めるには、請求日の24時間前までに解約してください(2026年11月22日確認)。
