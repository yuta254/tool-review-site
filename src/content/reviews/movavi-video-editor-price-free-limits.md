## この記事の結論

- **料金は3通り**(税込・2026年11月6日の公式購入ページ):Video Editor の**1か月契約は月2,500円**(初月は2,100円)、Video Editor Plus の**1年は9,100円**、Video Editor Plus の**永久ライセンス(買い切り)は18,200円**。
- **買い切りは「その時点の版」をずっと使える形**。購入ページには「更新なしで現在のバージョンに永久アクセス」とあり、新しい版(メジャーアップデート)は追加料金で買うとライフサイクルポリシーに書かれています。
- **無料版(体験版)の制限**:書き出した動画に「体験版」の透かしが入り、**動画は60秒まで**、音声は元の長さの半分までしか書き出せない。一部の高度な機能も使えない。体験版の制限の一覧には、Video Editor の**使える日数は書かれていません**。
- **対応OS**:Windows 10/11(64bit)、macOS 12以降。メモリは4GBが目安と公式の動作環境にあります。
- **返金は購入から14日以内**。ただし、技術的な問題が14日以内に解決しない場合などに限られ、「気が変わった」「体験版で見られる機能に満足できない」は対象外です。
- **販売元は Movavi Software Limited**。登記上の所在地はキプロスのリマソールと公式のプライバシーポリシーにあり、会社の設立は2004年と公式の会社情報に書かれています。

この記事は、Movavi の日本語公式サイト(movavi.com/jp)の購入ページ・体験版の制約・返金ポリシー・動作環境・会社情報・プライバシーポリシーを**2026年11月6日に確認**して整理したものです。当サイトでは実機・実サービスを検証していません。

## 無料版(体験版)の制限

公式の「Movavi ソフトウェア体験版での制限事項」のページと、製品ページの注記(2026年11月6日確認)をまとめました。

| 項目 | 体験版の制限 |
| --- | --- |
| 透かし | 書き出した動画に「体験版」の透かしが入る |
| 動画の書き出し | 最大60秒まで |
| 音声の書き出し | 元の長さの半分まで |
| 機能 | 一部の高度な機能は使えない |
| 使える日数 | Video Editor の項目には日数の記載なし(Video Suite や Screen Recorder などは「7日間の体験期間」と記載) |

- 体験版の説明ページの冒頭には、試用版は「インストール後、指定された日数しか使用できず、その他の制限が含まれる場合がある」と書かれています。一方で、Video Editor(Windows・Mac)の項目には日数が書かれていません。日数が気になる場合は、ソフトの表示か公式のサポートで確かめてください。
- 制限を外すには、アクティベーションキーを買ってソフトに入力します。公式には、**再インストールは要らない**と書かれています。
- 返金ポリシーには「すべてのプログラムは全機能を備えた体験版として提供されているので、十分に検討したうえで購入を決定できる」とあります。返金の条件が厳しめなので、**買う前に体験版で、手持ちのパソコンで動くかと、60秒までの書き出しで仕上がりを確かめる**のが無駄のない順番です。

別の製品として「Movavi Video Editor Lite」(1,500円の表示、隅に小さな透かしが入ると案内)もありますが、確認した製品ページには契約の期間が書かれていなかったため、この記事の比較からは外しました。

## 返金の条件

公式の返金ポリシー(2026年11月6日確認)では、払い戻しの申請は**購入後14暦日以内**、または「サブスクリプションを購入してから3暦日以内」と書かれています。購入ページには「技術的問題またはその他の問題が発生し、解決できない場合、購入から14日以内であれば全額返金」と表示されています。

| 返金を受けられる場合(公式の要旨) | 返金されない場合(同) |
| --- | --- |
| 技術的な問題が続き、サポートが14暦日以内に解決できなかった | 体験版で使える機能(または機能がないこと)に満足できない |
| 同じプログラムを14暦日以内に誤って2回買った(片方を全額返金) | 購入について気が変わった |
| ライセンス認証の問題で、依頼から24時間以内に返信がなかった | プログラムが不要になった |
| Movavi が提供を終えたなどで、支払い済みの期間を使えない(未使用分を返金) | 購入後に、より望ましいプログラムを見つけた |

- 返金は、サポートが申請を確認してから10営業日以内に、銀行またはクレジットカードの口座に戻ると案内されています。
- この条件は **Movavi のサイトで直接買った場合だけ**に当てはまります。販売店やオンラインのパートナーストアで買った場合は、その販売店の条件に従います。
- 取引手数料などは返金の対象外です。

## よくある質問

### Movavi Video Editor は買い切りで買えますか。

買えます。2026年11月6日の公式購入ページでは、Video Editor Plus の「永久ライセンス」が18,200円(税込)で表示されています。ただし「更新なしで現在のバージョンに永久アクセス」と書かれていて、新しい版は追加料金で買う形です。

### 無料版はいつまで使えますか。透かしは消せますか。

公式の体験版の制限の一覧では、Video Editor の項目に使える日数は書かれていません。書き出した動画には「体験版」の透かしが入り、動画は60秒までしか書き出せません。透かしを消すには、アクティベーションキーを買ってソフトに入力します(再インストールは不要と案内)。

### 1年のプランは自動で更新されますか。解約の方法は。

公式ヘルプでは、サブスクリプションの期限が切れる前に、自動で請求されることを知らせるメールが届くと案内されています。解約は、Movavi アカウントにログインし、「プログラム」「効果」「サービス」のタブから対象を選んでキャンセルします。Movavi Effects の無料体験も始めていた場合は、別にキャンセルが必要です。

### 返金はしてもらえますか。

購入から14日以内で、技術的な問題がサポートで解決しなかった場合や、誤って二重に買った場合などが対象です。「気が変わった」「不要になった」「体験版で見られる機能に満足できない」は対象外と、公式の返金ポリシーに書かれています。

### Movavi はどこの国の会社ですか。

公式のプライバシーポリシーでは、事業者は Movavi Software Limited で、登記上の所在地はキプロスのリマソールと書かれています。
