## この記事の結論

AIの英文校正と人の英文校正は、どちらが上というより**向いている文書が違います**。

| | AIの英文校正(Grammarly・DeepL Write など) | 人の英文校正(ネイティブチェック) |
| --- | --- | --- |
| 料金のかかり方 | 無料版あり。有料版は月額の定額 | 1単語あたりの従量(または回数券・定期券) |
| 返ってくるまで | その場ですぐ | 数時間〜2日程度(分量による) |
| 直してもらえる範囲 | 文法・スペル・句読点、言い換えの提案 | 上記に加え、文脈・意図・読み手に合った表現 |
| 何度も直すとき | 何度でも試せる | 依頼のたびに費用がかかる |
| 責任の置き方 | 採用するかどうかは自分で判断 | 人が読んだ結果として受け取れる |

- **毎日のメール、社内向けの英文、下書きの段階** → AIの英文校正で十分なことが多い。回数を気にせず直せる
- **契約書・対外的な提案書・論文の投稿・発表資料など、誤解されると困る英文** → 人の校正を入れる。AIは「文法として正しいか」は拾えても、「その文書の目的に合っているか」までは保証しない
- **両方使う場合**は、AIで単純な誤りを取ってから人に出すと、人の校正で意図や表現の確認に集中してもらえる

この記事の料金・条件は、各社の公式サイトを**2026年10月23日**に確認したものです。当サイトは実際に使った検証はしていません。公式の公開情報を整理した記事です。料金は変わることがあるため、申し込む前に公式サイトで最新の表示を確かめてください。

## AIの英文校正:代表的な2つ

### Grammarly

英文の文法・スペルの誤りを直し、文章のトーン(印象)を表示するツールです。公式の料金ページ(2026年10月23日確認)では次のとおりです。

| プラン | 料金 | 主な内容 |
| --- | --- | --- |
| Free | 0ドル | 誤りの修正、トーンの表示、AIによる文章生成が月100回 |
| Pro | 12ドル(料金ページの表示) | 文全体の書き換え、トーンの調整、盗用とAI生成文の検出、AIによる文章生成が月2,000回 |
| Enterprise | 要問い合わせ | 組織向けの管理・セキュリティ機能 |

Pro の請求の周期(月払い・年払い)は、料金ページの表示からは読み取れませんでした。申し込み画面で確認してください。

**日本語の扱い**:公式ヘルプでは、英語に加えて日本語を含む24言語で修正の提案に対応し、無料版を含むすべてのプランで使えるとされています。ただし、段落ごとの書き換えに対応するのはスペイン語・フランス語・イタリア語・ドイツ語・ポルトガル語・ウクライナ語で、日本語は含まれていません。英文の校正が主な用途です。

### DeepL Write

翻訳サービスの DeepL が提供する文章の推敲ツールです。公式ヘルプでは、文法・スペル・句読点の修正と、別の語や表現の提案を行うと説明されています。対応言語には英語(UK・US)と日本語が含まれます。

| 使い方 | 1回に処理できる文字数 | 料金(2026年10月23日 公式サイトで確認) |
| --- | --- | --- |
| 無料(有料アカウントなし) | 1,500文字まで | 0円 |
| DeepL Pro(翻訳の有料プラン)の利用者 | 2,000文字まで | Individual は月1,150円相当(年払い) |
| DeepL Write Pro | 制限なし | アドオンとして月1,150円(年払い) |

公式ヘルプでは、**DeepL Pro(翻訳)の契約だけでは DeepL Write の有料版は含まれない**と注意書きがあります。Write Pro では、ログイン中に入力した文章が保存されないことも説明されています。社外に出していない文章を推敲するなら、この点は確認しておきたいところです。

DeepL の翻訳機能については[DeepLレビュー](/reviews/deepl-review/)、Grammarly の詳細は[Grammarlyレビュー](/reviews/grammarly-review/)にまとめています。

## 人の英文校正:アイディービジネスの場合

人が見る英文校正の例として、アイディービジネス(公式サイト idiy-biz.com)の公式の表示を整理します。

### 担当者を2種類から選べる

| | ネイティブ | 英語専門家 |
| --- | --- | --- |
| 入稿するもの | 英文 | 英文 + 元の日本語 |
| 補足の指示・質問 | 英語で行う | 日本語で行う |
| 向いている場面 | 英文として自然か、伝わり方を整えたい | 日本語で伝えたかった内容に沿って直してほしい |

公式サイトでは、英語専門家に日本語の原稿も一緒に渡すと、伝えたい内容をもとに表現を提案したり、不要な部分を大きく削ったりできると説明されています。英語に自信がなく、「元の日本語の意図どおりになっているか」を見てほしい場合は、英語専門家を選ぶ形です。医療・薬学、法務・行政、産業・工学・IT など、専門分野の英文にも対応するとされています。

### 料金(2026年10月23日 公式サイトで確認)

料金はポイント制で、**校正は1単語あたり1.5ポイント**です。担当者(ネイティブか英語専門家か)や英文の種類で価格は変わりません。1ポイントの価格は、まとめて買う量で変わります。

| 購入するポイント | 1ポイント(税込) | 1単語あたり(税込の目安) |
| --- | --- | --- |
| 100pt以上 | 13.20円 | 約19.8円 |
| 500pt以上 | 11.00円 | 約16.5円 |
| 1,000pt以上 | 9.79円 | 約14.7円 |

- 50単語未満の原稿も、50単語分のポイントがかかります。1回に出せるのは2,000単語までです。
- 購入したポイントの有効期限は、購入日・利用日から180日です。
- 無料のメンバー登録で100ポイント(公式サイトでは1,200円相当)がもらえます。

**分量ごとの納期と料金の例**(公式サイトの表。1ポイント9.79円で換算した目安)

| 単語数 | 納期の目安 | 料金の例(税込) |
| --- | --- | --- |
| 100単語 | 3時間以内 | 1,469円 |
| 200単語 | 5時間以内 | 2,937円 |

公式サイトの説明では、校正者が見つからず手配の時間内に担当が決まらなかった場合は、原稿とポイントが戻されます。納品後1週間は、質問や誤訳の確認ができます(料金表では1回50ポイント、誤訳が含まれていた場合は返金と書かれています。ページによって表記が異なるため、申し込む前に確認してください)。

### 「327円から」の意味

トップページの「327円から」は、**定期券を使った場合の1回あたりの料金**です。

| 定期券 | 価格(税込) | 使える量 | 1回あたり(税込) |
| --- | --- | --- | --- |
| 50単語 | 10,780円 | 30日間、1日1回50単語まで | 359円(税抜327円) |
| 100単語 | 16,478円 | 30日間、1日1回100単語まで | 549円(税抜499円) |

定期券は**30日間毎日1回使った場合**に1回あたりが327円(税抜)になる計算で、最初に30日分をまとめて払います。毎日短い英文を書く人には割安ですが、月に数回しか使わないならポイントで都度払う方が安く済みます。50単語を超えた分は、ポイントと組み合わせて最大2,000単語まで出せるとされています。

## 文書の種類ごとの使い分け

| 文書 | おすすめの組み合わせ | 理由 |
| --- | --- | --- |
| 社内向けのメール・チャット | AIだけ | 回数が多く、多少の言い回しの差は問題になりにくい |
| 取引先への定型的なメール | AI(毎日使うなら人の定期券も検討) | 数十単語の短い英文が中心 |
| 対外的な提案書・プレスリリース | AIで下ごしらえ → 人の校正 | 読み手に合った表現かを人に確かめてもらう |
| 契約書・規約 | 人の校正(専門分野に対応する担当者) | 1語の違いで意味が変わる。AIの提案をそのまま採用しない |
| 論文・学会の抄録 | AIで下ごしらえ → 人の校正 | 投稿先の規定(英文校正の証明書が要るか等)も先に確認する |
| 英語学習の作文 | AI、または解説つきの添削サービス | 直された理由を知ることが目的 |

### 費用の比べ方(例)

たとえば300単語の英文を月に4本、人に校正してもらう場合、公式の料金で計算すると、300単語は450ポイント、4本で1,800ポイントです。1,000ポイント以上をまとめて買うと1ポイント9.79円なので、**月に約17,600円(税込)**になります。同じ量をAIで直すなら、Grammarly の無料版や DeepL Write の無料版の範囲でも始められます。

この差をどう考えるかは、**その英文の誤りがどれだけの損につながるか**で決まります。社内メモなら AIで十分で、契約や論文の採否にかかわる英文なら、人の確認の費用は安全のための費用と考えやすくなります。

## どちらを使う場合も確かめたいこと

1. **入力してよい文章か。** AIのサービスにも人の校正サービスにも、文章を外部に送ることになります。社外秘の資料や個人情報を含む文書は、勤め先の取り扱いの決まりと、各サービスのプライバシーに関する説明を先に確認してください。DeepL Write Pro は、ログイン中に入力した文章を保存しないと説明しています。アイディービジネスの公式サイトにも「個人情報配慮」のページがあります。
2. **直された理由を自分で確かめる。** AIの提案も人の修正も、元の意図からずれていないかは書いた本人にしか分かりません。数値・固有名詞・否定の位置は必ず見直してください。
3. **翻訳と校正を混同しない。** 日本語から英文を作るなら翻訳、英文を整えるなら校正です。訳から始める場合の道具選びは[AIライティング・英文校正5種の比較](/reviews/ai-writing-proofreading-comparison/)にまとめています。

## よくある質問

**Q. AIの英文校正と人の英文校正は何が違いますか。**
AIはその場で何度でも、文法・スペル・句読点の誤りや言い換えを提案できます。人の校正は時間と費用がかかる代わりに、文脈や読み手に合った表現か、元の意図どおりかまで見てもらえます。誤解されると困る英文ほど、人の確認を入れる意味が大きくなります。

**Q. 英文校正サービスの料金はどれくらいですか。**
アイディービジネスの場合、1単語1.5ポイントで、1単語あたり約14.7〜19.8円(税込、ポイントの購入量による)です。100単語なら約1,469円、納期は3時間以内が目安とされています(2026年10月23日 公式サイトで確認)。

**Q. 無料で英文校正する方法はありますか。**
Grammarly の無料版は文法・スペルの誤りの修正に対応し、DeepL Write は有料アカウントがなくても1回1,500文字まで推敲できます。人の校正では、アイディービジネスが無料登録で100ポイント(100単語の校正に使うと150ポイントかかるため、短い英文向け)を配っています。

**Q. Grammarly は日本語の文章にも使えますか。**
公式ヘルプでは、日本語を含む24言語で修正の提案に対応するとされています(2026年10月23日確認)。ただし、段落ごとの書き換えは日本語に対応していません。日本語の推敲を主な目的にするなら、日本語に対応した推敲ツールや汎用のAIチャットも比べてみてください。[QuillBotレビュー](/reviews/quillbot-review/)もあわせて参照してください。
