## この記事の結論

**Canva Pro(有料版、日本語の画面では「Canvaプロ」)の料金は、1人あたり月1,180円、または年11,800円です。** 無料トライアルは30日間(約1ヶ月)あり、支払い方法を登録して始めた場合は、終わる前に解約しないと自動で有料に切り替わります。複数人で使う Canvaビジネスは月1,880円・年18,800円で、ブランドキット・容量・AIの利用枠が多く、メンバーで素材を共有できる点が違います(2026年11月27日に公式の料金ページ・解説記事で確認)。

- Canva Pro(日本語の画面では「Canvaプロ」)の料金は**年11,800円、または月1,180円(1人あたり)**。1つのアカウントを使えるのは1人だけ(2026年11月23日に公式の料金ページで確認。11月3日から変更なし)
- 料金ページでは、**月払いの最初の3か月が50%オフ(月590円)になる期間限定のキャンペーン**が2026年12月4日まで案内されている。無料トライアルとは併用できない
- **無料トライアルは30日間**。支払い方法を登録して始めた場合は、トライアルが終わる前に解約しないと自動で請求される。請求はGMT(グリニッジ標準時)基準
- 無料版との違いは、テンプレート160万点以上→360万点以上、素材470万点以上→1億4,100万点以上、AIの利用枠が無料版の10倍、ブランドキット1つ→5個、容量5GB→100GB
- 定期プランは、ヘルプセンターで**ほとんどの場合払い戻しできない**とされている。解約しても支払い済みの期間の終わりまでは有料機能を使える
- 日本の**大学・専門学校の学生**、幼小中高の教員と児童生徒、認定を受けた**非営利団体**には、有料の機能を無料で使えるプランがある
- 作ったデザインは商用に使えるが、素材の再販売、ロゴや商標への利用、素材を単体でTシャツなどにして売ることは使用許諾契約で禁止されている

この記事は、Canvaの日本語の料金ページ・Canvaプロのページ・ヘルプセンター・解説記事・使用許諾契約・国別の税のページを2026年11月23日に確認してまとめたものです。当サイトでは Canva を操作して確かめてはいません。

## Canva Pro(Canvaプロ)とは

Canva は、テンプレートに文字や写真を差し替えてSNSの投稿画像・資料・チラシ・動画などを作るデザインツールです。無料版でも多くのテンプレートが使え、Canvaプロはその**個人向けの有料プラン**です。料金ページでは、プレミアムのテンプレートと素材、背景透過やサイズ変更などのツール、多めのAIの利用枠が使えるプランとして案内されています。

複数人で使う場合は、同じ素材やブランドキットを共有できるCanvaビジネス(旧Canvaチームス)が別にあります。

## 無料トライアルと自動更新(1ヶ月無料で使えるか)

「Canva 1ヶ月無料」と言われるのは、Canvaプロの30日間の無料トライアルのことです。Canvaの解説記事に「30日間」と書かれています(2026年11月27日確認)。

| 項目 | 公式の説明 |
| --- | --- |
| トライアル期間 | Canvaプロは30日間(解説記事、2026年10月12日更新) |
| トライアル中のAI | AIの利用枠は無料版と同じ。有料プランが始まると10倍の利用枠になる |
| トライアルが終わったら | プランは自動更新される。トライアルが終わる前に解約しない限り料金が請求される |
| 支払い情報なしで始めた場合 | トライアル期間は自動的に終わり、請求は発生しない |
| 請求の時刻 | 料金はGMTに従うため、日本時間ではトライアル終了の前日に請求が表示されることがある |
| 12月4日までの50%オフとの関係 | 無料トライアルとは併用できない(料金ページ) |
| Canvaビジネスのトライアル | 料金ページのよくある質問で、プロ・ビジネスとも無料トライアルを始められると案内され、ビジネスのトライアル中にメンバーを招待しても請求は発生しないと書かれている。ビジネスのトライアルの日数は確認したページに記載なし |

自動更新と支払い情報の扱いは、ヘルプセンターの「[なぜ請求されたのですか?](https://www.canva.com/ja_jp/help/unfamiliar-charge/)」の説明です。料金ページのトライアルのボタンには日数が書かれておらず、30日間という期間は解説記事の記載です。

## Canvaプロとビジネスの違い

料金ページの比較表とよくある質問の記載です(2026年11月27日確認。容量・ブランドキット・AIの倍率は11月23日の確認)。

| 項目 | Canvaプロ | Canvaビジネス |
| --- | --- | --- |
| 料金(1人あたり) | 月1,180円・年11,800円 | 月1,880円・年18,800円 |
| 使える人 | 1アカウントにつき1人だけ | 個人と小規模のチーム。招待を受け入れたメンバーの分だけ請求 |
| テンプレート・素材 | 360万点以上・1億4,100万点以上 | プロと同じ |
| ブランドキット | 5個 | 100個と承認機能 |
| クラウドストレージ | 100GB | 500GB |
| AIの利用枠 | 無料版の10倍 | 無料版の20倍 |
| カスタム短縮リンク | 最大5件 | 最大100件 |
| 料金ページでの位置づけ | 個人のクリエイター向け | 広告のパフォーマンス分析、強化されたブランド管理、チームの共同作業の機能 |

1人で使うならプロ、同じ素材やブランドキットを複数人で共有したい・承認の流れを作りたいならビジネス、という分かれ方です。素材とテンプレートの量は同じなので、1人で使う範囲ではビジネスにしても素材は増えません。

Canvaプロのページでは、写真の背景透過、マジックリサイズ(別の媒体のサイズに変える)、ブランドキット、マジック消しゴムなどが紹介され、よくある質問では「40以上のAIを活用したツール」と説明されています。

### AIの利用枠のしくみ

- AIの利用枠は**プランごとに異なり、毎月リセット**されます(料金ページのよくある質問)。
- 料金ページの注記では、枠を使うのは**標準・高品質・最高品質のモデルのAI機能**で、それ以外の機能(有料プランの標準モデルを含む)は使っても枠が減らないと書かれています。高度な機能や複雑な作業ほど枠を多く使います。
- 月の利用枠と同じ量を1回だけ追加で買える「AIチャージ」(有効期間30日)は、料金ページでは**Canvaビジネスでオンライン注文した人向け**と書かれています。料金は「追加料金がかかります」とだけあり、金額は書かれていません。
- さらに多く使う人向けの**AIパス**は1人あたり月100米ドルで、プロ・チームス・非営利団体の加入者はAI機能を40倍、ビジネスの加入者は20倍使えると[AIパスのヘルプ](https://www.canva.com/ja_jp/help/ai-pass/)に書かれています。無料版・教育版・エンタープライズ・無料トライアル中・プリペイドプラン・App Store/Google Play経由の契約は対象外です。
- 無料版で何回使えるかは、確認したページには数字で書かれていませんでした。

## 解約と返金

ヘルプセンターの「[Canvaプランを解約する](https://www.canva.com/ja_jp/help/cancel-canva-plan/)」と「[定期プランの払い戻し](https://www.canva.com/ja_jp/help/subscription-refunds/)」の要点です(2026年11月23日確認)。

- **解約の手順(ウェブ):** プロフィールのメニューから「設定」→「請求」に進み、プランの下の「プランをキャンセル」を選ぶ。
- **スマホのアプリで契約した場合:** アプリを消しても解約にはなりません。App Store などの定期購入の画面から解約します。
- **解約した後:** 今後の支払いは止まり、**今の支払い期間が終わるまでは有料機能を使えます。** その後は無料版に移り、デザインは引き続き使えます。
- **返金:** 定期プランは利用規約のとおり**ほとんどの場合払い戻しできない**とされています。申請は一件ずつ確認されます。Apple経由で契約した場合はAppleに申請します。

## 日本の消費税・インボイス

- 料金ページには、金額が税込か税抜かの表示がありませんでした(2026年11月23日確認)。
- ヘルプセンターの[国別の税のページ](https://www.canva.com/help/canva-sales-tax-per-country/)の日本の項目では、**事業者が購入時に有効な事業者登録番号を示せば、サブスクリプションの請求書に消費税は載らない**と書かれています。個人の契約の扱いは書かれていません。印刷物(Canvaプリント)には、すべての利用者に消費税を請求すると書かれています。
- Canvaの日本の適格請求書発行事業者の登録番号は、確認したページに書かれていませんでした。法人で仕入税額控除を受けたい場合は、最初の請求書の表示を確かめてください。

ほかの海外AIツールの消費税の扱いと登録番号は、[海外AIツールの消費税・インボイス対応一覧](/reviews/ai-tools-japan-consumption-tax-invoice/)にまとめています(国税庁の公表サイトで照合)。

## 商用利用とライセンスの注意点

Canvaの「[コンテンツ使用許諾契約](https://www.canva.com/ja_jp/policies/content-license-agreement/)」の主な内容です(2026年11月23日確認)。ここに書いたのは要点で、法的な助言ではありません。

**できること**

- 無料素材もプロ素材も、広告・販促物・印刷物などの商用のデザインに使える
- プロ素材は、有効な定期プランがあれば追加費用なしでライセンスが発行される

**禁止されていること(主なもの)**

- 素材を再販売・譲渡・貸与すること
- 素材を**商標・ロゴ・屋号などの一部として使う**こと(フォントを除く)
- 素材を**単体で**ポストカード・マグカップ・Tシャツ・ポスターなどのオンデマンド製品にして売ること
- プロ素材を単体のアイテムとしてコピー・ダウンロード・配布すること
- 機械学習やAIの目的に使うこと

**気をつけたい点**

- 1つのデザインに種類の違う素材が混ざっている場合は、**いちばん制限の厳しい条件がデザイン全体に適用**されます(厳しい順に、教育・ブランド・プロ・無料)。
- 「教育コンテンツ」は教育目的の非営利利用のみ、ディズニーの素材は個人用・教育目的のみです。「ブランドコンテンツ」は別の利用条件(Branded Content Terms)に従うとされています。
- プロの音楽素材は、テレビ・ラジオ・ポッドキャストなど有料チャネルの従来型の広告には使えない(オンライン広告は可)とされています。
- 確認したページは日本語の機械翻訳で、英語版と食い違う場合は英語版が優先すると書かれています。

AIで作った画像を仕事に使うときの確認事項は[AIツールの商用利用チェックリスト](/reviews/ai-commercial-use-checklist/)にまとめています。

## よくある質問

**Q. Canvaは1ヶ月無料で使えますか。**
Canvaプロには30日間(約1ヶ月)の無料トライアルがあります(Canvaの解説記事、2026年11月27日確認)。トライアル中のAIの利用枠は無料版と同じです。支払い方法を登録して始めた場合は、トライアルが終わる前に解約しないと自動で月1,180円または年11,800円の請求が始まります。12月4日までの月払い50%オフとは併用できません。

**Q. Canva Proの料金はいくらですか。**
日本語の料金ページでは、年払いで11,800円、月払いで1,180円(どちらも1人あたり)と表示されています(2026年11月23日確認)。12月4日までは、月払いの最初の3か月が50%オフ(月590円)のキャンペーンがあります。税込か税抜かの表示は、確認したページには見当たりませんでした。

**Q. 無料トライアルは何日間ですか。終わったら自動で請求されますか。**
Canvaの解説記事では、Canvaプロの無料トライアルは30日間とされています。支払い方法を登録して始めた場合、トライアルが終わる前に解約しないと自動更新で請求されます。支払い情報を出さずに始めたトライアルは、自動的に終わって請求されません。請求はGMT基準のため、日本時間では前日に表示されることがあります。

**Q. 無料版との一番大きな違いは何ですか。**
使える素材とテンプレートの量です。料金ページでは、無料版のテンプレート160万点以上・素材470万点以上に対して、プロはテンプレート360万点以上・素材1億4,100万点以上とされています。ほかに、AIの利用枠(無料版の10倍)、ブランドキット5個、ストレージ100GBが加わります。

**Q. Canva ProとCanvaビジネスはどちらを選べばよいですか。**
Canvaプロは1つのアカウントを1人だけが使えるプランです。複数人で素材やブランドキットを共有し、承認の流れを作りたいならCanvaビジネス(年18,800円・1人)が想定されています。ビジネスはAIの利用枠が無料版の20倍、ストレージが500GBです。

**Q. 学生は無料で使えますか。**
日本の大学・専門学校の学生は、学校のメールアドレスで登録すると、プレミアムのテンプレート・素材や背景透過などを無料で使えるプランがあります(毎年の在学確認、最大4年)。幼小中高の教員と児童生徒はCanva教育版を無料で使えます。

**Q. 途中で解約したら返金されますか。**
ヘルプセンターでは、定期プランはほとんどの場合払い戻しできないとされています。解約すると次回以降の請求が止まり、支払い済みの期間が終わるまでは有料機能を使えます。

**Q. 作ったデザインを商用に使えますか。**
使えます。ただし、素材をそのまま再販売する、ロゴや商標に使う、素材を単体でTシャツやマグカップにして売る、といった使い方はコンテンツ使用許諾契約で禁止されています。素材の種類ごとに条件が違うものもあるため、仕事で使う前に契約の本文を確かめてください。
