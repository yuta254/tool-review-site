## この記事の結論

Aiarty Image Enhancer は、**パソコンにインストールして使う画像の高画質化ソフト**です。拡大(アップスケール)、ノイズ除去、ぼやけの補正、細部の補正などを、AIでまとめて行います。

- **無料版でもAI処理そのものは使える**。有料版との大きな違いは、**複数の画像をまとめて書き出す機能(一括書き出し)**が使えるかどうか(公式FAQの記載)。
- 処理はパソコンの中で完結し、画像を外部のサーバーに送らないと公式サイトに書かれている。人物写真や社外に出せない画像を扱うときに選ぶ理由になる。
- 料金は年間プランと買い切り(永久ライセンス)がある。2026年10月21日の公式ストアの表示では、永久版(パソコン3台)が **7,880円(税込)** のキャンペーン価格だった。

この記事は公式サイト(jp.aiarty.com)の記載を2026年10月21日に確認して整理したもので、当サイトでソフトを使った検証はしていません。

## できること

公式サイトでは、主に次の機能が紹介されています。

| 機能 | 公式サイトの説明(要旨) |
| --- | --- |
| 拡大(アップスケール) | 最大8倍までの拡大プリセットで、最大32K解像度で書き出せる |
| ノイズ除去 | 高ISOで撮った写真などのノイズや粒子を自動で除去する |
| ぼやけの補正 | ぼやけた画像や柔らかい画像を鮮明にする |
| 細部の補正 | 髪の毛・肌・建物などの細かい部分を補正する |
| 顔の補正 | 実写やAI生成画像の顔を自然に整える |
| 色の補正 | 色合いを補正する |

用途に合わせて複数のAIモデル(公式ページでは「More-Detail GAN」「Real-Photo」などの名前)を切り替えて使う作りです。

### 「拡大」はどこまで信じてよいか

AIによる拡大は、元の画像に無い細部をAIが**推定して描き足す**処理です。見た目は鮮明になりますが、描き足された部分が実物と同じとは限りません。

- **向いている**:ブログやECの画像を大きく見せたい、古い写真を見やすくしたい、AIで作った画像を印刷用に大きくしたい
- **向いていない**:文字や番号を正確に読み取る必要がある画像、記録・証拠として使う写真。補正後の画像だけを残さず、元の画像も必ず保存しておいてください

## 無料版と有料版の違い

公式の「購入に関するFAQ」(2026年10月21日確認)には、次のように書かれています。

| | 無料版 | 有料版(年間プラン・永久ライセンス) |
| --- | --- | --- |
| AIによる画像処理 | 使える | 使える |
| 一括書き出し(複数の画像をまとめて書き出す) | 使えない | 使える |
| 使えるパソコンの台数 | — | 最大3台(公式ストアの表示) |
| 期限 | — | 年間プランは1年ごとの自動更新、永久ライセンスは期限なし |

- 年間プランは自動更新で、FAQでは更新の7日以上前に通知が届くとされています。期限が切れると、ソフトの更新はできても有料版の機能は使えなくなる、と説明されています。
- 無料版で手持ちの画像を1枚ずつ試し、**枚数が多くて1枚ずつでは手間になる**と分かってから有料版を考える、という順番で無駄がありません。

| | Windows | Mac(Intel) | Mac(Appleシリコン) |

## よくある質問

**Q. 無料版だけで使い続けられますか。**
公式FAQでは、無料版でもAIによる画像処理が使えるとされています。違いは一括書き出しなので、1枚ずつ処理して困らない枚数なら無料版で足りる場合があります。最新の制限は公式サイトで確認してください。

**Q. 画像がネットに送られることはありますか。**
公式サイトでは、完全にオフラインで動作し、処理する画像データが外部のサーバーに送られることはないと説明されています。社外に出せない画像を扱う場合は、社内のルールもあわせて確認してください。

**Q. AI生成画像を拡大して商用で使えますか。**
高画質化ソフトの使い方とは別に、元の画像を作った生成AIの規約で商用利用が認められているかを確かめる必要があります。考え方は[AIで作ったものを商用利用する前のチェックリスト](/reviews/ai-commercial-use-checklist/)にまとめました。

**Q. スマートフォンで使えますか。**
この記事で確認した動作環境ページは、Windows と Mac のデスクトップ版が対象です。スマートフォンで使えるかどうかは、公式サイトで最新の案内を確認してください。
