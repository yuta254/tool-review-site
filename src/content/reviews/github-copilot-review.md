## 総評

GitHub Copilotは「ゼロから書く」よりも「途中から続きを書く/定型処理を自動補完する」場面に強いツールです。いつものエディタ(VS Code / JetBrains系など)に組み込んで使えるため、開発環境を変えずに導入できるのが最大の利点です。

一方で、2026年は料金の仕組みが大きく変わりました。**6月1日から、チャットやエージェントの利用は「AIクレジット」で数える従量制に移行**しています(コード補完はクレジットを使いません)。評価そのものより先に、「自分の使い方だと月いくらになるか」「入力したコードがどう扱われるか」を確認しておくのが、導入で失敗しないための近道です。

この記事の料金・条件は、GitHubの公式料金ページ(github.com/features/copilot/plans)、公式ドキュメント(docs.github.com)、公式ブログ・変更履歴を **2026年10月27日** に確認して整理したものです。当サイトは実際の開発現場での計測は行っておらず、公式情報と公開資料をもとにまとめています。

組織で導入したあとに「効果があったか」を数字で示す方法(公式のダッシュボードとAPIで見られる指標、導入前後の比べ方)は、[GitHub Copilotの導入効果測定の方法](/reviews/github-copilot-impact-measurement/)に分けてまとめました。

## 得意なこと

- テストコードのひな形作成
- 既存コードと似たパターンの繰り返し実装
- 見慣れない言語・フレームワークでの書き方の参考
- (有料プラン)プルリクエストのコードレビューの補助、課題を渡してプルリクエストを作らせるコーディングエージェント

## 過信は禁物な点

- 生成されたコードをそのまま鵜呑みにせず、必ずレビューする前提が必要
- セキュリティやライセンスに関わるコードは人間の最終確認が必須
- 学習目的で「自分の手で書く力」を伸ばしたい初学者は、頼りすぎに注意
- エージェントや長いチャットは多くのAIクレジットを使う。従量制の今は、使い方しだいで月額を超える費用がかかり得る(後述)

## 料金プラン(2026年10月27日 公式確認)

| プラン | 料金(米ドル) | 毎月含まれるAIクレジット | 主な違い |
| --- | --- | --- | --- |
| Free | 無料 | 少量(公式は「限定的」と表記) | コード補完は月2,000回まで。追加クレジットは買えない。組織経由でCopilotを使える人は対象外 |
| Pro | 月10ドル | 15ドル分(基本10ドル+変動枠5ドル) | コード補完は無制限。プルリクエストのコードレビュー、クラウドのコーディングエージェント |
| Pro+ | 月39ドル | 70ドル分(基本39ドル+変動枠31ドル) | Proの内容に加え、他社のコーディングエージェント(プレビュー) |
| Max | 月100ドル | 200ドル分(基本100ドル+変動枠100ドル) | Pro+と同じ機能で、含まれるクレジットが多い |
| Business | 1ユーザー月19ドル | 1ユーザー19ドル分 | 組織での管理(ポリシー・監査ログ・除外設定)、クレジットを組織で共有 |
| Enterprise | 1ユーザー月39ドル | 1ユーザー39ドル分 | Businessの内容に加えた企業向け機能 |

- **AIクレジットは1クレジット=0.01ドル**。チャット・エージェントなどの利用は、使ったモデルのトークン量(入力・出力・キャッシュ)に応じてクレジットが減ります。**コード補完と「次の編集の提案」はクレジットを使いません。**
- Pro以上は、使い切った後に追加のクレジットを購入でき、予算(ドル)の上限と通知(75%・90%・100%)を設定できます。Freeは追加購入ができず、翌月のリセットを待つか軽いモデルに切り替えます。
- BusinessとEnterpriseは、管理者が利用上限や「含まれる分を超えた利用を認めるか」を決めます。公式の料金ページでは営業窓口の案内になっており、価格はドキュメントと変更履歴に記載があります。
- **学生は認証を受ければ「Copilot Student」を無料で使えます。** 認証を受けた教師や、利用者の多いオープンソースの管理者は、Proを無料で使える場合があります(公式ドキュメントより)。
- **Proの無料トライアルは、2026年4月から一時停止中**と公式の変更履歴に記載があります(不正利用への対策のため。再開時期は未定)。試すならまずFreeプランで、自分のエディタと作業に合うかを確認するのが確実です。

料金は米ドル建てです。円での支払額は為替と決済方法で変わるため、契約前に購入画面の表示を確認してください。

### 2026年6月の料金の仕組みの変更

公式ブログ・変更履歴(2026年4月27日)によると、**2026年6月1日に全プランが従量制(AIクレジット)へ移行**しました。それまでの「プレミアムリクエスト」の回数制は、AIクレジットに置き換わっています。

- 月払いのPro・Pro+は6月1日に自動で新しい仕組みへ移行。
- 年払いのPro・Pro+は、契約が切れるまで従来のプレミアムリクエスト制のまま(ただしモデルごとの倍率は6月1日に引き上げ)。契約終了後はFreeに移り、月払いの有料プランに切り替えられます。
- Business・Enterpriseはクレジットを組織内で共有でき、企業・コストセンター・ユーザー単位で予算を設定できます。

古い記事や比較表にある「プレミアムリクエストが月何回」という説明は、現在の個人の月払いプランには当てはまりません。

## 入力したコードは学習に使われるか(2026年10月27日 公式確認)

GitHubは2026年3月に、Copilotの「インタラクションデータ」(入力・出力・コード片・周辺のコードなど)の扱いを変更すると公式ブログで発表しました。

- **2026年4月24日から、Free・Pro・Pro+の利用者のインタラクションデータは、オプトアウトしない限りAIモデルの学習・改善に使われます。** 設定(github.com/settings/copilot)のプライバシーの項目で止められます。以前に製品改善のためのデータ収集をオプトアウトしていた場合、その設定は引き継がれます。
- **Business・Enterpriseの利用者は、この変更の対象外です。**
- Issue・ディスカッション・保存されているプライベートリポジトリの内容は学習に使われません。ただし、Copilotを使っている最中に処理されるプライベートリポジトリのコードは、インタラクションデータに含まれます。
- 有料のOrganizationのリポジトリの内容は、Free・Pro・Pro+の利用者が作業していても学習には使われないと説明されています。

会社のコードを扱うなら、**個人プランではなくBusiness以上を会社として契約する**のが基本です。個人プランを業務に使う場合は、少なくとも学習の設定をオフにし、社内の規程で許されているかを確認してください。

## 向いている人

- 普段からエディタ(VS Code / JetBrains系)で開発している人
- 定型的なコードやテストを書く頻度が高い人
- 一人で開発していて、レビュー役が近くにいない人(有料プランのコードレビュー補助を使う場合)
- 会社で導入する場合は、管理機能と学習の扱いの点でBusiness以上を選べる組織

## 向いていない・別のツールを検討したい人

- エディタごと乗り換えて、コードベース全体を前提にした提案を受けたい人 → [Cursor](/reviews/cursor-review/)など
- 課題をまるごと渡して任せたい人 → [AIエージェントの比較](/reviews/ai-agent-tools-comparison/)も参照
- AWS中心の開発 → AWSは Amazon Q Developer の新規受付を2026年5月に止め、後継として Kiro を案内しています([Amazon Q Developerの現状](/reviews/amazon-q-developer-review/))

ツールごとの違いは[AIコーディングツールの比較](/reviews/ai-coding-tools-comparison/)にまとめています。

## 導入前に確認すること

1. **Freeプランで合うか確かめる**: 補完の回数(月2,000回)とチャットの範囲で、自分の作業に効くかを見る。Proの無料トライアルは停止中(2026年10月27日時点)。
2. **月の費用の上限を決める**: Pro以上は追加クレジットの予算を設定できる。エージェントを多用するなら、上限と通知を先に設定しておく。
3. **会社で使うならBusiness以上**: 学習の扱い、管理者のポリシー、監査ログの点で個人プランとは前提が違う。
4. **レビューの運用を決める**: AIが書いたコードのチェック項目をコードレビューに足す。
5. **効果を測る準備をする**: 導入前の数字(プルリクエストの数、マージまでの時間など)を取っておく。方法は[GitHub Copilotの導入効果を測る方法](/reviews/github-copilot-impact-measurement/)にまとめました。

チーム全体での利用を検討する場合は、[AI API料金計算ツール](/tools/ai-api-cost-calculator/)で人数分の想定コストを事前に試算しておくと予算感がつかみやすくなります。

## よくある質問

**Q. GitHub Copilotは無料で使えますか。**
使えます。Freeプランはコード補完が月2,000回まで、チャットやエージェントは少量です。認証を受けた学生はCopilot Studentを無料で使えます。

**Q. ProとPro+はどちらを選べばよいですか。**
違いは毎月含まれるAIクレジットの量(Proは15ドル分、Pro+は70ドル分)と、他社のコーディングエージェントを使えるかどうかです。コード補完が中心ならPro、エージェントやチャットを多く使うならPro+、という分け方になります(2026年10月27日 公式確認)。

**Q. 実際にどれくらい速くなりますか。**
定型的なコード(テスト、ボイラープレート、既知のAPI呼び出し)ほど効果が大きく、設計判断が要る部分ではほとんど変わらない、というのが一般的な見方です。「全体が何割速くなる」より「どの作業が消えるか」で見たほうが導入判断を誤りません。GitHub自身も、公式ダッシュボードのプルリクエストとの関係は因果の証明ではないと説明しています。組織で導入効果を数字で確かめる方法は[GitHub Copilotの導入効果を測る方法](/reviews/github-copilot-impact-measurement/)にまとめました。

**Q. 提案されたコードをそのまま使って問題ありませんか。**
動くコードが出てくることと、正しいコードであることは別です。特に境界値の扱いとエラー処理は補完が甘くなりやすく、レビューを省略すると後で効いてきます。

**Q. 会社のコードを学習に使われませんか。**
Business・Enterpriseの利用者は、2026年4月24日からの学習の変更の対象外です。Free・Pro・Pro+はオプトアウトしない限り学習に使われるため、個人プランを業務で使う場合は設定の確認が必須です(2026年10月27日 公式確認)。

料金・プランの内容は変更されることがあります。契約の前に、GitHubの公式料金ページで最新の情報を確認してください。
