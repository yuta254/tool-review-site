## この記事の結論

- 個人の有料プランは Pro 月10ドル・Pro+ 月39ドル・Max 月100ドル、組織向けは Business 1席月19ドル・Enterprise 1席月39ドル(2026年11月22日 公式で確認。前回11月12日から金額の変更なし)
- チャットとエージェントは「AIクレジット」(1クレジット=0.01ドル)で数える従量制。コード補完と次の編集の提案はクレジットを使わない
- 日本で自分でカード・PayPal払いをする人には、2024年10月1日から消費税10%が加算され、請求書に GitHub Inc. の登録番号(T4700150079306)が載る(公式の変更履歴)
- 個人向けの Free・Pro・Pro+ の入力は、オプトアウトしない限りAIの学習に使われる。Business・Enterprise は対象外
- Pro の無料トライアルは2026年4月から停止したまま。再開の告知は確認日時点で見当たらない
- 前回からの変化は「Copilot Fusion」(タスクごとにモデルを選ぶ仕組み)の追加と、11月30日までの有料プラン向け30%引き

この記事の料金・条件は、GitHubの[公式料金ページ](https://github.com/features/copilot/plans)、[公式ドキュメント](https://docs.github.com/en/copilot/get-started/plans)、公式の変更履歴を **2026年11月22日** に確認して整理したものです。当サイトでは実機・実サービスを検証していません。操作した感想や生成されるコードの質の評価は書かず、公式に書かれていることと書かれていないことを分けて並べます。

[GitHub Copilot](https://github.com/features/copilot)は、VS Code・Visual Studio・JetBrains系・Xcode・Neovim・Eclipse・Zed などのエディタに組み込んで使うコーディング支援です(公式料金ページの対応環境の欄)。ターミナル(Copilot CLI)、github.com、GitHub Mobile、Slack・Teams からも使えると公式のよくある質問に書かれています。

## 料金プラン(2026年11月22日 公式確認)

| プラン | 料金(米ドル・税別) | 毎月含まれるAIクレジット | 主な違い |
| --- | --- | --- | --- |
| Free | 0ドル | 少量(公式は「チャットおよびエージェント機能の利用制限あり」) | コード補完は月2,000回まで。モデルは自動選択のみ。追加クレジットは買えない。組織経由でCopilotを使える人は対象外 |
| Student | 0ドル(認証を受けた学生) | 少量 | モデルは自動選択のみ。他社のエージェントは対象外 |
| Pro | 月10ドル | 1,500(基本1,000+変動枠500)=15ドル分 | コード補完は無制限。プルリクエストのコードレビュー、クラウドのコーディングエージェント、モデルの選択 |
| Pro+ | 月39ドル | 7,000(基本3,900+変動枠3,100)=70ドル分 | Opus などの上位モデル、監査ログ、Copilot Fusion の High・Max |
| Max | 月100ドル | 20,000(基本10,000+変動枠10,000)=200ドル分 | 新しいモデル・機能の優先利用。含まれるクレジットが最も多い |
| Business | 1席月19ドル | 1人あたり1,900(19ドル分) | 組織での管理(ポリシー・監査ログ・除外設定)、クレジットを組織で共有 |
| Enterprise | 1席月39ドル | 1人あたり3,900(39ドル分) | Business の内容に加えた企業向け機能。GitHub Enterprise Cloud の利用が前提 |
| Copilot access | Enterprise Cloud のライセンス保有者は0ドル、持たない人は「Copilot Standalone」として1人月10ドル | 含まれる分なし(最初から従量) | 対象の企業向け。機能とモデルは Enterprise と同じ扱い |

- 金額の出典は[公式料金ページ](https://github.com/features/copilot/plans)と[公式ドキュメントのプラン一覧](https://docs.github.com/en/copilot/get-started/plans)。クレジットの内訳(基本・変動枠)は[個人の従量課金の説明](https://docs.github.com/en/copilot/concepts/billing/usage-based-billing-for-individuals)にあり、変動枠は「今後変更される場合がある」と料金ページに書かれています。
- 含まれるクレジットは翌月に繰り越されず、毎月1日の0時(UTC)にリセットされます。
- Pro 以上は使い切った後に追加のクレジットを買えます(10ドルで1,000クレジット)。予算の上限を決められ、75%・90%・100%に達したときの通知を設定できると料金ページのよくある質問に書かれています。
- 他社のコーディングエージェント(Claude Code・Codex)は、料金ページの Pro の説明には「外部エージェントへのアクセス」とある一方、同じページの機能比較表では「サードパーティ コーディング エージェントにタスクを委任(プレビュー)」が Pro+ 以上になっています。前回(11月12日)と同じく、公式の表記がそろっていません。必要なら購入画面で確かめてください。
- 認証を受けた教師や、利用者の多いオープンソースの管理者は Pro を無料で使える場合がある、と公式ドキュメントに書かれています。

## 日本の消費税・インボイス

- 公式の[変更履歴(2024年8月1日)](https://github.blog/changelog/2024-08-01-japanese-consumption-tax-jct-on-your-github-account/)によると、**2024年10月1日から、日本でクレジットカードか PayPal で自分で支払う利用者に、日本の消費税10%がかかります。** 更新後の請求書には GitHub Inc. の登録番号(T4700150079306)と、消費税の額が米ドルと日本円の両方で表示されると書かれています。
- 料金ページ・ドキュメントの金額は米ドルで、消費税は含まれていません。たとえば Pro は月10ドルに10%が加わり、月11ドルが支払いの目安です。
- 請求書払い(営業経由の契約)の場合の消費税の扱いは、確認したページには書かれていませんでした。
- 円での支払額は、カード会社の為替と手数料で変わります。法人で仕入税額控除を受けるかどうかなど、個別の税務の扱いは税理士か税務署に確認してください。

ほかの海外AIツールの消費税の扱いと登録番号は、[海外AIツールの消費税・インボイス対応一覧](/reviews/ai-tools-japan-consumption-tax-invoice/)にまとめています(国税庁の公表サイトで照合)。

## 1年・2年の総額の試算

前提: 公式の月額×月数で計算。消費税10%を加えた額も並べる。含まれるクレジットを超えた追加購入は入れない。円は仮に1ドル=150円とした場合の目安です(実際の為替で変わります)。

| プラン | 1年(税別) | 1年(消費税込み) | 2年(消費税込み) | 2年の円の目安 |
| --- | --- | --- | --- | --- |
| Pro | 120ドル | 132ドル | 264ドル | 約39,600円 |
| Pro+ | 468ドル | 514.8ドル | 1,029.6ドル | 約154,440円 |
| Max | 1,200ドル | 1,320ドル | 2,640ドル | 約396,000円 |
| Business 5席 | 1,140ドル | 1,254ドル | 2,508ドル | 約376,200円 |
| Enterprise 5席 | 2,340ドル | 2,574ドル | 5,148ドル | 約772,200円 |

- 現在の料金ページには年払いの価格が表示されていません。公式ブログ(2026年4月)では、年払いの Pro・Pro+ は契約が切れるまで旧制度のまま、とされていました。
- Business・Enterprise の消費税の扱いは、支払い方法(カードか請求書か)で変わる可能性があります。上の表の税込みの列は、カード払いで10%がかかる場合の目安です。
- エージェントを多く使う場合は、含まれるクレジットを超えた分(1クレジット0.01ドル)が加わります。予算の上限を先に決めておくと、総額の上振れを抑えられます。

## 条件別の選び方

| 条件 | 行き先 | 理由(公式の仕様) |
| --- | --- | --- |
| まず自分のエディタで合うかを見たい | Free | 補完が月2,000回まで無料。Pro の無料トライアルは停止中 |
| 学生で認証を受けられる | Student | 無料。ただしモデルは自動選択のみで、他社のエージェントは対象外 |
| 補完が中心で、チャットは少し | Pro | 補完は無制限。含まれるクレジットは15ドル分 |
| エージェント・チャットを多く使う、上位モデルを選びたい | Pro+ | 70ドル分のクレジット、Opus などの上位モデル、Copilot Fusion の High・Max |
| 毎日長いエージェント作業を回す | Max | 200ドル分のクレジット(料金ページの表記は「Pro+ の2.9倍以上」。クレジットの数で計算すると 20,000÷7,000 で約2.86倍) |
| 会社のコードを扱う | Business 以上 | 学習の変更の対象外。管理者がポリシーと利用上限を決められる |
| GitHub Enterprise Cloud を契約している企業 | Copilot access か Enterprise | Copilot access はライセンス保有者の座席料金0ドルで、使った分だけ課金 |

## 入力したコードは学習に使われるか

GitHubは2026年3月に、Copilotの「インタラクションデータ」(入力・出力・コード片・周辺のコードなど)の扱いを変更すると公式ブログで発表しました(2026年10月27日に確認)。2026年11月22日の料金ページのよくある質問にも、同じ趣旨の内容が書かれています。

- **2026年4月24日から、Free・Pro・Pro+ の利用者のインタラクションデータは、オプトアウトしない限りAIモデルの学習・改善に使われます。** 止める設定は github.com/settings/copilot/features にあり、オプトアウトしても機能は変わらないと書かれています。
- **Business・Enterprise の利用者は、この変更の対象外です。** 組織向けのデータの扱いはデータ保護契約(DPA)に沿う、と説明されています。
- Issue・ディスカッション・保存されているプライベートリポジトリの内容は学習に使われません。ただし、Copilotを使っている最中に処理されるプライベートリポジトリのコードは、インタラクションデータに含まれます(2026年10月27日確認)。
- 公開コードに一致する提案(平均150文字ほどの長さ以上)を表示しない設定があります(料金ページのよくある質問)。

会社のコードを扱うなら、個人プランではなく Business 以上を会社として契約するのが基本です。個人プランを業務に使う場合は、少なくとも学習の設定をオフにし、社内の規程で許されているかを確認してください。

## 公式に書いていないこと

- **年払いの現在の価格**: 料金ページにもドキュメントのプラン一覧にも、年払いの金額は見当たりませんでした。年払いがあるかどうかは購入画面で確かめるしかありません。
- **Free のクレジットの量**: 「限定的」「利用制限あり」とだけ書かれ、数字はありません。どこで止まるかは、Free でいつもの作業をして、設定画面の使用量の表示で確かめられます。
- **日本語の指示でどこまで期待どおりに動くか**: 公式は「英語以外では十分に機能しない可能性がある」と書くだけで、日本語についての個別の説明はありません。Free の範囲で、普段の日本語の指示と英語の指示を同じ課題で比べると、自分の作業での差が分かります。
- **請求書払いの消費税と登録番号**: 変更履歴はカード・PayPal 払いの利用者についての説明でした。
- **AIクレジットが1回あたりいくつ減るか**: モデルとトークン量で変わるとだけ書かれています。設定画面で使用量の推移を見られるので、最初の数日の減り方から月の量を見積もれます。

## 向いていない・別のツールを検討したい人

- エディタごと乗り換えて、コードベース全体を前提にした提案を受けたい人 → [Cursor](/reviews/cursor-review/)など

## よくある質問

**Q. GitHub Copilotは無料で使えますか。**
使えます。Freeプランはコード補完が月2,000回まで、チャットやエージェントは制限つきで、モデルは自動選択のみです。認証を受けた学生はCopilot Studentを無料で使えます(2026年11月22日 公式確認)。

**Q. ProとPro+はどちらを選べばよいですか。**
違いは毎月含まれるAIクレジットの量(Proは15ドル分、Pro+は70ドル分)と、Pro+ではOpusなどの上位モデル、監査ログ、Copilot Fusion の High・Max が使えることです。コード補完が中心ならPro、エージェントやチャットを多く使う・上位モデルを使いたいならPro+、という分け方になります(2026年11月22日 公式確認)。

**Q. 日本から支払うと消費税はかかりますか。**
かかります。公式の変更履歴によると、2024年10月1日から、日本でカードかPayPalで支払う利用者には消費税10%が加算され、請求書にGitHub Inc.の登録番号(T4700150079306)と税額が米ドルと日本円で表示されます。料金ページの金額は税別です。

**Q. 提案されたコードをそのまま使って問題ありませんか。**
公式のよくある質問は、Copilotの提案にも、第三者のコードと同じテスト・コードスキャン・レビューを使うよう求めています。公開コードに一致する提案を止める設定や、よくある脆弱性のパターンを止めるフィルターもあると説明されていますが、それで安全が保証されるとは書かれていません。

**Q. 会社のコードを学習に使われませんか。**
