各ツールの料金・機能・規約は公式サイトの記載を2026年11月3日に確認したものです。当サイトで実際に使った検証はしていません。

## この記事の結論

- **商用利用時に学習データの出どころを説明しやすいこと**を重視するなら Adobe Firefly。ただし、アドビが商用利用に適しているとするのは Firefly のモデルで生成したものだけで、Firefly で選べる他社の「パートナーモデル」の生成物は別扱い
- **画像内に短い英字の文字・ロゴ案を入れたい**なら Ideogram。文字の描画を売りにしているが、公式ヘルプでは最も正確なのは英語で、ラテン文字以外は崩れることがあるとされている
- **ゲームのコンセプトアートやアセットを、画風の違うモデルを選んで作りたい**なら Leonardo AI(Canva 傘下)。無料プランの生成物は公開され、他のユーザーがコピーやリミックスに使える
- **雰囲気重視のビジュアルやSNS用アイキャッチ**なら Midjourney。無料プランはなく(niji·journey のアプリでの限定的な体験のみ)、年間売上100万米ドル超の会社は Pro か Mega が必要

どの比較も公式の説明と規約にもとづくもので、画質を当サイトで比べたものではありません。生成画像の商用利用条件や著作権の扱いは、実際に使う前に公式サイトの最新情報を確認してください。

## 比較の観点

画像生成AIを選ぶ際に迷いやすいポイントは主に次の4つです。

1. 商用利用の条件と、権利関係を説明しやすいか
2. 生成した画像が他の利用者に公開されるか
3. 画像内の文字をどこまで描けるか
4. 特定用途(ゲーム素材など)向けのモデルを選べるか

### Adobe Firefly

アドビは、Firefly の独自モデルを Adobe Stock などのライセンス取得済みコンテンツと、著作権の保護期間が終わったパブリックドメインのコンテンツで学習していると説明しています。Photoshop の生成塗りつぶしなどにも組み込まれているため、単体の生成AIというより制作ワークフローの一部として使う場面が多くなります。

注意したいのは、現在の Firefly では**Google・OpenAI・Flux など他社の「パートナーモデル」も選べる**ことです。アドビの料金ページのよくある質問では、商用利用に適しているとされるのは Firefly のモデルで生成したコンテンツで、パートナーモデルで生成したものがプロジェクトに適しているかは利用者自身が判断する必要がある、と書かれています。また知的財産に関する補償は、対象となるエンタープライズ顧客向けとされています。「商用利用に安全」はあくまでアドビ側の説明で、生成物が既存の作品に似ていないかの確認までは免除されません。詳しくは[Adobe Fireflyレビュー](/reviews/adobe-firefly-review/)を参照してください。

### Ideogram

画像生成AIが長く苦手としてきた「画像内に読める文字を描く」ことを売りにしているツールです。ただし公式ヘルプの「Text in Images」のページでは、文字が最も正確に出るのは英語で、ラテン文字以外やアクセント付きの文字は誤って出たり出なかったりすることがある、と説明されています。単語が増えるほど誤字や文字の抜けが起きやすく、長い本文は後からデザインツールで入れるよう勧めています。日本語の文字を入れたい場合は、崩れる前提で毎回確認するか、文字だけ別のツールで入れるのが無難です。

公式ヘルプによると、無料プランと旧Basicプランで生成した画像は公開され、Plus・Pro・Team・Enterprise では公開するまで非公開のままです。利用規約(2024年8月14日改定)では、生成物の所有権を主張せず、商用を含む利用を制限しないとしていますが、同時に生成物が他の人の生成物と同じになりうること、商用利用から生じる責任は負わないことも書かれています。生成したロゴ風デザインを商用ロゴにするなら、既存の商標との類似は自分で確認する必要があります。詳しくは[Ideogramレビュー](/reviews/ideogram-review/)を参照してください。

### Leonardo AI

キャラクターコンセプトやアイテムアイコン、環境テクスチャといったゲーム制作向けのアセット生成を打ち出している画像生成AIです。Canva に買収されており、Canva の発表では Leonardo のモデルを Canva の Magic Studio に取り入れる一方、Leonardo 自体は独立した運営を続けるとされています。有料プランでは80以上のモデルを使い分けられます(無料プランはモデルの選択が「Auto」のみ)。

商用利用について、公式ヘルプでは生成物は商用目的で使えるとしたうえで、**無料プランの生成物は公開され、他のユーザーがコピーやリミックスに使える**扱いとしています。有料プランでプライベートモードをオンにして生成した場合は、所有権・著作権などの権利をユーザーが持つと説明されています。収益化する用途なら、有料プランで非公開にして生成するのが前提になります。詳しくは[Leonardo AIレビュー](/reviews/leonardo-ai-review/)を参照してください。

### Midjourney

テキストの指示(プロンプト)から画像を生成するサービスで、Webサイト(midjourney.com)と Discord で使えます。公式ヘルプでは、2026年7月24日から V8.2 が標準のモデルとされています。実在の人物・製品を正確に再現する用途より、雰囲気やコンセプトを伝えるビジュアル作りに向いています。画像内の文字は英字などのラテン文字が最も得意と公式ヘルプにあり、日本語の文字を入れたいバナーには向きません。

利用規約では、作成した画像は法律が許す範囲で利用者のものとされますが、**年間の売上が100万米ドルを超える会社(またはその従業員)が使う場合は Pro か Mega のプランが必要**です。また作成した画像は標準では公開され、他の利用者がリミックスできる扱いで、midjourney.com 上で非公開にする Stealth Mode は Pro・Mega だけです。詳しくは[Midjourneyレビュー](/reviews/midjourney-review/)を参照してください。

### Canvaで済ませる場合

画像の生成そのものより、テンプレートに写真や文字を載せてバナーや資料を作るのが目的なら、Canva の AI機能(マジック拡張、AI背景生成など)で足りることもあります。ただし Canva のコンテンツ使用許諾契約では、素材を商標・ロゴの一部として使うこと(フォントを除く)や、素材を単体でTシャツなどのオンデマンド製品にして売ることが禁止されています。料金と条件は[Canva Proの解説](/reviews/canva-pro-review/)にまとめています。

## どれを選ぶべきか(タイプ別)

| タイプ | 候補 |
| --- | --- |
| 商用利用で学習データの出どころを説明しやすくしたい | Adobe Firefly(Firefly のモデルを選ぶ) |
| 画像内に短い英字の文字・ロゴ案を入れたい | Ideogram |
| ゲームのコンセプトアート・アセットを作りたい | Leonardo AI |
| SNSアイキャッチなど雰囲気重視のビジュアルを作りたい | Midjourney |
| Photoshop/Illustratorの作業に生成AIを組み込みたい | Adobe Firefly |
| 特定の画風のモデルを選んで使いたい | Leonardo AI |
| 生成した画像を他の利用者に公開したくない | Ideogram・Leonardo AI は有料プラン、Midjourney は Pro・Mega |

手指や画像内の文字の崩れなど、AI画像生成全般に共通する苦手分野はどのツールにも残ります。複数パターンを生成して選ぶ前提で使い、商用利用を検討する場合は必ず各社の最新の利用規約を確認してください。

## よくある質問

**Q. まず1つ選ぶならどれですか。**
用途で決まります。商用利用で学習データの説明をしやすくしたいならAdobe Firefly、画像内に英字の文字を入れたいならIdeogram、雰囲気重視のビジュアルならMidjourney、特定スタイルのアセットを作るならLeonardo AIが候補です。

**Q. 生成した画像を商用で使えますか。**
4つとも規約やヘルプでは商用利用の道が示されていますが、条件が違います。Midjourney は年間売上100万米ドル超の会社に Pro か Mega が必要、Leonardo AI と Ideogram は無料プランの生成物が公開される、Firefly はパートナーモデルの生成物が「商用利用に適している」という説明の対象外です。加えて、生成物が既存の作品や商標に似ていないかの確認は自分で行う必要があります。規約の確認と目視確認の両方を工程に入れてください。

**Q. 日本語の文字を画像に入れられますか。**
Ideogram も Midjourney も、公式ヘルプでは英字(ラテン文字)が最も得意とされています。日本語の文字は崩れる前提で確認するか、文字だけ Canva などのデザインツールで後から入れるのが無難です。

**Q. AIで作ったことを明示する必要はありますか。**
掲載先によってはルールがあります。広告や配信プラットフォームに出す前に、掲載先のルールを確認してください。確認すべき項目は[生成AIの商用利用チェックリスト](/reviews/ai-commercial-use-checklist/)にまとめています。
