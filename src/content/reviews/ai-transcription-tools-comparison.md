## この記事の結論

- **有料の入口が安いのは、Notta プレミアムの年払い(月あたり1,185円・税込)**、次いで Otter.ai Pro の年払い(月8.33ドル)、PLAUD の Pro の年払い(月あたり1,400円・本体が別に要る)。1分あたりでは、Notta プレミアムの年払い(約0.66円)と Rimo の文字起こしプラン(約0.79円)が低い
- **無料で会議1本を最後まで記録しやすいのは、tl;dv(1回3時間まで)・Fireflies.ai(自動参加の文字起こしは無制限、保存は400分)・Otter.ai(月300分・1回30分まで)**。Notta のフリーは1回3分まで、Zoom の無料版は会議が40分まで
- **英語の会議**は、Otter.ai(英語が中心)、Fireflies.ai(1つの会議で複数の言語を自動で見分けるモードがベータ版)、Teams Premium(会議の字幕のライブ翻訳40言語)が公式の説明で手厚い。Google Meet の自動メモは、1回の会議で1つの言語だけ

- **Zoom・Teams・Google Meet の AI 機能**は、会議ツールの有料プランに含まれる(Teams は追加のライセンス)。会議ツールを1つに絞っているなら、追加の契約を増やさずに済む
- AI GIJIROKU と YOMEL は、公式のページを自動で読み取れず、料金を確かめられなかった(未確認)。Otolio(旧スマート書記)は料金を公開しておらず、問い合わせで見積もる形

## 英語の会議

英語の会議を記録するときに見たいのは、「英語に対応しているか」より、**1回の会議で日本語と英語が混ざっても記録できるか**と、**翻訳まで要るか**です。

| ツール | 英語の会議についての公式の説明 |
| --- | --- |
| Otter.ai | 英語の会議記録が中心のサービス。日本語は対応言語の一覧に入っている。1回の録音は録音前に選んだ1つの言語で行うのが基本(11月12日にヘルプで確認。27日はヘルプが403で未確認) |
| Fireflies.ai | 100以上の言語に対応し、日本語も一覧にある。「Multi-Language(Auto-Detect)」はベータ版で、1つの会議の中の複数の言語を見分けて文字にし、1つの会話で60以上の言語に対応とされる |
| tl;dv | 文字起こしは30以上の言語(一覧に日本語あり)。録画の前に言語を選び、録画ごとに言語を変えることもできる |
| Microsoft Teams Premium | 会議の字幕のライブ翻訳(40言語)、文字起こしのライブ翻訳、多言語の会議のサポートが Premium の機能 |
| Zoom | ミーティング要約は33言語(日本語・英語を含む)。有料プランに「ライブ音声翻訳」がある |
| Google Meet | Gemini の自動メモは日本語・英語に対応。ただし「一度に1つの言語にのみ対応」で、複数の言語が混ざる会議には対応していない |
| Notta | 2か国語の文字起こし・翻訳は全プランで月4回まで無料。続けて使うならアドオン(年払いで月1,320円) |
| PLAUD | 112言語に対応 |

- 英語だけの会議が多いなら、英語が中心の Otter.ai や、ボットで自動参加する Fireflies.ai・tl;dv が候補になります。
- 日本語と英語が1つの会議で混ざるなら、混在に対応すると書いているのは Fireflies.ai(ベータ版)と Teams Premium(多言語の会議のサポート)です。Google Meet の自動メモは混在に対応していないと明記されています。
- 相手の英語を字幕で読みたいなら、Teams Premium の字幕のライブ翻訳か、Notta の翻訳のアドオンです。
- 雑音の除去が先に必要な場合の Krisp は、文字起こしの対応言語に日本語がありません(11月22日確認)。詳しくは[Krispの記事](/reviews/krisp-review/)を参照してください。

## レコーダー型と会議ボット型の違い

| | レコーダー型(PLAUD NOTE・Notta Memo) | 会議ボット型(Notta・Otter.ai・tl;dv・Fireflies.ai) | 会議ツール内蔵(Zoom・Teams・Meet) |
| --- | --- | --- | --- |
| 何で録るか | 手元の録音機 | 会議に「参加者」として入るボット | 会議ツールそのもの |
| 向いている会議 | 対面の会議、電話、外出先 | オンライン会議(ツールをまたぐ場合も) | そのツールだけで会議をする組織 |
| 初めにかかる費用 | 本体代(PLAUD NOTE 通常27,500円、Notta Memo 23,500円) | 0円から | 会議ツールの有料プラン |
| 相手から見えるか | 録音機が見えるだけ | 参加者の一覧にボットが出る。待機室ではホストの承認が要る | 会議ツールの録画・文字起こしの表示 |
| つまずきやすい点 | オンライン会議を録るには、会議ボット型か会議ツールの録音が別に要る | ボットを入れられない会議がある(Notta はログインが必要な Teams 会議に非対応) | 他社の会議ツールでは使えない(Zoom の My Notes を除く) |

## よくある質問

**Q. 議事録AIで一番安いのはどれですか。**
月あたりの金額で最も低いのは、Notta プレミアムの年払い(月あたり1,185円・税込、月1,800分)です。1分あたりでは約0.66円で、Rimo の文字起こしプラン(月1,650円・2,100分、約0.79円)が続きます(2026年11月27日確認)。お金をかけないなら、tl;dv の無料プランは文字起こしの上限が書かれていません。

**Q. 無料のまま英語の会議を記録できますか。**
Otter.ai の Basic は月300分・1回30分まで、tl;dv の無料プランは1回3時間まで記録できます。Fireflies.ai の Free は自動参加の文字起こしが無制限で、保存は400分までです。要約まで毎回ほしい場合は、tl;dv は最初の10会議、Zoom のベーシックは月3回が上限です。

**Q. レコーダー型とアプリ・ボット型はどちらがいいですか。**
対面の会議や電話が多いなら、PLAUD NOTE や Notta Memo のような録音機が向いています。オンライン会議が中心なら、本体代のかからない会議ボット型(Notta・Otter.ai・tl;dv・Fireflies.ai)か、会議ツールの AI 機能で足ります。

**Q. Nottaの無料と有料の違いは何ですか。**
フリーは1回3分までなので、会議1本を丸ごと文字起こしするには有料のプレミアム(1回5時間まで)以上が要ります。プレミアムの3日間の無料トライアルは、終わると年間プランで自動で課金されるため、続けない場合は72時間以内に解約してください。

**Q. 評判や口コミはどう見ればよいですか。**
当サイトは感想としての評判は書きません。差が出やすいのは、1回の録音の上限、無料トライアルのあとの自動課金、年払いの返金、会議のデータの学習への利用といった公開条件です。契約の前に、この記事の「評判・口コミの前に見ておきたい公開条件」の表と、各社の最新の表示を確かめてください。

**Q. 文字起こしの精度はどれくらいですか。**
確認した公式ページに、日本語の精度を数字で示したものはありませんでした。当サイトも測っていません。話す人の数、専門用語、回線やマイクの状態で結果は変わるため、無料の枠で自分の会議を1本記録して確かめるのが確実です。

**Q. 会議の内容がAIの学習に使われないツールはどれですか。**
Rimo は「AI学習に使われない」と書いています(2026年11月27日確認)。Notta はビジネス Plus とエンタープライズの機能に「AI学習なし」があります。Fireflies.ai と Krisp は学習に使わない、Otter.ai は匿名化した録音と文字起こしで自社の AI を学習させると書いています(11月22日までの確認)。
