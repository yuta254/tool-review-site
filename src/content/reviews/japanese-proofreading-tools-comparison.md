## この記事の結論

- **日本語の校正に専用のルールを持つのは文賢とShodo。** 文賢は「ルール校正」13項目と「ルール推敲」22項目、Shodoは無料のベーシックでも1回1万文字まで校正できます。
- **料金(税込)は、Shodoが0円から(有料は月1,000円から)、文賢は月1,980円から(1年更新なら月あたり1,650円)。** どちらも14日間の無料トライアルがあります。
- **Wordのエディターは、日本語の「文法チェック」に対応。** ただし公式の言語別の表では、日本語の「文章校正」はデスクトップのWordアプリではまだ使えないと注記されています。
- **Googleドキュメントの標準のスペル・文法の訂正案は6言語のみで、日本語は入っていません。**
- **入力した文章の扱いは、文賢とShodoが「AIの学習に使わない」と明記。** 文賢は文章をサーバーに保存しないとしていますが、AIアシストに送った文章はOpenAI社のサーバーに30日間保管されると書かれています。
- **ChatGPTの個人向けプランは、学習への利用を「拒否可能」(設定で止める形)。** 法人向けのBusinessは、デフォルトでビジネスデータを学習に使わないと表示されています。

この記事の料金と条件は、各社の公式サイト・公式ヘルプの記載を**2026年11月6日**に確認したものです。当サイトでは実機・実サービスを検証していません。公式の公開情報どうしを並べた記事です。

## それぞれの位置づけ

### 文賢:日本語のルールとチームの表記統一

文賢は、株式会社ウェブライダーが提供するブラウザで動く校正・推敲の支援ツールです。公式サイトでは、日本語の誤りを正す「ルール校正」(誤字脱字、誤った敬語、差別語・不快語など13項目)と、読みやすくする「ルール推敲」(一文が100文字以上、同じ文末表現の連続、冗長な表現など22項目)に分けて説明されています。

社内の表記ルールを「辞書」に登録でき、ビジネスチームプランでは辞書をメンバーで共有して共同編集できます。OpenAI社のAPIを使う「AIアシスト」は初期設定がオフで、オーナーが許可しないと使えない仕組みです。文章の一部を伏せ字にしてAIに送る「マスキング機能」もあります。料金と機能の細かい内訳は[文賢の料金とできること](/reviews/bunken-price-features/)にまとめました。

### Shodo:無料から始められ、WordやGoogleドキュメントの中でも使える

Shodoは無料のベーシックで1回1万文字まで校正でき、生成AI校正も週間の制限つきで使えると料金ページに書かれています。プレミアム(月1,000円)からは、ブラウザ拡張(note、Gmail等)、Wordアドイン、Googleドキュメントのアドオンが使えるようになり、表記ゆれの自動チェックや校正ルールの設定も加わります。マックスとビジネスでは、背景情報を使う「AI校閲」とPDFの校正が加わります。

### Word のエディター:すでにWordで書いているなら最初に確認

Wordでは[ホーム]タブの[エディター]から使うと公式に案内されています。Microsoftの言語別の対応表では、日本語は「文法チェック」に対応、「文章校正」(スタイルの提案)は対応の印つきですが「デスクトップのWordアプリではまだ使用できません」と注記されています。Web版のWordでは、無料のMicrosoftアカウントで基本的なスペルチェックと文章校正、Microsoft 365のサブスクリプションでは高度な文法とスタイルの提案が使えると説明されています([公式ヘルプ](https://support.microsoft.com/ja-jp/office/microsoft-%E3%82%A8%E3%83%87%E3%82%A3%E3%82%BF%E3%83%BC%E3%81%A7%E3%83%89%E3%82%AD%E3%83%A5%E3%83%A1%E3%83%B3%E3%83%88-%E3%83%A1%E3%83%BC%E3%83%AB-web-%E5%85%A8%E4%BD%93%E3%81%AE%E6%96%87%E6%B3%95%E3%81%A8%E3%82%B9%E3%83%9A%E3%83%AB%E3%82%92%E3%83%81%E3%82%A7%E3%83%83%E3%82%AF%E3%81%99%E3%82%8B-91ecbe1b-d021-4e9e-a82e-abc4cd7163d7))。

### Google ドキュメント:標準機能は日本語の校正に向かない

公式ヘルプでは、スペルと文法の訂正案が使える言語は英語・スペイン語・フランス語・ドイツ語・ポルトガル語・イタリア語とされています。日本語の文章を直したい場合、標準機能では足りません。Geminiを使って文章を書き直す機能もありますが、[公式ヘルプ](https://support.google.com/docs/answer/13447609?hl=ja)では対象のGoogle WorkspaceまたはGoogle AIのプランへの登録が必要とされています。

### ChatGPT など生成AI:頼み方で何でもできるが、基準は自分で決める

生成AIには、誤字の指摘、言い換え、敬語の直し、要約などを文章で頼めます。専用ツールのような決まったチェック項目はないため、何をどの基準で直すかは自分で指示する形になります。料金や機能の違いは[ChatGPT・Claude・Geminiの比較](/reviews/chatgpt-claude-gemini-comparison/)で扱っています。

## 社内で使うときのデータの扱い

社外秘の文章や個人情報を貼る前に、入力した文章がどこへ行くかを確かめておくと安全です。各社の公式の表示は次のとおりです。

| | 公式の表示(要点) |
| --- | --- |
| 文賢 | 入力した文章はAIの学習に使われず、文賢のサーバーにも保存されない(ブラウザのキャッシュとローカルストレージに一時保存)。AIアシストに送った文章は、不正利用の監視のためOpenAI社のサーバーに30日間保管。追加利用規約では、米国の裁判所命令により一部のデータがより長く保持される場合があるとも書かれている |
| Shodo | 投稿した文章をAIが学習することはない(無料・有料とも)。データは外部からアクセスできない暗号化されたデータベースに保存。サーバーは全利用者で共有(専有はエンタープライズプラン) |
| Word のエディター | 「コンテンツを分析する接続エクスペリエンス」の1つ。基本機能はオフラインでも、この接続エクスペリエンスを無効にしても使え、その場合はエディターの使用に関するデータはMicrosoftに送られない。職場・学校のアカウントでは管理者が使えるかを決める([Microsoft Learn](https://learn.microsoft.com/ja-jp/microsoft-365-apps/privacy/connected-experiences)) |
| ChatGPT | 無料版・Go・Plus・Proは「学習への利用を拒否可能」。Businessは「デフォルトではビジネスデータを学習に使用しません」 |

文賢の扱いは[文賢のセキュリティの説明](https://rider-store.jp/bun-ken/)、[ヘルプ「入力した文章データは保存されているのでしょうか?」](https://help.bun-ken.net/dont-text-data-saved/)、[AIアシスト機能に関する追加利用規約](https://help.bun-ken.net/terms-ai-assist/)によります。文賢の追加利用規約では、AIアシストに機密情報を送らないよう利用者に求めています。生成AIを仕事に使う前の確認項目は[生成AIの商用利用チェックリスト](/reviews/ai-commercial-use-checklist/)も参考にしてください。

## 条件で分ける選び方

| あなたの条件 | 候補 |
| --- | --- |
| まず無料で、日本語の誤りをまとめて拾いたい | Shodoのベーシック(1回1万文字まで) |
| WordやGoogleドキュメント、Gmailの中で直したい | Shodoのプレミアム以上(アドイン・拡張あり)。Wordだけならエディターの文法チェックを先に確認 |
| 部署の表記ルールを辞書にして、チームで同じ基準で直したい | 文賢のビジネスチーム、またはShodoのビジネス |
| AIに文章を送る前に、社名や個人名を伏せたい | 文賢(マスキング機能。自動検出はビジネスチームのみ) |
| 書き直しや要約まで1つで頼みたい | 生成AI。仕事の文章なら学習の設定と法人向けプランの条件を先に確認 |
| 英文の校正が中心 | [AIライティング・英文校正ツールの比較](/reviews/ai-writing-proofreading-comparison/)へ |

どのツールも、すべての誤りを拾うとは書いていません。文賢の公式サイトには、校閲機能はあくまで支援であり、文章中の誤りをもれなく指摘するものではないと明記されています。社外に出す文書は、ツールの指摘の後に人の目で読む前提で選んでください。

## よくある質問

### 無料で使える日本語の校正ツールはどれですか。

この記事の中では、Shodoのベーシック(永年無料・1回1万文字まで)、無料のMicrosoftアカウントで使えるWord for the webのエディター(基本的なスペルチェックと文章校正)、ChatGPTなどの生成AIの無料版です。Googleドキュメントの標準のスペル・文法の訂正案は日本語が対象外です。

### 文賢とShodoの料金はどちらが安いですか。

1人で使う場合、Shodoのプレミアムは月1,000円、文賢のパーソナルは月1,980円(1年更新なら月あたり1,650円)です。チームでは、Shodoのビジネスが1名月2,000円(3名から)、文賢のビジネスチームが1ユーザー月3,300円(1年更新なら月あたり2,750円)です。いずれも税込で、2026年11月6日に公式で確認した金額です。

### 会社の文章を入れても学習に使われませんか。

文賢とShodoは、入力した文章をAIの学習に使わないと公式に書いています。ただし文賢でもAIアシストに送った文章は、OpenAI社のサーバーに不正利用の監視のため30日間保管されると案内されています。ChatGPTの個人向けプランは学習への利用を設定で止める形で、Businessはデフォルトで学習に使わないと表示されています。社内の取り扱い規程とあわせて確かめてください。

### Wordのエディターだけで足りますか。

文法の誤りを拾う用途なら、まずWordのエディターで足りるかを確かめるのが手間の少ない順番です。日本語の「文章校正」(スタイルの提案)はデスクトップのWordアプリではまだ使えないと公式に注記されているので、表記ゆれや社内の表記ルールまで揃えたい場合は、辞書や校正ルールを設定できる文賢・Shodoが候補になります。
