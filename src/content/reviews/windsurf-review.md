## この記事の結論

- **Windsurf は現在「Devin Desktop」という名前で提供されている**。製品ページでは「Windsurf の新しい名前」と説明され、通常のアップデートで切り替わり、プラン・料金・拡張機能・設定は引き継がれる(2026年11月22日確認)
- windsurf.com は devin.ai/desktop に、windsurf.com/pricing は devin.ai/pricing に転送される
- 旧エージェントの **Cascade は新しい会話にも過去の会話にも使えない**。新しい会話はローカルで動く Devin Local で始まり、Cascade 専用だった Workflows はスキルへの移行が案内されている
- 料金は Free(0ドル)・Pro(月20ドル)・Max(月200ドル)・Teams(月80ドル)・Enterprise(要問い合わせ)。**Teams は11月3日の「80ドル〜・フル席1人40ドル・最大200人」から、「月80ドルの定額・最大100人・共有のクレジット」の説明に変わっていた**
- 初期設定では、データがモデルの学習に使われることがある。有料プランは設定で学習への利用を止められる(Teams は管理者のみ)。無料プランでの止め方は確認したページに書かれていなかった
- 対応OSは公式ドキュメントで macOS・Windows 10 以降・Linux。製品ページのダウンロードボタンは macOS 用だけが表示されていた

この記事は、Cognition の公式ブログ、Devin の製品ページ・料金ページ・公式ドキュメント(docs.devin.ai)を2026年11月22日に確認してまとめたものです。当サイトでは Devin Desktop を操作して確かめてはいません。

## Windsurf(Devin Desktop)とは

Windsurf は、もとは Codeium が開発した AI エディタです。Cognition が2025年7月に買収の正式な契約を発表し、2026年6月2日に「Windsurf の次の世代」として Devin Desktop を発表しました。公式ブログでは、Windsurf と完全な後方互換があると書かれています。

Devin Desktop は、Windsurf のエディタを土台に、ローカルで動くエージェント(Devin Local)、クラウドで動く Devin への作業の受け渡し、複数のエージェントをまとめて管理する「Agent Command Center」を組み込んだエディタです。製品ページでは、作業に必要なファイルと行を探す Fast Context、差分を確かめる Devin Review、上位のモデルと費用の低いモデルを組み合わせる Fusion などが紹介されています。VS Code や Cursor の設定・キーバインドを取り込む機能もあります。

競合の [Cursor](/reviews/cursor-review/) や [GitHub Copilot](/reviews/github-copilot-review/) との違いは、[コーディング支援AIの比較](/reviews/ai-coding-tools-comparison/)にまとめています。

## 料金

[公式の料金ページ](https://devin.ai/pricing)の表示です(米ドル・月額。2026年11月22日確認)。Devin Desktop は、クラウドの Devin や Devin CLI と同じプランで使います。

| プラン | 月額 | 人数 | 主な内容 |
| --- | --- | --- | --- |
| Free | 0ドル | 1人 | エージェント用の少なめの利用枠、使えるモデルは一部、Tab 補完・インライン編集は無制限 |
| Pro | 20ドル | 1人 | 利用枠の拡大、OpenAI・Claude・Gemini・SpaceXAI などのモデルとオープンソースのモデル、SWE-2。超過分は API 料金で追加購入 |
| Max | 200ドル | 1人 | Pro より大幅に多い利用枠、Devin Bots |
| Teams | 80ドル(定額) | 最大100人 | Pro の内容と Devin Bots、3段階の利用の上限による費用の管理、共有のクレジット |
| Enterprise | 要問い合わせ | 無制限 | チーム単位・個人単位の利用上限、主なモデル提供元への対応 |

料金ページのよくある質問では、「ほとんどの利用者は上限に達しない」とされ、上限を超えた分は有料プランで API 料金で追加購入できると書かれています。具体的な利用枠の量は、料金ページにもドキュメントにも示されていません。

## 日本の消費税・インボイス

- 料金ページと料金のドキュメントには、**表示の金額が税込か税抜か、日本の消費税(10%)が加算されるか、適格請求書(インボイス)を発行するかは書かれていませんでした**(2026年11月22日確認)。
- 請求書は設定の「Invoices」から取り出せると料金のドキュメントに書かれています。法人で仕入税額控除を受けたい場合は、最初の請求書に税の行と日本の登録番号があるかを確かめるか、契約前に問い合わせてください。

ほかの海外AIツールの消費税の扱いと登録番号は、[海外AIツールの消費税・インボイス対応一覧](/reviews/ai-tools-japan-consumption-tax-invoice/)にまとめています(国税庁の公表サイトで照合)。

## 1年・2年の総額の試算

月額を12か月・24か月払い続けた場合の合計です(税は含まない)。料金ページに年払いの表示はありません。円は1ドル=150円で換算した目安で、実際の請求額は税・為替・カード会社の手数料で変わります。API 料金での追加購入と、Teams の共有クレジットの購入分は含みません。

| プラン | 1年 | 2年 | 1年の円の目安 |
| --- | --- | --- | --- |
| Pro | 240ドル | 480ドル | 約36,000円 |
| Max | 2,400ドル | 4,800ドル | 約360,000円 |
| Teams(定額部分) | 960ドル | 1,920ドル | 約144,000円 |

Teams はメンバーごとの利用枠がなく、前払いの共有クレジットから使う仕組みのため、実際の総額は人数と使う量で大きく変わります。定額の80ドルだけで比べないよう注意が要ります。

## 条件別の選び方

| 条件 | 選び方 | 理由(公式の記載) |
| --- | --- | --- |
| まず画面と補完を確かめたい | Free | Tab 補完・インライン編集は無制限。エージェントの枠は少なめ |
| 他社の上位モデルでエージェントを動かしたい | Pro | Pro から OpenAI・Claude・Gemini などのモデル |

## 公式の説明から分かる注意点

- **Cascade 前提の手順は使えない**: 旧版の Cascade の会話は開けず、Workflows は Devin Local では使えません。古い解説の手順は、そのままでは当てはまりません。
- **パッケージ名と保存場所に旧名が残る**: Getting started によると、Linux のリポジトリの URL には旧名の「windsurf」が残り、パッケージは「devin-desktop」に変わっています。「windsurf」のパッケージは devin-desktop を入れる移行用として残ります。Windows では古いインストールが「Windsurf」フォルダに残ることがあり、Mac・Linux で消すときは `~/.codeium/windsurf` を削除すると書かれています。
- **学習への利用は初期設定でオン**: セキュリティのドキュメントでは、初期設定では学習に使うことがあるとされ、止め方は有料プランについてだけ書かれています。無料プランで社外秘のコードを扱う前に、この点を確かめる必要があります。
- **拡張機能の互換性**: 公式ドキュメントでは、他社の AI 補完の拡張機能や一部の独自の拡張機能は互換性がないとされています(2026年11月3日確認)。

## 公式に書いていないこと

確認したページに見当たらなかった事項と、各自で確かめる方法です。

- **具体的な利用枠の量**: 料金ページは「少なめ」「拡大」「大幅に多い」とだけ書いています。Free で登録すると、設定の画面で残りの利用枠を見られるかを確かめられます。
- **無料プランの学習への利用の止め方**: セキュリティのドキュメントは有料プランの止め方だけを書いています。Free の設定画面に「Disable training」の項目があるかを確かめてください。
- **Windows・Linux 版のダウンロード先**: 製品ページには macOS 用のボタンだけが表示されていました。Getting started のドキュメントに Windows・Linux の手順があります。
- **税と返金**: 確認したページには書かれていませんでした。
- **画面の日本語表示**: 確認したページに記載がありませんでした。

## よくある質問

**Q. Windsurfは今も使えますか。**
製品は Devin Desktop という名前に変わって提供されています。製品ページによると、切り替えは通常のアップデートで行われ、プラン・料金・拡張機能・設定は自動で引き継がれます。ただし、旧エージェントの Cascade は新しい会話にも過去の会話にも使えません(2026年11月22日確認)。

**Q. Cursorとどちらを選ぶべきですか。**
どちらも AI エージェントを組み込んだエディタで、方向性は近い競合です。料金の仕組みは大きく違い、Cursor は2026年8月の買収後に Grok 中心のプランへ変わっています([Cursorの記事](/reviews/cursor-review/)参照)。両方の無料プランで、同じ小さな作業を頼んで出てくる差分を比べると判断しやすくなります。

**Q. 自律的にコードを書かせて大丈夫ですか。**
差分を確認できる範囲に作業の単位を区切るのが前提です。製品ページでは、差分を確かめる Devin Review の機能が紹介されています。Git でこまめにコミットしておけば、意図しない変更を戻せます。

**Q. 書いたコードは学習に使われますか。**
公式のセキュリティのドキュメントでは、初期設定では学習に使うことがあるとされています。有料プランは設定の「Data controls & privacy」にある「Disable training」をオンにすると使われなくなり、Teams では管理者だけが設定できます。Enterprise は書面の同意なしに学習に使わないとされています(2026年11月22日確認)。
