## この記事の結論

AIボイスレコーダーは、どれも**本体で録音し、アプリ経由でクラウドに送って文字起こし・要約する**仕組みです。本体価格は多くが2万〜3万円前後で、それほど変わりません(Comu Action Pro は通常価格39,800円)。差が大きいのは、**本体を買うと付く無料の文字起こし時間**、**通話を録れるかどうか**、**返品の条件**です。

## 「買い切り」「サブスクなし」で使えるか

「買い切り」「サブスクなし」で探す場合、気をつけたいのは、**本体の中だけで文字起こしするAIボイスレコーダーは、今回確認した中には見当たらなかった**ことです。どの製品も、文字起こしと要約はインターネット経由のクラウドで行います(Soundcore Work の FAQ には「録音機能はオフラインでもご使用いただけます。文字起こしや要約等の機能をご利用いただくために、インターネット接続が必要です」とあります)。

そのうえで「月額料金を払わずに使えるか」で分けると、次のようになります。

| 製品 | 月額0円で使える範囲 | 期間についての公式の記載 |
| --- | --- | --- |
| HiDock P1 / P1 mini | 文字起こし時間は無制限。話者識別や Word・PDF での書き出しは有料 | 「生涯無料」 |
| Notta Memo / Memo Pro | 毎月600分。機能はプレミアムと同じ範囲だが、AI要約は月100回などの回数上限あり | 商品ページは「永久無料」。公式ヘルプでは、本体の登録を解除した場合などに失効するとされる |
| Comu Action Pro / Comulytic Note Pro | 文字起こし・基本要約は無制限。リアルタイム翻訳(月1回)や高度な分析(月3回)などは回数の上限あり | 商品ページは「無料・無制限」と案内。Note Pro のよくある質問では、基本の文字起こし・要約は「継続して無料」で使えるとされる |

## 機種ごとの特徴

### PLAUD(Note Pro / Note / NotePin S / NotePin)

カード型2機種とピン型2機種があり、どの機種も保存容量は64GB、文字起こしは112言語に対応しています。プランの内容は機種で変わりません。カード型はマグネットケースでスマートフォンの背面に付けて通話を録れ、上位の Note Pro は通話と対面を自動で切り替え、マイクが4基で録音範囲は最大5mです。ピン型は身につけて使う代わりに、対面の録音だけに対応しています。公式ストアの返品条件がこの中で最も広いのも特徴です。機種ごとの違いと買う場所による返品の違いは[PLAUDの料金まとめ](/reviews/plaud-note-price-plans/)にまとめました。

### Notta Memo / Notta Memo Pro

カード型の録音機で、無料の文字起こし時間が毎月600分と、PLAUD と Soundcore Work の倍あります。Notta Memo Pro は、64GB・最大収音距離8m・通話と対面の自動識別・USB Type-C 端子に加え、録音を本体のチップで暗号化し、設定した Wi-Fi に戻ると自動でアップロードすると説明されています。Notta Memo は2万円台前半と安く、確認日はセール価格でした。PLAUD Note との詳しい比較は[Notta MemoとPLAUD Noteの違い](/reviews/notta-memo-vs-plaud-note/)にあります。

### HiDock P1 / P1 mini

本体を持っていれば、文字起こしと要約を時間の上限なしで無料で使えるとしているのが、ほかの製品との一番の違いです。その代わり、無料のままでは話者識別が使えません。会議の参加者が多く「誰が言ったか」を残したい場合は、プロメンバーシップ(従量制)か使い放題プロ(年28,800円)が必要になります。録り方も独特で、Bluetooth イヤホンをつけたまま通話やオンライン会議を録る「BlueCatch」という方式です。P1 は通話モード・対面モード・呟きモードの3つ、P1 mini は通話モードと対面モードの2つの録音モードがあります。カード型ではなく、P1 は72gの棒状、P1 mini はスマートフォンに差し込む12gの小型です。

取り外せる約10gのマイクを襟元・首元・スマートフォンに付けて使う形で、カード型の充電ケースと組み合わせて最大32時間録音できます。対応言語は150以上と、この中で最も多く書かれています。一方で、通話の録音には対応していません。料金体系は PLAUD とよく似ていて(無料300分、1,200分のPro、無制限のUnlimited)、年額は Pro・Unlimited とも PLAUD より少し安い表示です。Pro は月額都度払い(2,680円)も選べます。

## 選び方

1. **オンライン会議が中心なら、録音機は要らないかもしれません。** Zoom や Teams の会議なら、会議ツール側の文字起こし機能で足りる場合があります。AIボイスレコーダーが向くのは、対面の打ち合わせや電話など、オンライン会議の外の会話です。違いは[AIボイスレコーダーと会議の文字起こしAIの違い](/reviews/ai-voice-recorder-vs-meeting-transcription/)に、ソフトだけで使う文字起こしサービスは[AI文字起こしツールの比較](/reviews/ai-transcription-tools-comparison/)にまとめています。
2. **電話を録るかどうかで、候補が半分に絞れます。** 録るなら、PLAUD のカード型・Notta Memo・Comu・HiDock。録らないなら、Soundcore Work や PLAUD のピン型も候補に入ります。
3. **先月の会議時間を数えて、月の録音時間を見積もります。** 1時間の会議が月5本(300分)以内なら、どの製品も無料の枠で収まります(オートメモを除く)。月10本(600分)以内なら Notta Memo、時間を気にしたくないなら無料で無制限の HiDock か Comu、それ以外で毎月長く録るなら、有料プランを含めた総額で比べてください。
4. **話者の識別が要るか。** 複数人の会議で「誰が言ったか」を残したいなら、HiDock は有料のメンバーシップが必要です(Comu は全プランで使える表示)。
5. **返品の条件を確かめてから買います。** 開封後でも返品できるのは PLAUD の公式ストア、オートメモの満足保証、Comu の公式ストア(著しい使用痕がないこと)で、Notta は未開封のみ、HiDock は使用痕跡がないことが条件です。

## 録音の同意について

どの機種を選んでも、録音の前に相手へ伝えて同意を得るのが基本です。Soundcore Work の製品ページにも「録音の際は相手の同意を取得し、プライバシーと法令を遵守してください」と書かれています。電話の録音や、身につけたまま録る使い方は、相手が録音に気づきにくい分、先に一言伝えておくことが大切です。社内ルールや取引先との取り決めも確認してください。考え方は[AI議事録の録音同意ガイド](/reviews/ai-meeting-recording-consent-guide/)で整理しています。

## よくある質問

**Q. サブスクなしで使えるAIボイスレコーダーはどれですか。**

今回確認した公式ページには見当たりませんでした。オフラインで録音はできても、文字起こしと要約はクラウドで行う仕組みです。パソコンの中だけで文字起こしするものとしては、ソースネクストの Windows 用ソフト「RecText AI」(9,980円)がありますが、録音機ではなく、対応言語は日本語と英語の2言語です。

Comu Action Pro の商品ページと料金プランの表では、無料のスタータープランで文字起こしと基本要約が「無制限」とされています(2026年11月10日確認)。ただし、リアルタイム翻訳は月1回、高度な分析ツールは月3回、資料やメールを作るエージェントワークフローは月500クレジットまでで、それ以上は有料プラン(プレミアムは年払いで月あたり1,733円)かクレジットが必要です。将来の条件変更の可能性は、ほかの製品と同じく残ります。

**Q. 通話の録音に対応していないのはどれですか。**
Anker Soundcore Work は、製品ページの FAQ で「通話録音には対応しておりません」とされています。PLAUD のピン型(NotePin S / NotePin)も、公式の比較ページで「対面録音モードのみ」です。通話を録るなら、PLAUD のカード型(Note Pro / Note)、Notta Memo / Memo Pro、Comu Action Pro / Comulytic Note Pro、Bluetooth イヤホンでの通話を録る HiDock P1 / P1 mini が候補です。

**Q. 一番安く始められるのはどれですか。**
通常価格で比べると、本体はオートメモ S(19,800円)と HiDock P1 mini(21,800円)が安く、Notta Memo(23,500円)が続きます。オートメモは無料の枠が毎月1時間なので、月に何時間も録るなら年14,800円のプレミアムを足した総額で考える必要があります。セールで順番が入れ替わることもあるため、買う直前に各社の公式ストアを確かめてください。

**Q. 文字起こしの精度や音質はどれが良いですか。**
当サイトでは実機を使った検証をしておらず、共通の条件で比べた公式のデータもないため、精度や音質で順位は付けていません。公式に書かれている違いは、マイクの数(Plaud Note Pro は4基など)と収音距離(Notta Memo Pro は最大8m、Plaud Note Pro・Soundcore Work・オートメモは5m前後)です。話す人とマイクの距離が近いほど録りやすい、という点はどの製品でも同じです。
