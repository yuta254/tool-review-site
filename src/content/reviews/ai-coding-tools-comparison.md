## この記事の結論

- **エディタごと乗り換えて、AIと一緒にコードベース全体を操作したい**なら Cursor。ただし2026年8月にSpaceXが買収し、プランはGrokと共通の利用枠に変わりました。Grok以外のモデルはAPIの定価で別料金です
- **今のエディタのまま、補完とチャットを足したい**なら GitHub Copilot
- **Cursorと同じ方向のAIエディタを、OpenAI・Claude・Geminiなどのモデルを含むプランで比べたい**なら Devin Desktop(旧Windsurf)
- **コードを書かずに、アイデアを動くアプリにして公開まで進めたい**なら Replit Agent
- **ターミナルでの作業にAIエージェントを使いたい**なら Warp
- **AWS中心の開発でAmazon Q Developerを検討していた**場合、IDEプラグインはすでに新規受付が止まり、2027年4月30日にサポートが終わります。公式の移行先は **Kiro** です

料金プランや対応機能は各社が頻繁に見直しているため、導入前に必ず公式サイトの最新情報を確認してください。

個人向けプランの月額(米ドル)です。詳しい条件は各ツールの記事を参照してください。

| --- | --- | --- | --- |

| GitHub Copilot | Free(コード補完は月2,000回まで、チャットとエージェントは限定的) | Pro 10ドル・Pro+ 39ドル・Max 100ドル | 2026年6月から、チャットとエージェントはAIクレジットで数える仕組み。コード補完はクレジットを使わない |

## 比較の観点

一口に「AIコーディングツール」と言っても、守備範囲はかなり異なります。選ぶ前に整理しておきたいのは以下の3点です。

1. エディタ型(既存の開発環境に統合)か、エージェント型(自律的に複数ファイルを操作)か、それとも領域特化型(ターミナル、ブラウザ上の開発環境など)か
2. すでにコードが書ける人向けの設計か、非エンジニアでも使える設計か
3. 生成・自動変更されたコードやコマンドを、どの程度の頻度・粒度で人間がレビューする必要があるか

どのツールにも共通するのは、「生成結果をそのまま採用せず、差分やコマンドの内容を人間が確認する」という前提が外せないことです。

### Cursor

VS Codeをベースにフォークされたエディタで、チャットによる対話型編集と、複数ファイルにまたがる自動修正を行うエージェント機能を標準搭載しています。VS Codeの拡張機能・テーマ・設定・キーバインドを取り込む機能がありますが、拡張機能はVS Code MarketplaceではなくOpen VSXから入れる仕組みのため、すべての拡張機能があるとは限りません。

2026年8月14日の公式ブログによると、開発元のAnysphereはSpaceXに買収されました。料金はFree・Plus(月8ドル)・Premium(月30ドル)・Super(月100ドル)・Ultra(月200ドル)で、利用枠はxAIのGrokと共通です。Plusで使えるのはGrokのモデルだけで、Premium以上でも**他社のモデルは利用枠に含まれず、APIの定価で使った分が別に請求**されます。Grok以外のモデルを主に使うなら、月額とは別の費用を見込んでください。詳しくは[Cursorレビュー](/reviews/cursor-review/)をご覧ください。

### GitHub Copilot

いつものエディタ(VS Code / JetBrains系など)に組み込んで使うため、開発環境を変えずに導入できます。テストコードのひな形作成、既存コードと似たパターンの繰り返し実装、見慣れない言語での書き方の参考など、日々の開発フローの中での補助が中心です。有料プランでは、プルリクエストのコードレビューの補助や、課題を渡してプルリクエストを作らせるコーディングエージェントも使えます。

料金はFree・Pro(月10ドル)・Pro+(月39ドル)・Max(月100ドル)などで、2026年6月1日からチャットやエージェントの利用は「AIクレジット」で数える仕組みに変わりました(コード補完はクレジットを使いません)。また2026年4月24日から、Free・Pro・Pro+の利用者のやり取りのデータは、オプトアウトしない限りAIモデルの学習に使われます。詳しくは[GitHub Copilotレビュー](/reviews/github-copilot-review/)をご覧ください。

### Devin Desktop(旧Windsurf)

Windsurfは、2025年7月にCognitionが買収を発表したAIエディタです。2026年6月に「Windsurfの次の世代」として**Devin Desktop**が発表され、製品ページでは「Windsurfの新しい名前」と説明されています。切り替えは通常のアップデートで行われ、プラン・拡張機能・設定は引き継がれるとされています。

旧版の目玉だったエージェント「Cascade」は、公式ドキュメントで「レガシー」とされ、新しい会話にも過去の会話にも使えなくなりました。現在はローカルで動くエージェント「Devin Local」で作業し、クラウドのDevinへの受け渡しや、複数のエージェントをまとめて管理する「Agent Command Center」が加わっています。Cascade専用だった「Workflows」は使えないため、旧版の解説や手順はそのまま当てはまりません。

料金はFree・Pro(月20ドル)・Max(月200ドル)・Teams(80ドル〜)などで、Proでは OpenAI・Claude・Gemini などのモデルが使えます。公式ドキュメントによると、初期設定ではデータがモデルの学習に使われる場合があり、有料プランでは設定からオフにできます。詳しくは[Windsurf(現Devin Desktop)の解説](/reviews/windsurf-review/)をご覧ください。

### Replit Agent

ブラウザで使う開発環境Replitに組み込まれたAIで、ふつうの言葉で作りたいものを伝えると、コードを書き、必要な設定をして、結果を確かめ、そのまま公開まで進めます。現在の版は**Agent 4**(2026年3月発表)です。Cursorのような「すでにコードが書ける人向けのAIエディタ」とは対照的に、手元の環境構築なしで試作品を作ることに向いています。

プランはStarter(無料)・Core(月20ドル)・Pro(月100ドルから)・Enterprise。以前あったTeamsプランは終了し、契約者はProへ移されました。料金は「定額のプラン+使った分」で、無料のFree Modeと有料のPower・Maxモードがあり、有料モードの作業と公開の費用は月のクレジットから差し引かれます。料金ページにも、Agentは間違えることがあるという趣旨の注意があり、認証・権限まわりを中心に人間の確認が欠かせません。詳しくは[Replit Agentの解説](/reviews/replit-agent-review/)をご覧ください。

### Warp

AIエージェントと一緒に作業することを前提に作り直されたターミナルです。コマンドとその出力を「ブロック」単位でまとめ、エージェント(Warp Agent)が指示を受けてコマンドの実行やファイルの編集を行います。エージェントは実行や編集の前に承認を求め、どこまで自動で進めてよいかは設定で決めます。macOS・Windows・Linuxに対応し(Windowsではコマンドプロンプトは非対応)、2026年4月28日にはアプリ本体がオープンソース化されました。

料金はFree・Build(月20ドル)・Max(月200ドル)・Business(1人月50ドル)など。**Freeには、Warpが用意するAIの利用分が含まれていません**(使った分を買うか、自分のAPIキーなどを持ち込む)。ファイル削除やシステム設定の変更を伴うコマンドは、承認する前に内容を確認してください。詳しくは[Warpの解説](/reviews/warp-review/)をご覧ください。

### Amazon Q Developer(サポート終了が決定)

AWSが提供するAIコーディング支援ツールで、旧CodeWhispererを土台にしたサービスです。AWSの公式ブログ(2026年4月30日)で、サポート終了が発表されています。

- **2026年5月15日**:IDEプラグインからの無料枠のアカウント作成と、新しいサブスクリプションの作成を停止(既存のProへのユーザー追加は可能)
- **2027年4月30日**:IDEプラグインと有料サブスクリプションのサポート終了。IDEで行うJavaのアップグレードと.NETの移植(コード変換)も使えなくなり、代わりにAWS Transformが案内されている
- AWSマネジメントコンソールやSlack・Microsoft Teams向けのチャットアプリでのAmazon Q Developerは、影響を受けないとされている

そのため、これからIDEで使うツールとして新しく選ぶ対象にはなりません。公式の移行先は**Kiro**(仕様駆動開発のためのエージェント型IDEとCLI)で、料金ページではFree(0ドル・50クレジット)、Pro(月20ドル)、Pro+(月40ドル)などのクレジット制のプランが表示されています。既存の契約者向けの整理は[Amazon Q Developerの現状](/reviews/amazon-q-developer-review/)をご覧ください。

## どれを選ぶべきか(タイプ別)

| タイプ | 候補 |
| --- | --- |
| エディタごと乗り換えて、AIとコードベースを操作したい(Grok中心のプランで構わない) | Cursor |
| 普段のエディタのまま、補完とチャットを足したい | GitHub Copilot |
| 乗り換えるエディタで、OpenAI・Claude・Geminiなどのモデルを含むプランを使いたい | Devin Desktop(旧Windsurf) |
| コードを書かずにアイデアをアプリにして公開したい非エンジニア | Replit Agent |
| ターミナルでの作業にエージェントを使いたい | Warp |
| AWS中心の開発で、IDEのAIを新しく選びたい | Kiro(Amazon Q Developerの公式の移行先)。Q Developerの既存契約者は2027年4月30日までに移行を計画 |

## 導入前に押さえておきたいこと

- どのツールも「AIが生成・自動変更した内容を人間がレビューする」工程は省略できません。特にセキュリティ・認証・決済など影響範囲の大きい部分は必ず確認しましょう。
- **料金の数え方がツールごとに違います。** Cursorは週ごとの利用枠(他社モデルはAPI定価で別請求)、GitHub Copilotはドル建てのAIクレジット、Devin Desktopは日・週単位の利用枠、Replit Agentは月のクレジット、Warpはドル建ての利用分です。エージェントを使うほど消費が増えるため、想定利用量に応じたコストは[AI API料金計算ツール](/tools/ai-api-cost-calculator/)で事前に試算しておくと判断しやすくなります。
- **入力したコードの扱いを確認してください。** GitHub CopilotのFree・Pro・Pro+はオプトアウトしない限りやり取りが学習に使われ、Devin Desktopも初期設定では学習に使われる場合があります(有料プランで設定からオフにできる)。Cursorはプライバシーモードを有効にすると学習に使われないとされています。
- チャットに長いコードベースやログを貼り付ける機会が多い人は、[AIトークン数カウンター](/tools/token-counter/)でどの程度のトークン数になるかを事前に確認しておくと、想定外のコスト増や文脈の切り捨てを防ぎやすくなります。

料金プランや対応機能は変更される可能性が高い分野のため、契約前に必ず各公式サイトの最新情報を確認してください。

## よくある質問

**Q. 5つ全部を試す必要はありますか。**
ありません。まず「エディタを乗り換えてよいか」を決めると候補が絞れます。乗り換えたくないならGitHub Copilot、乗り換えてよいならCursorかDevin Desktopです。どちらにするかは、使いたいモデル(CursorはGrok中心、他社モデルは別料金)で分かれます。ターミナル作業が多いならWarpを足す、という順で考えると整理しやすくなります。

**Q. 無料プランだけで判断できますか。**
5つとも無料プランがありますが、範囲は大きく違います。たとえばWarpのFreeにはWarpが用意するAIの利用分が含まれず、GitHub CopilotのFreeはコード補完が月2,000回までです。判断材料にするなら、サンプルコードではなく自分のリポジトリで小さな作業を任せ、差分を確かめてください。

**Q. Windsurfは今も使えますか。**
Devin Desktopという名前に変わって提供されています。旧エージェントのCascadeは使えなくなっているため、Cascadeを前提にした古い解説には注意してください。

**Q. Amazon Q Developerを今から始められますか。**
IDEプラグインでは始められません。2026年5月15日から、無料枠のアカウント作成と新しいサブスクリプションの作成が止まっています。公式の移行先はKiroです。

**Q. 会社のコードを扱う場合の注意点は。**
入力データを学習に使わない設定があるか、その既定値は何か、を導入時に確認してください。個人プランと法人プランで条件が異なるツールが多く、個人プランを業務で使うのは避けるべきです。
