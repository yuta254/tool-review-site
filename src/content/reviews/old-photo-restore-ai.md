## この記事の結論

- **AIの高画質化は、写っていない細部を推定して描き足す処理です。** 見た目は鮮明になりますが、撮影した当時の姿がそのまま現れるわけではありません。Aiarty Image Enhancer の公式ページでも、モデルの仕組みを「ピクセルや微細な特徴をAIが推測・補完」と説明しています。
- **仕上がりを一番左右するのはスキャン。** エプソンの公式の製品ページでは、**300dpiは複製・共有、600dpiは引き伸ばし・トリミング、1200dpiはさらに精細な引き伸ばし**向けとされています。L判の写真を600dpiで読むと約2,100×3,000ピクセルになります。
- **元のデータは別に残す。** Adobe の古い写真の修復手順も、元の写真を変えずに上に調整を重ねる作り方です。補正後の画像だけを残すと、やり直しができません。
- **顔の補正は弱めから。** 公式の説明では、顔の補正機能に「しわ、シミ、ニキビ、赤み、そばかすを除去」まで含むものがあります。昔の家族写真を記録として残すなら、強さを下げ、元の写真と並べて確かめます。
- **人物写真は、どこで処理されるかを先に確かめる。** パソコンの中で処理するソフト(Aiarty、Upscayl のデスクトップ版、Topaz のローカル処理)と、画像をアップロードするサービス(Adobe Firefly のアップスケールなど)があります。
- **費用をかけずに始められる。** Upscayl は無料、Firefly のアップスケールは Adobe アカウントの無料クレジットの範囲で使えます。Aiarty の無料版は書き出しに透かしが入ります。

この記事の製品の機能・条件は、各社の公式サイトの説明を **2026年11月5日に公式で確認** した範囲で書いています。当サイトでは実機・実サービスを検証していません。仕上がりは元の写真の状態で大きく変わるため、ここに書いた手順で必ずきれいになるとは言えません。

## 手順の全体像

| 段階 | やること | 目安・注意 |
| --- | --- | --- |
| 1. 状態を見る | ぼけ・粒子・傷・色あせ・小ささのどれが気になるかを分ける | 目的によって使う機能が違う |
| 2. スキャン | フラットベッドかフォトスキャナーで読み取る | 引き伸ばすなら600dpi以上 |
| 3. 元データを保存 | スキャンしたままのファイルを別のフォルダに残す | 作業はコピーで行う |
| 4. 傷・色の補正 | 傷の軽減、色あせの補正、白黒のカラー化 | AIが色や線を推定する |
| 5. 鮮明化・拡大 | ノイズ除去、ぼかし解除、拡大 | 必要な大きさ以上に拡大しない |
| 6. 顔の補正 | 強さを下げて適用し、元と並べて比べる | 別の顔立ちに寄ることがある |
| 7. 保存・共有 | 補正後の画像を別名で保存。公開前に写っている人の了解を得る | 補正したことを分かるようにする |

## 1. 何を直したいかで、使う機能が変わる

「ぼやけた写真を鮮明にしたい」と言っても、原因は1つではありません。公式に案内されている機能を、困りごと別に並べます。

| 困りごと | 公式に案内されている主な機能 |
| --- | --- |
| 写真が小さい・画素が足りない | 拡大(アップスケール)。Aiarty は最大8倍のプリセット、Upscayl は最大16倍、Firefly は2倍・4倍、Lightroom などのスーパー解像度は縦横2倍 |
| ざらつき・粒子が目立つ | ノイズ除去(Aiarty、Topaz Photo など) |
| ピントが甘い・手ぶれ | ぼかし解除・シャープ(Aiarty の「AIぼかし解除」、Topaz Photo の Sharpen など) |
| 傷・汚れ・折れ目 | Photoshop のニューラルフィルター「写真を復元」の「スクラッチの軽減」とスポット修復ブラシ。Aiarty も活用例に色あせや傷のある古い写真の修復を挙げている |
| 白黒・セピアに色を付けたい | Photoshop のニューラルフィルター「カラー化」 |
| 顔がぼやけている | 顔の補正(Aiarty の「顔のレタッチ」モデル、Topaz の Recover Faces、Photoshop「写真を復元」の「顔の強調」) |

Adobe の公式ページの手順では、「写真を復元」で「写真の強調」「顔の強調」「スクラッチの軽減」のスライダーを調整し、残った傷はスポット修復ブラシやコピースタンプで直し、白黒やセピアの写真は「カラー化」で色を付ける流れが紹介されています。カラー化で付く色は、AIが推定した色です。当時の服や景色の色と同じとは限りません。

## 2. スキャンの解像度を決める

AIで補正する前の段階で、写真から読み取れる情報の量が決まります。スキャンが粗いと、AIが推定で補う部分がその分増えます。

エプソンのフォトスキャナー(FF-680W)の公式の製品ページでは、解像度ごとの向く用途が次のように書かれています。

| 解像度 | 公式ページの説明 | L判(89×127mm)を読んだときの大きさ(計算値) |
| --- | --- | --- |
| 300dpi | 写真の複製、スライドショー、共有に向く | 約1,050×1,500ピクセル |
| 600dpi | 写真の引き伸ばし、トリミングに向く | 約2,100×3,000ピクセル |
| 1200dpi | 非常に精細。引き伸ばし・トリミングに向く | 約4,200×6,000ピクセル |

- **画面で見る・家族で共有するだけ** なら300dpi、**集合写真の一人を切り出す・大きく印刷する** なら600dpi以上、というのが公式の説明から読める使い分けです。
- 同じページには、少し破れた写真は付属のキャリアシートに入れて読み取れると書かれています。一方で、このスキャナーには破れの補正や裂け目を直す機能は無いとも明記されています。破れや欠けは、読み取った後に画像編集ソフトで直す作業になります。
- 解像度を上げるほどファイルは大きくなります。アルバム一冊分を読むなら、先に数枚で保存先の容量を見積もっておくと途中で止まりません。

## 3. 元のデータを残す

Adobe の古い写真の修復手順では、スキャンした写真の上に新しいレイヤーを作り、元の写真を変えずに調整を重ねる方法が紹介されています。専用のソフトを使う場合も考え方は同じです。

- スキャンしたままのファイルは、別のフォルダ(できれば別のドライブ)に残す
- 補正した画像は別の名前で保存する(例:「祖父母_1970_補正.png」)
- 補正の強さや使った機能をメモしておくと、後で別の設定でやり直せる

## 4. 顔の補正の限界

古い写真で一番気になるのは顔ですが、AIの補正が最も推定に頼るのも顔です。

- **AIは、写っていない部分を推定で描き足します。** 元の画素が少ないほど(集合写真の小さな顔など)、描き足す部分の割合が増えます。目の形、しわ、ほくろ、歯並びなどが実物と違う形で描かれても、AIの側ではそれを判断できません。
- **美しく整える機能と、記録として残す目的はぶつかることがある。** Aiarty の公式ページでは、顔の補正機能の説明に「しわ、シミ、ニキビ、赤み、そばかすを除去」が含まれています。人物を記録として残したいなら、その人らしい特徴まで消えていないかを確かめてください。
- **強さを調整できる機能は、弱めから始める。** Photoshop の「写真を復元」には「顔の強調」のスライダーがあり、強さを変えられると公式ページで案内されています。
- **元の写真と並べて、写っている人を知る家族に見てもらう。** 本人をよく知る人が「別人に見える」と感じたら、補正を弱めるか、顔の補正を使わない版も残しておきます。
- **身分証明や記録・証拠には補正後の画像を使わない。** 補正後の画像は、元の写真そのものではありません。

## 5. 人物写真を扱うときの注意

### 画像がどこで処理されるか

| 処理の場所 | 例(公式の説明) |
| --- | --- |
| パソコンの中 | Aiarty Image Enhancer(「完全にオフラインで動作」、画像データを外部のサーバーに送らないと公式に記載)、Topaz Gigapixel のローカル処理(「ファイルはパソコンから出ない」)、Upscayl のデスクトップ版(パソコンのGPUで処理) |
| 画像をアップロード | Adobe Firefly の画像アップスケール(Adobe アカウントでログインしてアップロード)、Topaz のクラウド処理、Upscayl Cloud |

家族の写真でも、写っている人の顔は個人の情報です。クラウドで処理するサービスを使う場合は、そのサービスの利用規約とプライバシーポリシーで、アップロードした画像の保存期間や扱いを確かめてから使ってください。たとえば Upscayl Cloud の料金ページには、解約の1か月後に履歴を削除すると書かれています。

### 公開・共有する前に

- SNS などに公開する前に、写っている人(家族を含む)の了解を得る
- 補正した写真であることを、共有する相手に伝える
- 写真館の業務など、他人の写真を預かって補正する場合は、預かった画像をどこで処理するかを事前に伝える。商用で使う場合の考え方は[AIで作ったものを商用利用する前のチェックリスト](/reviews/ai-commercial-use-checklist/)も参考になります

## 6. 条件で分ける道具の選び方

- **1〜2枚を無料で鮮明にしたい** → Adobe Firefly の画像アップスケール(2倍・4倍、100MB以下の JPEG・PNG・WEBP)。画像はアップロードする形です。Vulkan 対応のGPUがあるパソコンなら Upscayl(無料)も候補です。
- **アルバム一冊分をまとめて処理したい** → 一括処理ができるもの。Aiarty は有料版で一括書き出しができ(無料版は不可)、Upscayl にも一括処理があります。
- **家族の写真を外に出したくない** → パソコンの中で処理する Aiarty、Upscayl のデスクトップ版、Topaz のローカル処理。
- **傷・色あせ・白黒が主な悩み** → Photoshop の「写真を復元」と「カラー化」。Photoshop 単体プランは月3,280円、フォトプランは月2,380円(いずれも税込・年間プランの月々払い)です。
- **ぼけ・粒子・小ささが主な悩み** → 高画質化ソフト。製品ごとの料金・無料版の範囲・動作環境は[AI画像高画質化・拡大ソフトの比較](/reviews/image-upscaler-comparison/)で整理しています。

## よくある質問

### AIで補正すると、古い写真は撮影した当時の状態になりますか。

なりません。AIは写っていない細部を推定して描き足すので、鮮明に見えても、描き足された部分が実物と同じとは限りません。見やすくするための補正と考え、元のスキャン画像は必ず残してください。

### スマートフォンで撮影した写真でも補正できますか。

各ソフトは JPEG や PNG などの一般的な形式を読み込めるので、スマートフォンで撮った画像も扱えます。ただ、引き伸ばしやトリミングを考えるなら、スキャナーの公式の説明にあるとおり600dpi以上で読み取った画像の方が、元の情報を多く残せます。撮影する場合は、照明の映り込みや写真のゆがみが出ないように撮ると、補正で直す部分が少なく済みます。

### 白黒写真をカラーにできますか。

Photoshop にはニューラルフィルターの「カラー化」があり、白黒やセピアの写真に色を付ける手順が Adobe の公式ページで紹介されています。付く色はAIの推定なので、当時の実際の色と同じとは限りません。

### 破れた写真はどうすればよいですか。

エプソンの FF-680W の公式ページでは、少し破れた写真は付属のキャリアシートに入れて読み取れるとされています。同じページに、スキャナーには破れの補正や裂け目を直す機能は無いとも書かれているので、読み取った後に、Adobe の手順で残った傷の修正に使うと案内されているスポット修復ブラシやコピースタンプなどで目立たなくする作業になります。

### 無料でどこまでできますか。

Upscayl のデスクトップ版は無料で、拡大と一括処理ができます(Vulkan 対応のGPUが必要)。Adobe Firefly の画像アップスケールは、Adobe アカウントの毎日の無料クレジットの範囲で使えます。Aiarty Image Enhancer の無料版はAI処理ができますが、書き出した画像に透かしが入り、一括書き出しは使えないと公式の購入FAQに書かれています。
