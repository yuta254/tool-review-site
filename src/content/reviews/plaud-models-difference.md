## この記事の結論

- 公式ストアで買える本体は、**カード型の Note Pro(30,800円)・Note(27,500円)と、ピン型の NotePin S(28,600円)・NotePin(27,500円)の4機種**です(税込)。Note Pro には、保存容量を512MBにした **Flow Edition(29,700円)** もあります。イヤホン型の新製品 **Plaud One(44,000円)** は、日本では販売準備中です。
- 最初に分かれ目になるのは**通話を録るかどうか**です。カード型の2機種には通話の録音モードがあり、ピン型の2機種は公式の比較表で「**対面録音モードのみ**」とされています。
- **Note Pro と Note の差は3,300円。** Note Pro はマイクが4基(Note は2基)で収音範囲は最大5m(Note は3m)、通話と対面を**自動で**切り替え、AMOLEDディスプレイを備え、長時間駆動モードなら**最大50時間**録音できます。
- **NotePin S と NotePin の差は1,100円。** NotePin S は物理ボタンで、短押しで大事な場面に印(ハイライト)を付けられます。NotePin は感圧ボタンで、ハイライトはアイコンのタップで付ける形です。連続録音はどちらも最長20時間で、NotePin S にはリストバンドとネックストラップも同梱されます。
- Apple の「探す」に対応するのは **Note Pro・NotePin S・NotePin** で、Note は比較表で「--」です。
- **文字起こしと要約のプランは機種で変わりません。** どの機種も本体を買うと無料の Starter(毎月300分)が付きます。機種で変わるのは「録音のしかた」の部分です。

この記事の仕様と価格は、PLAUD の日本公式サイト(jp.plaud.ai)の[機種の比較ページ](https://jp.plaud.ai/pages/plaud-device-comparison)・[シリーズ比較ページ](https://jp.plaud.ai/pages/plaud-series-comparison)と、各機種の商品ページ([Note Pro](https://jp.plaud.ai/products/plaud-note-pro)・[Note](https://jp.plaud.ai/products/plaud-note-ai-voice-recorder)・[NotePin S](https://jp.plaud.ai/products/plaud-notepin-s)・[NotePin](https://jp.plaud.ai/products/notepin)・[Plaud One](https://jp.plaud.ai/products/plaud-one))の表示を**2026年11月5日**に確認したものです。価格はセールで変わることがあります。当サイトでは実機を検証していません。録音の聞き取りやすさや文字起こしの精度は測っておらず、公式に書かれている仕様だけで比べています。

## まず「通話を録るか」で分ける

公式の説明では、カード型の Note Pro と Note は、マグネットケースに入れてスマートフォンの背面に付けて使うか、単体で持ち歩いて使う形です。カード型には MEMS マイクとは別に VPU が1基あり、Note Pro のFAQではこれを「骨伝導センサー(VPU)」と説明しています。ピン型には VPU がなく、NotePin S のFAQには、振動伝導センサーを搭載していないため通話録音に対応していないと書かれています。比較表でもピン型の録音モードは「対面録音モードのみ」です。

- **電話の内容も残したい** → カード型(Note Pro か Note)
- **対面の会話だけでよく、身につけて録りたい** → ピン型(NotePin S か NotePin)

ピン型は、マグネットピン・クリップ・ネックストラップ・リストバンドの4種類の付け方が案内されています。ただし NotePin の同梱品はマグネットピン・クリップ・充電ドック・ケーブルで、リストバンドとネックストラップが最初から入っているのは NotePin S です。

## Note Pro と Note の違い(カード型)

大きさと重さ(30g)は同じで、違いは中身です。

| 違うところ | Note Pro | Note |
| --- | --- | --- |
| マイクと収音範囲 | 4基・最大5m | 2基・最大3m |
| 通話と対面の切り替え | 自動 | 手動 |
| 画面 | 0.95インチのAMOLED(Note Pro のページでは600ニト) | なし |
| 録音時間 | 最大30時間、長時間駆動モードで最大50時間 | 最大30時間 |
| 無線 | BLE 5.4、2.4GHzと5GHzのWi-Fi | BLE 5.2、2.4GHzのWi-Fi |
| Apple「探す」 | あり | なし |
| 価格 | 30,800円 | 27,500円 |

**会議室で離れた席の声まで録りたい**、**通話と対面をいちいち切り替えたくない**、**録音中かどうかを画面で確かめたい**、のどれかに当てはまるなら Note Pro、どれも要らないなら Note、と分けると迷いにくくなります。

### Note Pro Flow Edition

2026年11月5日時点の公式ストアでは、Note Pro の商品ページで「Plaud Note Pro Flow Edition」(29,700円・ブラックとシルバー)も選べます。公式のFAQでは、通常の Note Pro との違いを次の2点としています。

- **収音**:AI指向性収音技術を搭載した、S/N比68dBのMEMSマイクを4基搭載
- **保存容量**:512MBで、データを転送するまでの一時保存用。標準の録音品質で約30時間分を保存でき、録音が終わるごとにアプリへ自動転送される

自動転送は Plaud App の設定で有効にする必要があり、現時点では iPhone のみ対応(Android は今後対応予定)と注記されています。その他の機能・仕様は Note Pro と共通とされ、充電端子は USB-C と書かれています。

本体の中に録音をためておきたい人や、Android のスマートフォンを使う人は、64GBの通常の Note Pro の方が条件に合います。iPhone を使っていて、録音を本体に残すよりアプリに自動で送りたい人向けの型です。

## NotePin S と NotePin の違い(ピン型)

大きさ(51×21×11mm)、マイク(2基)、収音範囲(3m)、連続録音(最長20時間)、待機(40日)は同じです。

| 違うところ | NotePin S | NotePin |
| --- | --- | --- |
| 録音ボタン | 物理ボタン | 感圧ボタン |
| ハイライト | 短押しで付ける | アイコンのタップで付ける |
| 電池 | 320mAh | 270mAh |
| 重さ(マグネットピンなし) | 17.4g | 16.6g |
| 同梱品 | リストバンドとネックストラップも入る | マグネットピン・クリップ・充電ドック・ケーブル |
| 価格 | 28,600円 | 27,500円 |

どちらもハイライトは付けられます。**物理ボタンで操作したい、付け方を最初から全部そろえたい**なら NotePin S、**少しでも安くしたい**なら NotePin です。公式の比較表の上では、録音時間は同じです。

ピン型のマグネットピンとクリップには磁石が使われています。NotePin S のFAQでは、最大2,100ガウスの磁場を生じるとして、ペースメーカーを使っている人は、ネックストラップ・マグネットピン・クリップのいずれでも胸部に着けないよう書かれています。NotePin の商品ページにも同じ趣旨の注意があります。

## 日本では販売準備中の Plaud One

公式ストアには、イヤホンと充電ケースの形をした新製品「Plaud One」(44,000円)のページもあります。2026年11月5日時点では「日本での販売は現在準備中です」と表示され、買えるのはまだ先で、ウェイトリストへの登録を受け付けている段階です。

公式ページの仕様では、イヤホンに MEMS マイク3基と VPU 1基(各イヤホン)、ケースに MEMS マイク4基を備え、収音範囲はイヤホンが最大2m、ケースが最大5mです。連続録音はイヤホンで最大3.5時間、ケースで最大25時間、スタンバイは最大14日間です。ケースには契約不要の eSIM が入り、4G LTE で録音のアップロードやAI機能を使えると説明されています。一部の機能はベータ版や今後の更新で提供されると注記されているため、発売時の条件を見てから比べるのが確実です。

## 4機種で同じところ

- **文字起こしと要約のプラン**:どの機種も同じクラウドのサービスで処理され、本体を買うと無料の Starter プラン(毎月300分)が付きます。有料の Pro(年額16,800円・月1,200分)と Unlimited(年額40,000円)も機種によらず共通です。プランの選び方と1年目・2年目の総額は[PLAUDの料金まとめ](/reviews/plaud-note-price-plans/)に整理しました。
- **製品保証**:シリーズ比較ページには、1年間の製品保証について「保証期間はご利用の地域における基準に準じます」と注記されています。
- **データの扱い**:保存先や暗号化は機種ではなくサービス側で決まります。会社で使う場合の確認点は[PLAUDを会社で使うときのセキュリティ](/reviews/plaud-note-business-security/)にまとめました。

## よくある質問

### Plaud Note Pro と Plaud Note の違いは何ですか。

公式の比較表では、Note Pro はマイクが4基で収音範囲が最大5m、通話と対面を自動で切り替え、AMOLEDディスプレイと Apple「探す」に対応し、長時間駆動モードで最大50時間録音できます。Note はマイク2基・最大3mで、通話と対面は手動で切り替えます。大きさと重さは同じで、価格差は3,300円です。

### NotePin で電話の録音はできますか。

公式の比較表では、NotePin S と NotePin の録音モードは「対面録音モードのみ」とされ、NotePin S のFAQにも通話録音に対応していないと書かれています。電話の内容も残したい場合は、通話の録音モードがあるカード型の Note Pro か Note を選びます。

### NotePin S と NotePin の違いは何ですか。

公式の情報では、NotePin S は物理ボタンで、短押しでハイライトを付けられ、電池は320mAhです。NotePin は感圧ボタンで、ハイライトはアイコンのタップで付け、電池は270mAhです。連続録音(最長20時間)・待機(40日)・マイク・大きさ・保存容量(64GB)は同じで、NotePin S にはリストバンドとネックストラップも同梱されています。

### 機種によって文字起こしの精度やプランは変わりますか。

プランの内容(時間・言語・要約の機能)は機種で変わりません。差が出るのは録音の段階で、マイクの数・収音範囲・通話を録れるかどうかが機種で違います。文字起こしの精度を機種ごとに比べた公式の数値は、確認したページには載っていませんでした。

### Note Pro Flow Edition は通常の Note Pro と何が違いますか。

公式のFAQでは、S/N比68dBのマイク4基で収音性能が上がっている一方、本体の保存容量は一時保存用の512MB(標準の録音品質で約30時間分)で、録音ごとにアプリへ自動転送する型と説明されています。自動転送は現時点で iPhone のみ対応です。価格は29,700円で、通常の Note Pro(30,800円・64GB)より1,100円安い表示です。
