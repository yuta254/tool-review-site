## 総評

この記事の料金・機能は公式サイトの記載を2026年11月12日に確認したものです(Sparkpage の公開ページとアフィリエイトの案内は2026年11月6日の確認)。当サイトで実際に使った検証はしていません。

Gensparkは、以前は質問に対して複数のWebサイトを横断的に調べ、その内容を1枚の「Sparkpage」と呼ばれるまとめページにするAI検索ツールとして知られていました。2026年11月12日に公式ヘルプを確認したところ、現在は調べ物からスライド・資料・Webページなどの成果物づくりまでを任せる「Super Agent」を中心にした AIワークスペースとして案内されており、機能一覧に Sparkpage の項目はありませんでした。公式ヘルプでは Super Agent(スーパーエージェント)を、欲しい成果物を伝えてファイルを添えると、手順を計画してクラウドコンピューター上で実行し、そのまま開けるファイル(レポート、プレゼン資料、スプレッドシート、Webページなど)を返すエージェントと説明しています。依頼を手順に分け、手順ごとに道具を選んで進めるとされ、長い作業は最大2時間まで実行できます。ほかに AI Slides・AI Sheets・AI Docs などの機能があります。

同じリサーチ系のPerplexityが「引用元付きの回答」を返すのに対し、Gensparkは「資料のような成果物」まで作るのが違いです。成果物の見た目が整っていても、内容を鵜呑みにしてよいかどうかは別問題です。Perplexity・NotebookLM との違いは[Genspark・Perplexity・NotebookLMの違い](/reviews/genspark-perplexity-notebooklm-difference/)にまとめています。

## Genspark の Sparkpage とは(今はどうなっているか)

Sparkpage(スパークページ)は、**質問に対して AI が Web の情報を集め、1枚のページにまとめたもの**です。ただし、**2026年11月12日に確認した Genspark の公式ヘルプの機能一覧に Sparkpage の項目はなく、いまの中心は Super Agent や AI Slides などの成果物づくりです。** Sparkpage を目当てに Genspark を調べている場合は、この点を先に押さえておくと迷いません。

Genspark の公式ブログの紹介記事(Introduction to Sparkpage)では、Sparkpage を次のように説明しています。

- Web 上の多くの情報を、1つのまとまったページに凝縮する
- ページごとに AI のコパイロットが付き、ページの内容について質問できる。ページに答えがなければ、Web を調べて答える
- ほかの人の Sparkpage を元に、自分のページを作る(フォークする)ことができる

いまの Genspark については、次のことを確かめました(2026年11月6日)。

- 公式ヘルプセンターの機能一覧には、Super Agent・AI Slides・AI Sheets・AI Docs・AI Drive など30を超える項目が並んでいますが、Sparkpage の項目はありませんでした。
- 検索結果に出てくる `genspark.ai/spark/` で始まる公開ページを3件開いたところ、いずれも「このページはもう利用できない。恒久的に削除された」と表示されました。
- 以前作った Sparkpage の扱いや、機能が終わった時期についての公式の案内は、確認した範囲では見つかりませんでした。

調べた内容を1枚にまとめたいなら、いまは Super Agent に頼んで、Webページやスライド、資料の形で作ってもらうのが公式の案内に沿った使い方です。

## Genspark のアフィリエイト(紹介)プログラムはあるか

**2026年11月6日に Genspark の公式サイトと公式ヘルプセンターを確認した範囲では、紹介した人に報酬が支払われるアフィリエイト(紹介)プログラムの公式の案内は見つかりませんでした。** 公式のトップページのリンク、ヘルプセンターの「Account Management」「Membership Plans」「Credits Guide」のどれにも、アフィリエイトや紹介報酬の記載はありませんでした。

公式サイトにあるのは、利用者のコミュニティづくりを手伝う「**Genius Program**(ベータ版)」です。公式ページの説明の要旨は次のとおりです。

| 項目 | 公式ページの説明の要旨 |
| --- | --- |
| 中身 | 各地域や業界ごとのコミュニティ(チャプター)を率い、勉強会・ハッカソンを開き、使い方の解説や事例を発信する |
| 受け取れるもの | 公式の「Genius」の肩書き、Plus プランと作業用のクレジット、記念品、新機能の先行利用、イベント開催の費用の補助、公式の場での紹介 |
| 求める人 | 毎日 Genspark を使っている人、業界の知識がある人、人を集められる人、継続して時間をかけられる人 |
| かける時間 | 多くの人は月10〜20時間ほど(よくある質問より) |

Genius Program は紹介の件数に応じて報酬が出る仕組みとしては説明されておらず、アフィリエイトプログラムとは別物です。なお、Genspark を扱うアフィリエイトの案件が第三者のサイトに載っていることがありますが、公式の案内で確かめられないため、当サイトでは報酬の条件を書きません。参加を考える場合は、Genspark に直接問い合わせて確かめてください。

## 得意なこと

- 「〇〇の比較」「〇〇のやり方」といった調べ物を、スライドや資料、Webページなどの形にまとめるところまで任せられる
- 依頼を手順に分け、必要な道具を選んで進めるため、調べる・まとめる・形にするを1つの依頼で進めやすい
- 手元のファイルや連携したアカウントの情報も材料にできる(公式ヘルプの説明)
- エージェントが仕上げた成果物はプロジェクトに保存され、後からダウンロードできる

## 過信は禁物な点

- 成果物は見た目が整っているため、内容の正確性まで担保されているように錯覚しやすい。数値や固有名詞は一次情報を自分の目で確認する必要がある
- 専門性の高いトピック(医療・法律・最新の技術仕様など)では、一般にAIの要約に古い情報や誤りが混じるおそれがあるため、専門家の資料や公式の情報で必ず裏取りする
- 確認した Super Agent の公式ヘルプには、出典の示し方や情報源の選び方についての説明は見当たりませんでした。重要な意思決定の根拠として単独で使うのは避ける
- 複数の情報源をまとめる過程で、個々のニュアンスが単純化され、細部の違いが見えにくくなることがある
- 作業の量はクレジットで数えられ、無料版のクレジットには生涯の上限がある(下の料金を参照)

## 料金(2026年11月12日確認)

Genspark の公式ヘルプ(Membership Plans)の表示です。ドル建てです。

| プラン | 月払い | 年払い | クレジット |
| --- | --- | --- | --- |
| Free | 0ドル | — | 1日100クレジットを補充(生涯の上限に達すると補充が止まる) |
| Plus | 月24.99ドル | 月19.99ドル(年239.99ドル) | 月10,000から |
| Pro | 月249.99ドル | 月199.99ドル(年2,399.99ドル) | 月125,000から |
| Team | 1人あたり月40ドル | 1人あたり月35ドル(年420ドル) | 1人あたり月10,000 |

Enterprise は個別見積もりです。無料版の生涯の上限がいくつかは、確認したページには書かれていませんでした。Plus と Pro には、Super Agent・AI Slides・AI Sheets・AI Docs などを標準モードで使う作業にクレジットを使わない「無料枠」が週ごとに付きます(Pro は Plus の10倍)。無料枠を使い切ると、プランのクレジットを使う形に切り替わります。

## 向いている人

- 調べ物の結果を、スライドや資料の形ですぐ共有・保存したい人
- 比較検討が必要なテーマ(製品選び、旅行計画、ツール選定など)を効率よく整理したい人
- 一次情報の裏取りを自分で行う前提で、リサーチの初期段階のたたき台が欲しい人

## 使い方のコツ

1. まずは軽い調べ物や比較検討から始め、出来上がった成果物の正確さを自分の目で確かめる
2. 重要な数値や固有名詞は、元の記事や公式のページを開いて必ず裏取りする
3. 専門性の高いテーマでは、Gensparkの結果を一次情報として扱わず、あくまで論点整理の出発点として使う

最新の料金プランや対応機能は変更される可能性があるため、利用前に必ず公式サイトで最新情報を確認してください。

## よくある質問

**Q. 通常の検索と何が違いますか。**
検索結果の一覧ではなく、調べた内容をまとめた資料やページなどの成果物が出来上がる点が違いです。調べ始めの全体把握には向きますが、特定の一次情報にたどり着きたい場合は従来の検索のほうが速く終わります。

**Q. Sparkpage は今も作れますか。**
2026年11月6日に確認した公式ヘルプの機能一覧には Sparkpage の項目がなく、作り方の案内も見当たりませんでした。調べた内容を1つのページにまとめたい場合は、Super Agent に Webページや資料の形で作ってもらうのが、いまの公式の案内に沿った使い方です。

**Q. Genspark にアフィリエイトプログラムはありますか。**
2026年11月6日に公式サイトとヘルプセンターを確認した範囲では、紹介報酬が出るアフィリエイトプログラムの公式の案内は見つかりませんでした。公式にあるのは、コミュニティを率いる人向けの「Genius Program」で、紹介の件数に応じた報酬の仕組みとしては説明されていません。

**Q. 生成された資料の情報は信用できますか。**
出典が示されていても、その出典が主張を裏付けているかは別問題です。重要な判断に使う情報は、必ず元のページを開いて確認してください。

**Q. Perplexityと使い分けますか。**
Perplexityは質問に出典つきの回答を返す検索AI、Gensparkは調べた内容をもとに資料などの成果物まで作るAIワークスペースという性格の差があります。料金と無料版の制限を並べた比較は[Genspark・Perplexity・NotebookLMの違い](/reviews/genspark-perplexity-notebooklm-difference/)、用途別の選び方は[リサーチAI4種の比較](/reviews/ai-research-tools-comparison/)を参照してください。
