## この記事の結論

- Replit Agent は、ブラウザで使う開発環境 Replit に組み込まれたAI。ふつうの言葉で頼むと、計画・設定・コードを書く・テスト・公開までを進める。現在の版は Agent 4(2026年3月11日発表)
- プランは **Starter(無料)・Core(月20ドル、年払いで月18ドル)・Pro(月100ドル、年払いで月90ドル〜)・Enterprise(要問い合わせ)**(2026年11月23日に公式の料金ページで確認。11月3日から変更なし)
- 料金は「定額のプラン+使った分」。無料の **Free Mode** には利用枠があり、Core・Pro は**5時間ごとに戻り、週の上限もある**。有料の Power・Max の作業はプランのクレジットから引かれ、切り替わる前に確認が求められる
- 有料の作業は**頼んだ内容の手間に応じた課金で、チェックポイント単位**。Plan モードの計画も、コードを変えなくても課金される
- 公開の費用も月のクレジットから引かれる。静的なサイトは公開無料(転送量1GBあたり0.05ドル)、常時動かす Reserved VM は月15ドルから
- 無料の Starter で公開できるアプリは1つで、**30日で自動的に止まる**
- 利用規約(2026年8月3日更新)では、**定期プランの支払いは購入から30日以内なら全額返金**。使った分の課金は返金なし。料金ページには「所在地によって税がかかる」とある

この記事は、Replit の料金ページ・公式ドキュメント(docs.replit.com)・公式ブログ・利用規約を2026年11月23日に確認してまとめたものです。当サイトでは Replit を操作して確かめてはいません。

## Replit Agentとは

Replit は、手元のパソコンに開発環境を用意せず、ブラウザの中でコードを書いて動かし、そのまま公開まで行えるサービスです。Replit Agent はその中のAIで、[Agent の公式ドキュメント](https://docs.replit.com/features/agent/overview)では、ふつうの言葉で作りたいものを伝えると、計画・準備・コード・テスト・公開を Replit が担い、「コードや技術の知識は要らない」と説明されています。

| 項目 | 公式の説明の要旨 |
| --- | --- |
| 作るもの | Webアプリ・スマホアプリ・スライド・データの表示などを、ふつうの言葉の指示から作る |
| 戻せる | 作業中にチェックポイントを作り、前の状態に戻せる |
| 計画 | Plan モード(`/plan`)で作業の一覧を出し、確認・承認してから作り始められる |
| デザイン | Design Canvas で画面の案を出して比べられる |
| 裏での作業 | 同時に動かせる裏の作業(background tasks)は Starter 0、Core 1、Pro 10 |
| 外部サービス | BigQuery・Linear・Slack・Notion などとつなぐ Connectors(Core 以上) |

料金ページには、Agent の動きは確率的で間違えることがある、という趣旨の注意も書かれています(2026年11月3日確認)。

## Agent の課金のしくみ

いちばん分かりにくい部分です。[Agent のモード](https://docs.replit.com/features/agent/agent-modes)、[Free Mode のヘルプ](https://docs.replit.com/help/free-agent-mode)、[AIの課金](https://docs.replit.com/billing/ai-billing)のドキュメントを整理します(2026年11月23日確認)。

| モード | 位置づけ | 費用 |
| --- | --- | --- |
| Free Mode | アイデアを試す、作り始める。モデルは Replit が自動で選ぶ | 追加費用なし。利用枠あり。Core・Pro は5時間ごとに戻り、週の上限もある |
| Power | 費用を抑えたいとき。1つの作業に使うクレジットが少ない | 有料(クレジットから) |
| Max | 複雑な作業向け。より高性能なモデル | 有料(クレジットから) |
| Auto | Power か Max を選んだうえで、作業ごとに Replit がモデルを選ぶ(Core・Pro) | 有料(クレジットから) |

- **有料モードに切り替わるとき:** Free Mode で手に負えない依頼では、Agent が理由を説明し、**有料の作業を始める前に確認を求めます。** 承認はその依頼だけに効き、終わると Free Mode に戻ります。断って Free Mode のまま続けることもできます。
- **何に対して課金されるか:** 頼んだ内容の手間に応じた課金で、1つの依頼につき1つのチェックポイントにまとめて数えられます。簡単な修正は安く、大きな機能の追加は高くなります。
- **計画にも課金:** Power・Max では、Plan モードの計画もコードを変えなくても通常の依頼として課金されます。Free Mode では Free Mode の枠を使います。
- **外部のAI:** Claude・ChatGPT・Gemini などを呼ぶ機能は、各社の公開のAPI料金でクレジットから差し引かれます。
- **使いすぎを防ぐ設定:** Billing の画面で、指定額に達したらメールで知らせる「使用量のアラート」と、それ以上使えなくする「予算の上限」を設定できます。Free Mode の残りは設定の Usage で見られます。
- 契約者全員に、1回限りの無料のチェックポイントが付くと書かれています(数は書かれていません)。

## 公開(デプロイ)の方式と費用

[公開費用のドキュメント](https://docs.replit.com/billing/deployment-pricing)の金額です(2026年11月23日確認)。公開の費用は月のクレジットから先に差し引かれ、使い切った後は使った分の料金がかかります。

| 方式 | 向いているもの | 費用(米ドル) |
| --- | --- | --- |
| Autoscale | アクセスに合わせて自動で増減するアプリ | 基本料月2ドル+計算量100万単位あたり0.60ドル+リクエスト100万回あたり0.40ドル |
| Static | 入力によって中身が変わらないサイト | 公開は無料、転送量1GBあたり0.05ドル |
| Reserved VM | 常に動かし続けたいアプリ | 月15ドル(共有・0.5vCPU/2GB)、35ドル(1vCPU/4GB)、50ドル(2vCPU/8GB)、130ドル(4vCPU/16GB) |
| Scheduled | 決まった時刻に動かす処理 | 基本料月2ドル+計算量100万単位あたり0.60ドル |

- Core には外向きの転送量が**月100GiB**含まれると[使った分の課金のドキュメント](https://docs.replit.com/billing/about-usage-based-billing)に書かれています。
- 本番用のデータベースは、動いていた時間と保存量で課金されます(要求を受けている間と、最後の要求から5分間が「動いている」扱い)。保存量の上限は有料プラン100GiB、Starter 1GiB。開発用のデータベースは無料です。
- 独自ドメインの付け方と、ドメイン代を含めた年間の費用は、[AIで作ったサイトを公開する方法](/reviews/ai-site-publish-custom-domain/)の Replit の章にまとめています。

## 返金と解約

[利用規約](https://replit.com/terms-of-service)(2026年8月3日更新)の要点です(2026年11月23日確認)。

- **定期プランの支払いは、購入から30日以内なら全額返金**の対象です。対象は直近の1回分の請求だけで、過去の請求期間の分は対象外です。
- **使った分の課金(Usage-Based Billing)は返金されません。** Agent の有料モードや公開の費用の超過分がこれに当たります。
- 定期プランは期間の終わりに自動で再請求されます。解約はアカウントのページからいつでもできます。価格は契約期間の終わりに変わることがあると書かれています。
- Replit がアカウントを停止・解約した場合や、機能を変更・削除した場合は、支払い済みの料金は返金しないと書かれています。

## データの扱いと、利用者が気をつけること

Replit の「[共同責任モデル](https://docs.replit.com/features/security/shared-responsibility-model)」のドキュメント(2026年11月3日確認、今回は再確認せず)では、Replit と利用者のどちらが何に責任を持つかが整理されています。

- 入力した指示や生成されたコードの記録・保存期間・学習への利用は、Replit の責任で、**契約しているプランの規約に従う**とされています。具体的な保存期間はこのページには書かれていません。
- **Agent が作ったコードの正しさ・安全性・ライセンスの確認**(Agent が追加した外部の部品を含む)は、利用者の責任です。
- APIキーなどの秘密の情報は、チャットに貼らず、Secrets や Connectors の機能で保管するよう案内されています。

## 1年・2年の総額の試算

プランの定額部分だけを合計した目安です。税、使った分の超過料金、公開の費用の超過分は含みません。円は1ドル=150円で換算しています。

| プラン | 年払い・1年 | 年払い・2年 | 月払い・1年 | 年払い1年の円の目安 |
| --- | --- | --- | --- | --- |
| Core | 216ドル | 432ドル | 240ドル | 約32,400円 |
| Pro(最初の段階) | 1,080ドル | 2,160ドル | 1,200ドル | 約162,000円 |

Replit は、有料モードの作業と公開の費用がまず月のクレジットから引かれ、使い切ると追加の請求になります。たとえば Reserved VM の最小構成(月15ドル)で1つのアプリを1年動かすと、それだけで180ドル分になります。Billing の画面で予算の上限を先に決めておくと、総額の見通しが立ちます。

## よくある質問

**Q. Replit Agent は無料で使えますか。**
無料の Starter プランでも、上限つきの Free Mode を使えます。ただし、公開できるアプリは1つで30日で自動的に止まり、Connectors などは使えません。続けて公開するなら Core(月20ドル、年払いなら月18ドル)以上が想定されています(2026年11月23日確認)。

**Q. 料金はどのように決まりますか。**
定額のプラン料金に加えて、有料モード(Power・Max)の作業と公開の費用が、プランに含まれる月のクレジットから差し引かれます。有料の作業は手間に応じた課金で、チェックポイント単位で数えられます。クレジットを使い切った後は、使った分の料金がかかります。

**Q. Free Mode と有料モードの違いは何ですか。**
Free Mode は追加費用なしのモードで、Core・Pro では利用枠が5時間ごとに戻り、週の上限もあります。Power は1つの作業に使うクレジットが少ないモード、Max は複雑な作業向けで高性能なモデルを使うモードです。有料モードに切り替わる前には確認が求められます。

**Q. 思ったより高くならないか心配です。**
Billing の画面で、指定額に達したら知らせるアラートと、それ以上使えなくする予算の上限を設定できます。使い始める前に設定しておくと、超過の請求を防げます。

**Q. 契約した後に返金してもらえますか。**
利用規約では、定期プランの支払いは購入から30日以内なら全額返金の対象とされています。使った分の課金は返金されません(2026年8月3日更新の利用規約、11月23日確認)。

**Q. 作ったアプリを公開し続けるにはいくらかかりますか。**
