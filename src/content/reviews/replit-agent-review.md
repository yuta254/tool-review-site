## この記事の結論

Replit Agent は、ブラウザで使う開発環境 Replit に組み込まれたAIで、**ふつうの言葉で「こういうアプリがほしい」と伝えると、コードを書き、必要な設定をして、結果を確かめ、そのまま公開まで進める**ことができます。現在の版は **Agent 4**(2026年3月11日発表)です。

- **プランは Starter(無料)・Core(月20ドル)・Pro(月100ドル〜)・Enterprise(要問い合わせ)。** 年払いにすると Core は月18ドル、Pro は月90ドルになります。
- **料金の考え方は「定額のプラン+使った分」。** Agent には無料で使える **Free Mode**(利用枠あり)と、有料の **Power / Max** モードがあり、有料モードの作業はプランに含まれるクレジットから差し引かれます。有料モードに切り替わる前には、確認が求められます。
- **有料の作業は、頼んだ内容の複雑さに応じて課金され、チェックポイント単位で数えられます。** 簡単な修正は安く、大きな作り込みは高くなります。
- **公開(デプロイ)の費用も、月のクレジットから差し引かれます。** 静的なサイトの公開は無料(転送量は1GBあたり0.05ドル)、常に動かす Reserved VM は月15ドルからです。
- **無料の Starter で公開できるアプリは1つで、30日で自動的に止まります。** 続けて公開するなら Core 以上が必要です。

この記事は、Replit の料金ページ([replit.com/pricing](https://replit.com/pricing))、公式ドキュメント(docs.replit.com)、公式ブログを2026年11月3日に確認して整理したものです。当サイトで実際に使った検証はしていません。公式情報を整理した記事です。

## Replit Agent でできること

[Agent の公式ドキュメント](https://docs.replit.com/features/agent/overview)と、[Agent 4 の発表記事](https://replit.com/blog/introducing-agent-4-built-for-creativity)に書かれている内容の要点です。

| 項目 | 公式の説明の要旨 |
| --- | --- |
| 作るもの | アプリ、デザイン、スライドなどを、ふつうの言葉の指示から作る。1つのプロジェクトの中で、Webアプリ・スマホアプリ・スライド・データの表示などを並べて作れる |
| 作り方 | コードを書き、インフラ(動かすための環境)を準備し、結果をテストする。見つけた問題は自分で直し、伝えた不具合の修正にも応じる |
| 戻せる | 作業中にチェックポイントを作り、前の状態に戻せる |
| 計画 | Plan モードで、作業の一覧を確認してから作り始められる |
| デザイン | Design Canvas で画面の案を複数出して比べ、選んだものをアプリに反映できる |
| 並行作業 | 認証・データベース・画面などの独立した作業を同時に進められる。同時に動かせる作業は Core が1つ、Pro が10 |
| 外部サービス | BigQuery・Slack・Notion などとつなぐ Connectors がある |

料金ページには、Agent の動きは確率的で、間違えることがある、という趣旨の注意も書かれています。出来上がったものは、人が確かめる前提で使うのが安全です。

## 料金プラン(2026年11月3日確認)

[料金ページ](https://replit.com/pricing)と[プランのドキュメント](https://docs.replit.com/billing/plans)の表示です。金額は米ドルです。

| プラン | 料金 | Agent まわり | 主な内容 |
| --- | --- | --- | --- |
| Starter | 無料 | Free Mode を1日ごとの上限つきで使える。ドキュメントでは「Lite build」のみ | 公開できるアプリは1つで30日で自動的に止まる。「Made with Replit」のバッジ付き。Plan モード・Connectors などは対象外。共同作業者は0人 |
| Core | 月20ドル(年払いなら月18ドル) | Free Mode のチャットは最大30時間・最大60プロジェクト、上位モデル用に月20ドル分 | 公開できるアプリの数に上限なし、バッジを外せる、最大5人で作業 |
| Pro | 月100ドル(年払いなら月90ドル)から | Free Mode をさらに多く、上位モデル用に月100ドル分・100ドル分のクレジット | 最大15人、並行作業10、データベースを28日前まで戻せる、優先サポート |
| Enterprise | 要問い合わせ | Free Mode ではなく Auto モードに一本化、管理者がモデルの利用を管理 | SSO・SCIM・監査ログ、専用の環境の選択肢など |

- 料金ページでは、Pro に月90ドルのほか **215・425・825・2,000ドル**の段階も表示されていますが、それぞれに含まれる内容は確認したページの本文からは読み取れませんでした。
- **以前あった Teams プランは終了**しました。公式ブログ([Pro プランの発表](https://replit.com/blog/pro-plan)、2026年2月24日)では、Teams の契約者は2026年3月3日から順に Pro へ追加費用なしで移ると案内されています。同じ記事で、Core は月25ドルから20ドルに値下げされています。
- Pro の使い残したクレジットは**2か月繰り越せる**と[AIの課金のドキュメント](https://docs.replit.com/billing/ai-billing)に書かれています(2月のブログでは1か月とされていたため、条件は変わることがあります)。Core のクレジットは繰り越せないとドキュメントにあります。

## Agent の課金のしくみ

ここがいちばん分かりにくい部分です。[Agent のモードの説明](https://docs.replit.com/features/agent/agent-modes)、[Free Mode のヘルプ](https://docs.replit.com/help/free-agent-mode)、[AIの課金のドキュメント](https://docs.replit.com/billing/ai-billing)の内容を整理します。

### モードは3つ(+Auto)

| モード | 位置づけ | 費用 |
| --- | --- | --- |
| Free Mode | アイデアを試す、作り始める | 追加費用なし。ただし利用枠あり。Core・Pro は**5時間ごとにリセットされ、週の上限もある**。Starter は1日ごとの上限 |
| Power | 費用を抑えたいとき。1つの作業に使うクレジットが少ない | 有料(クレジットから) |
| Max | 複雑な作業や大きなコード向け。最も性能の高いモデル | 有料(クレジットから) |
| Auto | Power か Max を選んだうえで、作業ごとに Replit がモデルを選ぶ(Core・Pro) | 有料(クレジットから) |

以前の Economy モードは、Power に置き換わって**今は使えない**とドキュメントに書かれています。

### 有料モードに切り替わるとき

Free Mode で手に負えない作業では、Agent が**有料のモードや機能が必要な理由を説明し、始める前に確認を求めます。** そのリクエストだけ許可するか、Free Mode のまま続けるかを選べ、終わるとモードは Free Mode に戻ります。

### 何に対して課金されるか

- **作業の手間(複雑さ)に応じた課金**です。簡単な修正は安く、複雑な作り込みは高くなります。
- 課金は**チェックポイント単位**で数えられます。大きな作業を1つのチェックポイントにまとめると、その1回の金額は大きくなります。
- **Plan モードでも、コードを変えなくても考える作業の分が課金される**ことがあります。
- Claude・ChatGPT・Gemini などの外部のAIを呼ぶ機能は、**各社の公開のAPI料金**でクレジットから差し引かれます。
- 契約者全員に、**1回限りの無料のチェックポイント**が付きます。

### 使いすぎを防ぐ設定

設定の Billing の画面で、**一定額に達したら知らせる「使用量のアラート」**と、**それ以上使えないようにする「予算の上限」**を設定できます。Free Mode の残りは設定の Usage で確認します。

## 公開(デプロイ)の方式と費用

[公開費用のドキュメント](https://docs.replit.com/billing/deployment-pricing)の金額です。公開の費用は**すべて月のクレジットから差し引かれ**、クレジットを使い切った後に使った分の料金がかかります。

| 方式 | 向いているもの | 費用(米ドル) |
| --- | --- | --- |
| Autoscale | アクセスに合わせて自動で増減するアプリ | 基本料月2ドル+計算量100万単位あたり0.60ドル+リクエスト100万回あたり0.40ドル |
| Static | 入力によって中身が変わらないサイト | 公開は無料、転送量1GBあたり0.05ドル |
| Reserved VM | 常に動かし続けたいアプリ | 月15ドル(共有・0.5vCPU/2GB)、35ドル(1vCPU/4GB)、50ドル(2vCPU/8GB)、130ドル(4vCPU/16GB) |
| Scheduled | 決まった時刻に動かす処理 | 基本料月2ドル+計算量100万単位あたり0.60ドル |

- Core には、外向きの転送量が**月100GiB**含まれると[使った分の課金のドキュメント](https://docs.replit.com/billing/about-usage-based-billing)に書かれています。
- 本番用のデータベースは、動いていた時間と保存量で課金されます。開発用のデータベースは無料です。Starter の本番データベースの保存量は1GiBまでです。
- 独自ドメイン(example.com のような自分のアドレス)の付け方と、ドメイン代を含めた年間の費用は、[AIで作ったサイトを公開する方法](/reviews/ai-site-publish-custom-domain/)の Replit の章にまとめています。

## データの扱いと、利用者が気をつけること

Replit の「[共同責任モデル](https://docs.replit.com/features/security/shared-responsibility-model)」のドキュメントでは、Replit と利用者のどちらが何に責任を持つかが整理されています。

- **入力した指示や生成されたコードの記録・保存期間・学習への利用**は、Replit の責任で、**契約しているプランの規約に従う**とされています。具体的な保存期間や学習の扱いは、このページには書かれていません。プランごとの規約を確認してください。
- **Agent が作ったコードの正しさ・安全性・ライセンスの確認**(Agent が追加した外部の部品を含む)は、利用者の責任です。
- **APIキーなどの秘密の情報は、チャットに貼らず**、Secrets や Connectors の機能で保管するよう案内されています。
- アプリを誰が見られるか・編集できるかを決めるのも利用者です。公開したアプリへのアクセス制限は Pro と Enterprise の機能です。

## 向いている人・向いていない人

**向いている人**

- 手元のパソコンに開発環境を用意せず、ブラウザだけで**動く試作品を早く作りたい人**
- 作ったものを、**同じ場所でそのまま公開まで**進めたい人
- 社内向けの小さなツールや、企画段階の確認用のデモを作りたい人

**慎重に考えたい人**

- 毎月の費用を固定したい人。有料モードと公開の費用はクレジットから引かれ、使い切ると使った分の料金がかかります。予算の上限を先に設定してください。
- 個人情報や決済を扱うアプリを、そのまま本番で使いたい人。Agent が作ったコードの確認は利用者の責任とドキュメントに明記されています。
- 生成されたコードを手元に持ってきて、自分の環境で育てたい人。その場合は[Bolt.newレビュー](/reviews/bolt-new-review/)や[v0レビュー](/reviews/v0-review/)、コードを書く人向けの[Cursorレビュー](/reviews/cursor-review/)も比べてみてください。

## 使い方のコツ

1. **最初に予算の上限を決める。** Billing の画面で、使用量のアラートと予算の上限を設定してから使い始める
2. **Plan モードで作業の一覧を確認してから作らせる。** ただし、Plan モードでも考える作業の分が課金されることがある
3. **小さな単位で頼む。** 大きな作業を一度に頼むと、1回のチェックポイントの金額が大きくなる
4. 認証・決済・個人情報を扱う部分は、出来上がった後に人の目でコードを確認する

## よくある質問

**Q. Replit Agent は無料で使えますか。**
無料の Starter プランでも、Free Mode を1日ごとの上限つきで使えます。ただし、公開できるアプリは1つで30日で自動的に止まり、Plan モードや Connectors などは使えません。続けて使うなら Core(月20ドル、年払いなら月18ドル)以上が想定されています。

**Q. 料金はどのように決まりますか。**
定額のプラン料金に加えて、有料モード(Power・Max)の作業と公開の費用が、プランに含まれる月のクレジットから差し引かれます。有料の作業は複雑さに応じた課金で、チェックポイント単位で数えられます。クレジットを使い切った後は、使った分の料金がかかります。

**Q. Free Mode と有料モードの違いは何ですか。**
Free Mode は追加費用なしで使えるモードで、Core・Pro では利用枠が5時間ごとにリセットされ、週の上限もあります。Power は費用を抑えたモード、Max は複雑な作業向けで最も性能の高いモデルを使うモードです。有料モードに切り替わる前には確認が求められます。

**Q. 思ったより高くならないか心配です。**
Billing の画面で、一定額に達したら知らせるアラートと、それ以上使えなくする予算の上限を設定できます。使い始める前に設定しておくのが安全です。

**Q. 作ったアプリを公開し続けるにはいくらかかりますか。**
静的なサイトなら公開は無料で、転送量1GBあたり0.05ドルです。アクセスに合わせて動く Autoscale は基本料月2ドル+使った分、常に動かす Reserved VM は月15ドルからです。どれも月のクレジットから先に差し引かれます。独自ドメインの付け方は[AIで作ったサイトを公開する方法](/reviews/ai-site-publish-custom-domain/)を参照してください。

**Q. プログラミング未経験でも使えますか。**
公式ドキュメントでは、ふつうの言葉の指示で作るノーコードの作り方として説明されています。ただし、Agent が作ったコードの正しさと安全性の確認は利用者の責任とされているため、個人情報や決済を扱うものは詳しい人に確認してもらう前提で進めてください。

**Q. Bolt.new とどちらを選ぶべきですか。**
Replit は実行環境・データベース・公開までを同じ場所で扱えるのが特徴です。生成されたコードを手元に持ってきて育てたいなら Bolt.new が候補になります。詳しくは[アプリビルダー4種の比較](/reviews/ai-app-builder-comparison/)を参照してください。
